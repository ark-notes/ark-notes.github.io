# 第一部分 · 战略（先看清现实）

## 1.1 市场现实（必须接受）

| 指标 | 数据 |
|---|---|
| AI漫剧爆款率 | **不足 0.1%**（1000部出1部） |
| AI短剧整体爆款率 | 0.47% |
| 赚钱公司 | 约 **10%** |
| 万次播放收益 | **5-10 元**（2026.5后，跌90%） |

**⚠️ 结论：**
```
❌ 别赌爆款
✅ 目标「稳定小额」（月入1-3万）
✅ 靠"数量+质量下限"取胜
```

## 1.2 分账不是收入，是获客成本

> 「分账今天的用途，是给你一份能拿出手的作品集，
> 用它去撬后面的商单、定制和 B 端订单。
> 把它当收入来源会亏得很难看；把它当获客成本，逻辑就通了。」

**→ 真正的现金流：B端接单 > 付费解锁 > 出海 > 广告分成**

## 1.3 目标定位：中层

| 层级 | 月收入 |
|---|---|
| 头部 | 百万 |
| 腰部 | 5-50万 |
| **普通（坚持更新）** | **1-3万** ✅ |

**→ 先跑通产能 → 再向头部靠。**

## 1.4 平台选择

| 平台 | 分成 | 门槛 |
|---|---|---|
| **红果**（字节） | 独家最高 90% | 低 ✅ |
| 抖音 | 同上 | 低 |
| 快手 | 99% 给创作者 | 中 |
| 视频号 | 60-70% | 要1000粉 |

# 第三部分 · 剧本（结构为王）

## 3.1 单集结构（90-120秒）

```
0:00-0:10  上集回顾 + 开场钩子
0:10-0:30  新场景展开
0:30-1:20  本集核心事件
1:20-1:50  反转或高潮
1:50-2:00  钩子
```

## 3.2 ⭐ 黄金时间节点（听花岛拆解）

```
3 秒   → 勾住观众
6 秒   → 进入冲突
10 秒  → 点出悬念
1 分钟 → 强化爽感
3 分钟 → 完整剧情
```

## 3.3 ⭐ 实测节奏（MasterD 拆解真实视频）

| 指标 | 实测 |
|---|---|
| **平均镜头长度** | **2.2 秒** ⚡ |
| 开场节奏 | 2.5s→3.0s→2.4s→1.8s |

**⚠️ 不是 6-8 秒！是 2.2 秒/镜。**

## 3.4 双层钩子（必须都有）

| 层 | 位置 | 作用 |
|---|---|---|
| **集内钩子** | 开场5秒 | 冲突/反常画面"摁住"观众 |
| **集间钩子** | 结尾5-10秒 | **情绪最高处切断** |

## 3.5 开篇方法

**极致冲突前置法：**
```
把全剧最炸的反转、最虐的场面、最爽的打脸
放在第1集开头。
```

**两种开场（都有效）：**
```
① 冲突式：「新婚夜，妻子把我推进手术室…」
② 悬念式：「招募两个听话懂配合的搭子」（反常行为）
```

## 3.6 台词铁律

```
单句：8-12 字（最长15字）
风格：短、碎、锋利
```
**⚠️ 实测爆款字幕更短：「我去」(2字)、「吃喝管够」(4字)**

## 3.7 反转层次

```
每 5-10 集 → 小反转（推动剧情）
每 20-30 集 → 大反转（改变格局）
全剧最多 2-3 个核心大反转
```

## 3.8 前三集铁律

```
第1集：极致冲突 + 立主角 + 抛悬念
第2集：展开世界观 + 增强冲突
第3集：安排第一个小爆点（留住第一批观众）
```

## 3.9 四层反派体系

```
小反派 → 中反派 → 大反派 → 隐藏反派
（关卡式，保证观众永远有"怪"可打）
```

# 第四部分 · 制作（提示词 + 工具）

## 4.1 提示词六大模块（专业结构）

```
① 主体（外貌/服饰/表情/动作）
② 场景环境
③ 镜头视角（景别/机位/运镜）
④ 画风（风格/色彩/光影）
⑤ 制式与画质（比例/清晰度）
⑥ 约束条件（负面提示词）★关键
```

## 4.2 负面提示词（防崩）

```
避免女性化脸、避免圆脸、避免肿眼泡、避免大鼻头、
避免宽鼻翼、避免厚唇、避免过度磨皮、避免塑料感皮肤、
避免畸形手指、避免多余手指、避免肢体扭曲、避免穿模、
避免服装结构错误、避免背景复杂、避免噪点、避免网红脸
```

**⚠️ 正确用法：基础负面词固定 + 遇到问题针对性补充**（不是无脑堆砌）

## 4.3 角色一致性（三视图）

**布局：**
```
最左侧1/3 = 超大面部特写
右侧2/3 = 正面/侧面/背面全身
纯白背景，无多余元素
```

**⚠️ 铁律（来自实战案例）：**
```
① 锚点图必须：正脸 + 无遮挡 + 干净光线
② 要 6-8 张基准图（全景/正脸/45度/表情）
③ ⭐ 单镜头提示词不要重复写外貌（会与锚点冲突→崩）
④ 用固定身份标识符
⑤ 风格一次性锁定
```

## 4.4 图生视频公式

```
图生视频 = 运动 + 运镜
（图像已定主体/场景/风格）
```
**⚠️ 用「图生视频」，不用「文生视频」**（后者锁不住脸）

## 4.5 运镜词汇

| 中文 | 英文 | 用途 |
|---|---|---|
| 推 | push-in/dolly in | 强调、情绪 |
| 拉 | pull-back | 交代环境 |
| 摇 | pan/tilt | 展示空间 |
| 移 | truck/tracking | 跟随 |
| 环绕 | orbit/arc | 展示全貌 |

**⚠️ 禁止在同一段写冲突运镜**（如固定+环绕）

## 4.6 工作流（9步）

```
① 选题 → ② 剧本 → ③ 角色设定
→ ④ 分镜脚本 → ⑤ 分镜图
→ ⑥ 图生视频 → ⑦ 配音+对口型
→ ⑧ 剪辑 → ⑨ 发布
```

## 4.7 工具链

| 环节 | 推荐 |
|---|---|
| 出图 | 即梦（BJD/UE5强）/ 豆包 |
| 出视频 | 阿奇 / 可灵 / 即梦Seedance |
| 剪辑 | 剪映 |
| 配音 | AnyVoice/豆包语音 |

**⚠️ 角色一致性铁律：同一个模型，不混用。**

# 第五部分 · 运营变现

## 5.1 平台机制

**抖音/红果核心指标：完播率**
```
· 首集 2 分钟引流 + 正片 1 分钟
· 超 3 分钟 → 完播率下滑
· 「短、快、密」是唯一出路
```

## 5.2 流量层级

```
Level 1：初始 200-500 播放
Level 2：3000-5000 池
Level 3：1-5 万池
Level 4：10-50 万
Level 5：100 万+
```

## 5.3 爆款公式

```
现象级爆款 = 优质内容 × 信息流放大 × 时机运气
```

## 5.4 六条变现路

```
① B端接单（最稳）  ② 承制  ③ 品牌定制
④ IP运营  ⑤ 知识付费  ⑥ 分账（当获客成本）
```

## 5.5 真实收益案例

# 第六部分 · 合规（红线，会封号）

## 6.1 备案制（2026新规）

| 投资额/题材 | 审核方 |
|---|---|
| ≥300万 或敏感题材 | 国家广电总局 |
| 100-300万 | 省级广电 |
| <100万 | 平台自审→报省级备案 |

**⚠️ AI漫剧 2026.4.1 起「先备案后上线」，未备案强制下线。**

## 6.2 AI 标识（强制）

```
「生成/编辑/配音合成」任一环节 AI 占比达红线
→ 必须在片头标注「AI 辅助制作」
```

## 6.3 禁拍清单

| 红线 | 后果 |
|---|---|
| 男女对立/家暴合理化 | 全平台封禁 |
| **历史虚无主义** | **永久禁入行业** |
| 儿童负面情节 | 严查（一月拦160部） |
| 低俗擦边/盗用肖像 | 下架/判赔 |

## 6.4 质量红线

```
穿模 / 模糊 / 杂音 / 字幕错误 → 判低质，影响上线
```

# 第七部分 · 学习方法（持续进化）

## 7.1 拉片拆解法（三层次）

```
第1层：一句话概括全剧
第2层：拆四阶段（前10/10-30/30-60/结局）
第3层：精拆前10集
   · 开场3秒钩子？
   · 6秒冲突？10秒悬念？
   · 反转在哪？结尾卡点？
   · 台词多少字？
```

## 7.2 技术拆解方法

```
① ffmpeg 抽帧（每秒1-2帧）
② ffmpeg 检测镜头切换（select='gt(scene,0.08)'）
   → 算出平均镜头长度
③ 图像识别读字幕/画面
④ 对比自己的剧本
```

## 7.3 数据抓取

**红果数据（MasterD 发现）：**
```
https://hongguoduanju.com/search/<关键词>
→ 返回 JSON（含热度/集数/标签/简介）
```

**官方资料库：**
```
https://ark-library.com/api/posts?category=<slug>
```

## 7.4 对标选择标准

```
抖音：单集播放 ≥2000万，完播率 ≥40%
快手：热度值 ≥80万，单日涨粉 ≥5万
```
