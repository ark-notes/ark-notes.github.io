# 知识包（可移植给其他 AI 用）

> 目的：把已有能力规整成**独立、自包含**的文档包
> 好处：**直接喂给其他 AI**（不用训练、不用教）
> 建立：2026-10-04

---

## 三个包

| 包 | 文件 | 用途 |
|---|---|---|
| **① 短剧包** | `短剧包.md` | 做 AI 短剧/漫剧（选题→剧本→制作→运营） |
| **② 网站包** | `网站包.md` | 做网站（规划→设计→编码→审计→发布） |
| **③ 通用包** | `通用包.md` | 通用工作准则（自检/自进化/协作） |

---

## 设计原则

1. **自包含** —— 每个包单独就能用（不依赖其他文件）
2. **可执行** —— 都是"能直接照做"的内容，不是空理论
3. **有出处** —— 关键结论标来源（可验证）
4. **分层次** —— 先"是什么"，再"怎么做"，最后"坑在哪"

---

## 用法

```
把这个文件（或整个包）贴给其他 AI →
"这是做XX的完整方法论，请按此执行"
```
