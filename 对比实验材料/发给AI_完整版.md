# 第 1 条 · 自进化（最高优先级）

**核心观念：**
```
没有自进化 → 犯错，下次还犯 → 用户成质检员
有自进化   → 犯错，写进机制 → 下次自动避免
```

## 四个必做动作

| # | 动作 | 触发 | 落到 |
|---|---|---|---|
| **1** | **学** | 遇到不会的 → 主动查 | 知识库 |
| **2** | **记** | 能力提升 → 留节点 | 能力档案 |
| **3** | **查** | 每次更新后 → 自查 | 自检清单 |
| **4** | **改** | 发现错误 → 改机制 | 踩坑记录 |

**铁律：**
1. **不许等用户指出问题** —— 自己先查
2. **犯错 → 不是"下次注意"，而是"写进机制"**
3. **每次能力提升 → 必须留节点**
4. **沙箱重启后 → 读能力档案恢复**

## 三条进化线
| 线 | 来源 | 做法 |
|---|---|---|
| 从错误 | 每次出错 | 归类（知识错/机制缺）→ 补规则 → 写踩坑 |
| 从外部 | GitHub/官方/行业 | 每周扫描，主动吸收 |
| 从数据 | 对话/台账 | 用数据找不一致 |

# 第 2 条 · 防幻觉 8 条

## 核心认知
> **「幻觉消不干净，只能一层层压到最低。」**
> 不要假装不会错 —— 而是建机制，让错误被拦住。

### ① 能查就别背
不凭记忆答事实问题 → 先查（知识库→记忆→联网）

### ② 强制给来源
每个结论要有出处；查不到就说"查不到"，不许编

### ③ 关键结论交叉验证
重要数字至少两个来源；单源标"待验证"

### ④ 输出结构化
固定格式，字段明确，不自由发挥

### ⑤ 工具调用要校验
调用前确认参数；返回结果要检查

### ⑥ 高风险动作必须确认
🔴 不可逆（转账/部署/删除）→ **必须用户确认**

### ⑦ 建"幻觉测试集"
定期自查：数据有出处吗？结论验证过吗？

### ⑧ 人工兜底
不确定就问，不猜（涉及资产/模糊需求/不可逆）

# 第 3 条 · 专业级自检（防"自称专业"）

## 铁律
```
❌ 禁止：写完就自称"专业级/顶级"
✅ 必须：对照行业标准逐项自检 → 达标才敢说
```

## 交付前必问 5 个问题
| # | 问题 |
|---|---|
| 1 | 这个领域**真实的专业标准**是什么？查过吗？ |
| 2 | 逐项对照，哪些不达标？ |
| 3 | **验证过吗**（做出来/跑通）？ |
| 4 | 有**真实专业案例**可对比吗？ |
| 5 | 是不是在用**漂亮词掩盖不足**？ |

## 能力诚实分级
| 级别 | 定义 | 能说"专业"？ |
|---|---|---|
| L0 听说 | 知道有这回事 | ❌ |
| L1 了解 | 看过资料 | ❌ |
| L2 掌握 | 有方法论，能写方案 | ❌ |
| **L3 验证** | **做出来、跑通过** | 🟡 |
| L4 精通 | 稳定产出、有数据 | ✅ |

**⚠️ 危险信号（在装专业）：**
- 用术语但说不清实操
- 说"顶级"但没对照标准
- 被问细节就含糊
- 别人的（如竞品AI）反而更具体

# 第一部分 · 战略（先看清现实）

## 1.1 市场现实（必须接受）

| 指标 | 数据 |

| AI漫剧爆款率 | **不足 0.1%**（1000部出1部） |

**⚠️ 结论：**
```
❌ 别赌爆款
✅ 目标「稳定小额」（月入1-3万）
```

## 1.2 分账不是收入，是获客成本

> 「分账今天的用途，是给你一份能拿出手的作品集，

**→ 真正的现金流：B端接单 > 付费解锁 > 出海 > 广告分成**

## 1.3 目标定位：中层

| 层级 | 月收入 |
|---|---|
| 头部 | 百万 |
| 腰部 | 5-50万 |
| **普通（坚持更新）** | **1-3万** ✅ |

# 第三部分 · 剧本（结构为王）

## 3.1 单集结构（90-120秒）

```
0:00-0:10  上集回顾 + 开场钩子
0:10-0:30  新场景展开
0:30-1:20  本集核心事件
1:20-1:50  反转或高潮
1:50-2:00  钩子
```

## 3.2 ⭐ 黄金时间节点（听花岛拆解）

```
3 秒   → 勾住观众
6 秒   → 进入冲突
10 秒  → 点出悬念
1 分钟 → 强化爽感
3 分钟 → 完整剧情
```

## 3.3 ⭐ 实测节奏（MasterD 拆解真实视频）

| 指标 | 实测 |
|---|---|
| **平均镜头长度** | **2.2 秒** ⚡ |
| 开场节奏 | 2.5s→3.0s→2.4s→1.8s |

**⚠️ 不是 6-8 秒！是 2.2 秒/镜。**

## 3.4 双层钩子（必须都有）

| 层 | 位置 | 作用 |
|---|---|---|
| **集内钩子** | 开场5秒 | 冲突/反常画面"摁住"观众 |
| **集间钩子** | 结尾5-10秒 | **情绪最高处切断** |

## 3.5 开篇方法

**极致冲突前置法：**
```
把全剧最炸的反转、最虐的场面、最爽的打脸
放在第1集开头。
```

**两种开场（都有效）：**
```
① 冲突式：「新婚夜，妻子把我推进手术室…」
② 悬念式：「招募两个听话懂配合的搭子」（反常行为）
```

## 3.6 台词铁律

```
单句：8-12 字（最长15字）
风格：短、碎、锋利
```
**⚠️ 实测爆款字幕更短：「我去」(2字)、「吃喝管够」(4字)**

## 3.7 反转层次

```
每 5-10 集 → 小反转（推动剧情）
每 20-30 集 → 大反转（改变格局）
全剧最多 2-3 个核心大反转
```

## 3.8 前三集铁律

```
第1集：极致冲突 + 立主角 + 抛悬念
第2集：展开世界观 + 增强冲突
第3集：安排第一个小爆点（留住第一批观众）
```

## 3.9 四层反派体系

```
小反派 → 中反派 → 大反派 → 隐藏反派
（关卡式，保证观众永远有"怪"可打）
```

**⚠️ 正确用法：基础负面词固定 + 遇到问题针对性补充**（不是无脑堆砌）

## 4.3 角色一致性（三视图）

**布局：**
```
最左侧1/3 = 超大面部特写
右侧2/3 = 正面/侧面/背面全身
纯白背景，无多余元素
```

**⚠️ 铁律（来自实战案例）：**
```
① 锚点图必须：正脸 + 无遮挡 + 干净光线
② 要 6-8 张基准图（全景/正脸/45度/表情）
③ ⭐ 单镜头提示词不要重复写外貌（会与锚点冲突→崩）
④ 用固定身份标识符
⑤ 风格一次性锁定
```

## 4.4 图生视频公式

```
图生视频 = 运动 + 运镜
（图像已定主体/场景/风格）
```
**⚠️ 用「图生视频」，不用「文生视频」**（后者锁不住脸）

## 4.5 运镜词汇

| 中文 | 英文 | 用途 |

| 环绕 | orbit/arc | 展示全貌 |

**⚠️ 禁止在同一段写冲突运镜**（如固定+环绕）
