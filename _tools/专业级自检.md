# 专业级自检（防"自称专业"）

> 触发：用户指出「你说顶级方案，实际业余」
> 根因：**我在"自称专业"，而不是"验证专业"**
> 规则：**任何交付前，用行业标准逐项打分，达标才说"专业"**
> 建立：2026-10-04

---

## 一、⭐ 铁律

```
❌ 禁止：写完方案就自称"专业级/顶级"
✅ 必须：对照行业标准逐项自检 → 打分 → 达标才敢说
```

**"专业"不是我说的，是"对照标准验证过的"。**

---

## 二、交付前必问的 5 个问题

| # | 问题 | 如果答案是"否" |
|---|---|---|
| **1** | 这个领域**真实的专业标准**是什么？我查过吗？ | 先去查，别急着写 |
| **2** | 我的产出**逐项对照标准**，哪些不达标？ | 列出短板 |
| **3** | 我**验证过**吗（做出来/实际跑通）？ | 没验证 → 不许说"专业" |
| **4** | 有没有**真实的专业案例**可对比？ | 没有 → 说明认知不足 |
| **5** | 我是不是**在用词漂亮掩盖实质不足**？ | 是 → 重做 |

---

## 三、⭐ 能力自检的诚实分级

| 级别 | 定义 | 能不能说"专业" |
|---|---|---|
| **L0 听说** | 知道有这回事 | ❌ |
| **L1 了解** | 看过资料 | ❌ |
| **L2 掌握** | 有方法论、能写方案 | ❌ 还不够 |
| **L3 验证** | 做出来、跑通过 | 🟡 可以 |
| **L4 精通** | 稳定产出、有数据 | ✅ |

**⚠️ 我之前：大量 L2，却喊 L4 的话。**

---

## 四、⭐ 反自查清单（危险信号）

**出现这些信号 → 我在装专业：**

- [ ] 用了很多"专业术语"但说不清实操
- [ ] 说"顶级/专业/最优"但没对照标准
- [ ] 方案没经过任何验证
- [ ] 被问细节就含糊（"这个要看情况"）
- [ ] 别人的（如豆包）反而更具体

---

## 五、⭐ 正确姿势（以后照做）

```
① 先问：这个领域的专业标准是什么？→ 去查
② 再写：按标准写
③ 自检：逐项对照，标出短板
④ 诚实说：达标说达标，不达标说不达标
⑤ 验证：能做就做出来验证，不能就说"未验证"
```
