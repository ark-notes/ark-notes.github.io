## ⭐ 关键发现：官方 API

```
https://ark-library.com/api/posts
```

### 可用端点
| 端点 | 说明 |
|---|---|
| `/api/categories` | 全部分类（带 id/slug/name） |
| `/api/posts` | 帖子列表（默认20条） |
| `/api/posts?category=<slug>` | **按分类筛选** ✅ |
| `/api/posts?limit=N` | 限制条数 |
| `/api/posts?offset=N` | 翻页 |

### 分类 slug
```
official-announcement  官方公告
subsidy-policy         补贴政策
community-tweets       社群动向
daily-class            每日课堂
arkie-ai               阿奇AI教程
how-to                 操作指南
video-hub              视频汇总
global-evangelism      全球布道
daily-poster           每日海报
```

### 数据格式
```json
{
  "items": [{
    "id": "...",
    "categorySlug": "official-announcement",
    "postType": "image|video|text",
    "language": "zh",
    "localizations": {"zh": {"text": "正文..."}},
    "attachments": [{"url":"https://ark-library.com/uploads/...", "kind":"image"}],
    "publishedAt": "..."
  }]
}
```

**⚠️ 注意：**
- 同一条内容有**7种语言**（zh/en/ja/ko/ms/vi/...）→ **只取 zh 去重**
- 图片/视频在 `attachments[].url`（直接下载）

---

## 抓取脚本

```bash
python3 fetch_news.py                                    # 默认4分类
python3 fetch_news.py official-announcement daily-class  # 指定分类
→ 输出 news_latest.json
```

---

## 用途

1. **资讯页更新**（news.html）
2. **空课内容**（daily-class = 每日课堂排期 → 找新逐字稿）
3. **政策追踪**（subsidy-policy）
4. **深挖素材**（community-tweets / official-announcement）
