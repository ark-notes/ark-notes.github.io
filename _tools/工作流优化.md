# 工作效率优化（2026-10-04）

> 用户要求：「你思考得慢，学豆包，提升效率」

---

## ⭐ 核心优化：抽帧提速 30 倍

### ❌ 慢的做法（39秒）
```bash
ffmpeg -i 视频 -vf "fps=1/20" out%02d.jpg   # 要解码全片
```

### ✅ 快的做法（1.3秒）
```bash
for t in 20 60 100 140; do
  ffmpeg -ss $t -i 视频 -frames:v 1 out$t.jpg &   # -ss 放 -i 前！
done; wait                                        # 并行
```

**原理：`-ss` 放 `-i` 前面 = 直接跳到时间点（不解码全片）**

---

## ⭐ 工作流原则（提速）

| 原则 | 做法 |
|---|---|
| **1. 批量并行** | 多个 ffmpeg 用 `&` 并行 |
| **2. 一次汇报** | 攒够再报，不每步打断 |
| **3. 精准定位** | 不抽全片，抽关键帧 |
| **4. 先粗后细** | 先 20 秒一帧，找到重点再密抽 |

