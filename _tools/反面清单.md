> 原则：犯了错 → 不是"下次注意"，而是【写进这里】
> 用途：每次动手前扫一遍，避免重犯

## 四、已验证的事实（别再重测）

```
· 不是软件问题（阿奇/即梦都能出）
· 阿奇输出 540x675，即梦最高4K
· 阿奇同一提示词结果会飘（时2D时写实）
· 参考图功能有效（但风格取决于哪张参考图）

```

## 五、使用规则

```
每次动手前：

③ 犯了 → 立刻补进清单
```
