## 🔴 坑 7：下载不完整，却怪"文件格式"（2026-10-04）

| 项 | 内容 |
|---|---|
| **现象** | 用户发的 .mov 视频，我"只能解码前几秒"，还说"mov 有概率损坏，建议传 mp4" |
| **用户的话** | 「你为什么不能读mov？检查你的工具做适配」 |
| **我的错** | **以为是格式问题 → 实际是"我下载不完整"** |
| **根因** | 我用 `curl -m 400`（400秒超时）→ 大文件没下完就被 kill |
| **铁证** | 服务器 177MB，我只下了 10MB（5.8%） |

### 修复

```
① 大文件下载：用断点续传 curl -C - ，不设固定超时
② 下载后必须校验：对比 Content-Length vs 本地大小
③ 抽帧前先检测：码率是否正常（<1000kbps = 可疑）
```

### 防再犯

```bash
# 正确做法
server=$(curl -sI "$url" | grep -i content-length | awk '{print $2}')
mine=$(stat -c%s "$out")
[ "$server" = "$mine" ] || echo "❌ 不完整，需重下"
```

**⚠️ 结论：先怀疑自己，再怀疑文件。**
