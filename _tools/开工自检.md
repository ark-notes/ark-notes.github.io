### 铁律

```bash
cd /app/workspace/build

```

**或单独跑自查：**
```bash
python3 自查.py
```

### 自查 7 项

| # | 检查 | 失败后果 |
|---|---|---|
| 1 | **HTML 结构**（标签闭合） | 页面可能破版 |
| 2 | **内链**（死链） | 用户点到 404 |
| 3 | **图片**（是否存在） | 破图 |
| 4 | **出处覆盖**（话术 vs 出处） | 违反核心规则第 3 条 |
| 5 | **术语系统**（terms.js 引用） | 术语点不开 |
| 6 | **SEO 元数据**（desc/og） | 分享无卡片 |
| 7 | **无障碍**（skip-link/main） | WCAG 不合规 |

### 为什么必须做

**我犯过的错：**
- 「几年内不能用」—— 没有依据就下结论
- 28 章内容没标出处 —— 写了话术没标来源
- 这些都是**用户指出**的，不是自查发现的

**自查的价值：把「等用户发现」变成「我自己发现」。**
