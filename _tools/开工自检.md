# 开工自检（每次干活前必读）

> **铁律：每次开工，第一件事是「抓仓库」—— 规则、需求、能力档案、对话记录、素材全拉一遍。**
> 不许凭记忆做事（沙箱会重启，记忆会丢）。

---

## 第 0 步：跑恢复

```bash
cd /app/workspace/build && python3 开工.py
```

这会自动：
1. 拉三个仓库
2. 同步到工作区
3. **读能力档案**（恢复"自己会什么"）
4. 读对话记录（最近 3 天）
5. 比对台账 vs 实际

**没有 token** → 从对话历史里找（`.token_site` / `.upload_token` / `.token`）

## 第 1 步：⭐ 读能力档案（恢复「我是谁」）

**文件：`能力档案.md`**

**用户明确要求（2026-10-03）：**
> 「沙箱重启后，你的自我进化、能力提升都要能恢复，
>   每个节点都要记清楚，防止出现初始化的问题。」
> 「Git 仓库里面不止记录了内容，也包括你的自我进化、你的能力提升。」

**看三样：**
1. **最新节点** —— 上次进步到哪
2. **待补能力** —— 有什么还没学
3. **核心理念** —— 用户的三句话

**为什么必须读：**

| 不读 | 读了 |
|---|---|
| 忘了自己会什么 | 知道已有能力 |
| 重复造轮子 | 接着上次继续 |
| **能力归零** | **能力延续** |
