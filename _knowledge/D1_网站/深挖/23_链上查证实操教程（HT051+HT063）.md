> 主题：**手把手教你在链上验证铸币合约的安全**

---

## 一、⭐ 为什么要查这个（核心问题）

> 「教大家如何查准一个铸币合约**是否开源**，
> 以及铸币合约的**权限是否已经放弃**。」

**→ 这是回答"安不安全"的**唯一硬办法**（链上查证，不是听说）。**

---

## 二、⭐ 完整操作流程（HT-051 · 7步）

### 第 1 步：打开区块浏览器
```
搜索该铸币合约（ARK 铸币合约）
```

### 第 2 步：查看交易记录
```
看到总共有 15 条交易记录
```

### 第 3 步：看"表面上"的地址
```
总共有 2 个地址：
① 末尾 3386 → 部署者
② 末尾 ED82 → 另一地址
→ 这两个地址"曾经"拥有过铸币合约权限
```

### 第 4 步：⭐ 深挖每一条调用记录的哈希
```
⚠️ 关键：不能只看表面 2 个
→ 要逐条点进 15 条记录，看有没有其他地址参与
→ 又发现：7108、D616（RBS 做市模块）
→ 最终：4 个地址曾经拥有权限
```

### 第 5 步：验证合约是否开源
```
「这里有一个绿色的对勾 → 合约代码都可以看到」
→ ✅ 开源
```

### 第 6 步：⭐ 逐个验证 4 个地址的权限
```
打开合约后台，关注前 3 个角色：
① 管理员权限
② 超级管理员权限
③ 铸币角色

对每个地址，逐一验证：
· 有管理员权限吗？→ 返回值 false（没有）
· 有超级管理员权限吗？→ false
· 有铸币权限吗？→ false
```

### 第 7 步：读结果
```
「全部都是 false → 这意味着它是安全的」
「它不能被更改」
```

---

## 三、⭐ 背后的原理（为什么"false"=安全）

| 权限 | 危险 | 如果 = false |
|---|---|---|
| **管理员权限** | 能改合约 | ✅ 安全 |
| **超级管理员** | 最高权限 | ✅ 安全 |
| **铸币角色** | 能凭空增发 | ✅ 安全 |

**核心逻辑：**
```
如果这些权限都被放弃（false）
→ 没人能改合约、没人能偷偷增发
→ 代币是"去中心化"的
```

## 四、⭐ HT-063 补充细节

**查调用记录的方法：**
> 「如果有一个地址调用铸币合约，
> 那么说明**这个地址曾经拥有管理员权限**。」

**逐条查哈希：**
> 「我们每一个区块哈希都要把它点进去看一下，
> 是否有新的地址被添加为管理员。」

**查到的 4 个地址：**
```
① 结尾 1D82
② 结尾 3386（部署者）
③ 7108
④ D616（RBS 做市模块）
```

**7 个功能（重点关注前 3）：**
| # | 功能 | 关注度 |
|---|---|---|
| 1 | 管理员权限 | ⭐⭐⭐ |
| 2 | 超级管理员权限 | ⭐⭐⭐ |
| 3 | 铸币角色 | ⭐⭐⭐ |
| 4 | 查某角色有谁管理 | 一般 |
| 5 | 验证角色权限（本教程用的就是这个） | 工具 |
| 6 | 暂停合约权限（false=正在运行） | 参考 |
