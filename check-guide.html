项目体检指南

给你一个项目，10 分钟判断它安不安全。不只查 ARK —— 任何区块链项目都能用这套方法。

核心原则

不听宣传，只看链上。
项目方说的话可以编，写在链上的数据编不了。
这一页是「体检表」—— 你拿着它，一个项目一个项目地过。

一、基础信息核验（3 分钟）

怎么做这一关

下面每一项都告诉你去哪查、点哪里、看到什么算合格。
左边的按钮直接点开就能查，不用自己找网址。

01
先找到它的合约地址
去哪查

打开下面任一平台，搜项目名（或代币名），就能看到合约地址。

DexScreener AVE
怎么判断

✅ 搜得到，而且只有一个同名 → 正常

🔴 搜不到，或者出来好几个同名 → 警惕

02
看持币地址有多少个
去哪查

打开区块浏览器，搜索合约地址 → 点「Holders」（持有人）标签。

BscScan
怎么判断

✅ 几万个以上 → 有人真的在用

🔴 不到 1000 个 → 基本是自家人玩，小心

03
看它上线多久了
去哪查

在 BscScan 上点「Contract」→ 看「Contract Creator」和创建时间。

怎么判断

✅ 上线一年以上、经历过行情起伏 → 相对稳

🔴 刚上线几天、几周 → 高度警惕

04
看池子里有多少钱（流动性）
去哪查

DexScreener 或 AVE 打开，直接看「Liquidity」（流动性）那一栏。

DexScreener AVE
怎么判断

✅ 几十万美金以上 → 买卖不容易被卡

🔴 不到 5 万美金 → 一点钱就能砸盘

05
看有没有被大平台收录
去哪查

去 CoinMarketCap 或 CoinGecko 搜项目名。

CoinMarketCap CoinGecko
怎么判断

✅ 两个都收录了 → 经过了平台审核，可信度更高

🔴 都没收录 → 谨慎，别急

这一关过不了，后面不用看了

如果上面 5 项里有 3 项以上亮红灯，直接放弃。不用往下查。

二、安全第一关：LP 底池锁了吗

「光锁了还不够，要看锁仓比例 —— 有的项目锁 20%、30%，根本没有意义。」

「必须接近 100% 全部上锁，而且最好是黑洞锁（永久）。」

检查表
检查项怎么看合格危险
是否上锁AVE → 点 → 看锁仓已锁未锁 → 随时撤池跑路
锁的类型看是"时间锁"还是"黑洞锁"黑洞锁（永久）时间锁 → 到期可取
锁仓比例看百分比≥ 95%锁 20-50% → 没意义
剩余未锁部分看地址交易所地址项目方地址
交叉验证（防第三方造假）

AVE 看到锁仓 → 去 BscScan 验证 → 打开 LP 合约 → Holders → 看是否黑洞地址（0x000...000）。

三、安全第二关：铸币权限丢了吗

「铸币权限决定代币的生死命脉。」

「如果项目方保留铸币权限：想拿底池的钱 → 敲代码铸币 → 砸到底池换钱；不想玩了 → 增发十亿百亿 → 把底池全部掏空。」

进阶：查"隐藏条款"（实战方法）

「BscScan → 合约代码 → 代码旁边有个小三角符号 → 点开。」

「如果他真的是光明的，为什么不能直接写在明面上？为什么要藏到隐藏条款里？」

五、资金盘特征识别

两种崩盘信号

什么时候会崩
信号表现
① 赚够了老板本打算赚 1 亿，结果突然进来 3 亿 → 想尽办法赶你走（惯用手法：贼喊捉贼、黑客背锅）
② 赚不够底池涨到瓶颈、市场不景气 → 想尽办法搞活动刺激（开大会 = 追悼会）

链上怎么判断

「如果一个项目底池长期存在、没有增长，交易量也很小 → 说明没有换手率，做不景气。」

「如果底池不怎么变化、但交易量持续在变化 → 说明是真正的换手率。」

资金盘 vs 真项目

对照表
维度资金盘真项目
钱在哪打给项目方账户链上合约
能不能提提现要"审核"，被驳回随时可提
生态没有 / 只有概念有真实产品、能创收
权限项目方可随时改规则写死在合约里
治理老板一言堂社区投票

六、识别假"海外项目"

「真项目方你在会议现场才见得到，而且上台一定拿着稿子念 —— 你把稿子抽掉问他几个问题，他就露馅了。」

「真正的海外组织，在 YouTube、推特上能看到他们日常正常工作。」

三个验证点
检查项怎么查假的特征
创始人是真的人吗谷歌 / 推特 / YouTube 搜只在会议现场出现，下台就找不到
团队有没有日常活动YouTube / Twitter没有日常更新
地址是否中心化链上查钱能被打到个人账户

七、输出风控结论

风险等级
等级特征
🟢 低风险LP 黑洞锁 ≥95% + 权限已丢弃 + 多签国库 + 有真实产品
🟡 中风险部分条件不满足（如时间锁、权限未丢弃但有说明）
🔴 高风险未锁仓 / 权限可人为操作 / 国库单签 / 无生态

「我不告诉你这个项目好不好 —— 我给你几个地址，你自己去查。」

「链上数据不会骗人。」

⚠️ 边界说明

本页只做链上事实核查，不做投资建议、不预测价格、不判定"项目一定是骗子"。
链上数据能证明风险，不能证明意图。最终判断由你自己做。

九、一次完整的「项目体检」（怎么跟客户说）

「有人跟我推荐一个项目，我不会说它好或不好 —— 我会说：把你的地址给我，我查一下。」

「然后我打开手机，当着你的面查三样：」

「① 底池锁了没有、锁多少；② 铸币权限丢没丢；③ 国库谁说了算。」

「三样都过关，我才继续听；有一项不过关，我就不看了。」

「你也可以学着查 —— 学会了，以后谁跟你说项目，你都不怕。」
