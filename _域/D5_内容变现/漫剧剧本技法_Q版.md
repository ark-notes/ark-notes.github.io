## 一、⭐ 漫剧剧本专业格式（我之前没有）

### 标注符号（关键）
```
△ ：视觉化场景与动作
    （无对话的动作/走位/镜头衔接/场景铺垫）

OS：人物心理活动、内心独白
    ⭐ 这就是"Q版内心活动"的位置

VO：旁白、画外音（画面中无人，仅声音）
```

### 镜头元素
```
· 运镜、景别（全景/远景/中景/近景/特写）
· 镜头数（单人/双人/三人）
· 立绘、⭐【Q版】
```

---

## 二、⭐ Q版 = 加分项/反差萌（核心）

```
正经剧情（立绘）→ 表现真实、严肃
        ↓
内心活动（OS）→ 用【Q版】表现
        ↓
= 反差萌 → 可爱到爆
```

**例：**
```
【画面】陈默（立绘）冷峻地看着尸群
【OS】陈默（Q版小人）："完了完了，腿软了……"
→ 反差萌，观众笑
```

---

## 三、⭐ 其他进阶技法（学到）

| # | 技法 |
|---|---|
| **1** | **环境替角色说话**（凌乱房间=混乱内心）|
| **2** | **镜头过渡**（全景→特写突兀 → 加转场/"眼部穿越"）|
| **3** | **镜头切换原则**（自然，不突然冒出人）|
| **4** | **强钩子设计**（3分钟让观众笑/爽/燃/怕）|

---

## 四、⭐ 我该改进剧本

| 我之前的剧本 | 该改 |
|---|---|
| 只写画面/台词 | **加 △/OS/VO 标注** |
| 没有Q版内心 | **加 Q版 OS 镜头（反差萌）** |
| 没过渡设计 | **加镜头过渡** |
| 没立绘/Q版区分 | **标注立绘/Q版** |
