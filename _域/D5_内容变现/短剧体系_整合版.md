# 第二层 · 剧本（结构为王）

## 2.1 公式
```
爆款 = 钩子 + 冲突 + 反转 + 爽点
```

## 2.2 节奏（进阶版）
```
· 前 5 秒必须钩子
· 每 3-5 秒一个小反转
· 每 30 秒一个大反转
· 单集 1-3 分钟
```

## 2.3 结构
```
开篇3秒设钩 → 6秒冲突 → 10秒悬念
中段：3集一小反转 / 5集一大高潮
结尾：卡在情绪最高点，抛新悬念
```

## 2.4 台词
```
· 单句 4-12 字（短、碎、锋利）
· 口语化（去书面语）
```

## 2.5 ⭐ 结尾技巧（进阶）
```
结尾设【开放式问题】→ 引导评论
例："她到底是谁？"
```

# 第三层 · 角色（锁一致性）

## 3.1 流程
```
① 出"定妆照"当锚点（阿奇试词 → 即梦出图）
② 后续镜头只描述动作/场景
③ 每个镜头【开新会话 + 传单张图】
```

## 3.2 提示词结构（进阶）
```
【角色】年龄/性别/气质
【面部】五官细节 + 眼神光
【皮肤】真实纹理/毛孔
【发型】发丝分明
【服饰】
【光影】主光+轮廓光
【画质】8K
【约束】无崩坏/无畸形/无穿模
```

## 3.3 ⚠️ 避坑
```
· 别用三视图（阿奇会展示三视图）
· 3D风格要强制加"真实纹理"（否则塑料感）
· "low"的5原因：塑料脸/崩坏/头发棉絮/空洞眼/平光
```

# 第四层 · 生成（视频）

## 4.1 铁律
```
· 图生视频（不是文生视频）
· 一镜一动作
· 每镜多生成2-3版挑最佳
· 时长 3-8 秒
```

## 4.2 阿奇实测结论
```
✅ 锁脸强（0.94-0.97 新会话）
✅ 简单动作可以
⚠️ 复杂动作打折
⚠️ 结尾有 ARKIE 水印（要剪）
```

# 第五层 · 剪辑（含去水印）

## 5.1 流程
```
① 剪掉每镜的"ARKIE AI"结尾
② 拼接成集
③ 配音（叮叮配音，免费）
④ 字幕 + 音效
⑤ 片头加：备案号 + AI标识
```

## 5.2 ⭐ 水印三层级
```
· 工具水印（阿奇）→ 去
· 合规标识（备案号+AI声明）→ 自己加
· 作者署名 → 可选
```

# 第六层 · 发布

## 6.1 红果流程
```
① 注册创作者账号 + 实名认证
② 准备：竖屏9:16、≥720p、1-3分钟
③ 创作中心 → 上传 → 填信息
④ 审核（3-7工作日）
⑤ 通过 → 上架
```

## 6.2 ⭐ 投放（进阶·我之前的盲区）
```
平台：巨量千川(抖音)/磁力金牛(快手)
策略：
· 测试期：500-1000/天，测3-5条
· 放量期：ROI>1.2 加投
· 稳定期：矩阵（10-30条）
指标：完播率>30% / 点击率>2% / ROI>1.2
```

## 6.3 ⭐ 数据复盘
```
发布后看：完播率/点击率/ROI
数据不好 → 先改【开头】（前3秒）
```
