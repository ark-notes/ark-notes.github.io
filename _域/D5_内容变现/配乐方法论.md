# 配乐方法论（短剧）

> 来源：知乎"短剧BGM榜单"+ 智谱Noema Lab"配乐工作流"+ 搜狐"BGM推荐"
> 整理：2026-10-04
> ⭐ 用户强调：配乐尤其重要

---

## 一、⭐ 核心原则：配乐跟「情绪曲线」走

```
用【动作速度 + 场景转折 + 情绪曲线】设计配乐
→ 音乐跟着情绪走
```

---

## 二、⭐ 配乐分类

| 类型 | 用途 |
|---|---|
| **核心配乐** | 主题曲/角色专属（反复出现）|
| **辅助配乐** | 氛围插曲/转场音乐 |
| **音效** | 转场音（嗖/风）+特殊音效 |
| **BGM** | 情绪铺底 |

---

## 三、⭐ 关键技法

### 1. 低频铺垫悬念
> 「低频音效全程铺垫悬念，张力跟着剧情往上拉，
> 结尾自带强悬念落点。**音乐一停，观众就点下一集**」

### 2. BPM 控制
```
· 悬疑 → BPM 90，低频贯穿，渐强
· 爽剧 → 强节奏鼓点 + 递进弦乐
```

### 3. "音乐一停" = 钩子
```
结尾音乐戛然而止 → 观众忍不住点下一集
→ 配乐的"钩子"作用
```

---

## 四、⭐ 配乐与情绪对应表

| 情绪 | 配乐 |
|---|---|
| 压抑铺垫 | 低频、慢 |
| 反转 | 鼓点/弦乐推高 |
| 爽点爆发 | 强节奏、高潮 |
| 悬念 | 渐强、戛然而止 |
| 温情 | 钢琴/柔和 |
| 紧张 | 心跳/急促 |
