# 提示词工程 · AI 短剧实操

> 来源：阿里云百炼《视频生成 Prompt 指南》/ seedance2-skill(GitHub) / LzyPrompt / ScreenWeaver / 知乎 / 123AI
> 抓取日：2026-10-03
> 用途：**D5 制作层核心** —— 决定画面能不能用

---

## 一、⭐ 核心认知：把变量拆开

> **纯文生视频 = 让 AI 同时决定「画什么」和「怎么动」，两个变量叠加 → 不可控。**
> **关键帧驱动 = 把两个变量拆开，先搞定画面，再搞运动。**

**所以短剧必须走「图生视频」路线：**
```
① 图生成（搞定「画什么」）—— 人物/场景，可反复微调
        ↓
② 图生视频（搞定「怎么动」）—— 起始画面已固定，结果可预测
```

---

## 二、提示词公式（阿里云官方）

### ① 基础公式（新手）
```
提示词 = 主体 + 场景 + 运动
```

### ② 进阶公式（推荐）
```
提示词 = 主体（主体描述）
       + 场景（场景描述）
       + 运动（运动描述）
       + 美学控制（光源/景别/视角/镜头/运镜）
       + 风格化
```

### ③ ⭐ 图生视频公式（短剧主要用这个）
**图像已定主体/场景/风格 → 提示词只描述动态 + 运镜：**
```
提示词 = 运动 + 运镜
```
- **运动**：结合图中元素描述动态（奔跑/转头/打招呼），用形容词控速度和幅度（"快速地"/"缓慢地"）
- **运镜**：写「镜头推进/镜头左移」；不想动就写「**固定镜头**」

### ④ 声音公式（支持原生音频的模型）
```
提示词 = 主体 + 场景 + 运动 + 声音描述
声音 = 人声 + 音效 + 背景音乐
- 人声 = 内容 + 情绪 + 语调 + 语速 + 音色 + 口音
- 音效 = 音源材质 + 行为 + 环境音
- BGM = 配乐 + 风格
```

### ⑤ 多镜头公式（模型支持时）
```
提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容
```

## 三、⭐ 运镜词汇表（短剧必备）

### 基础 4 式（新手先掌握）
| 中文 | 英文 | 效果 | 用在哪 |
|---|---|---|---|
| **推**（推镜头/推近） | push-in / dolly in | 强调、情绪放大 | 情绪高潮、面部特写 |
| **拉**（拉镜头/拉远） | pull-back / dolly out | 交代环境、孤立感 | 结尾、展示处境 |
| **摇**（摇镜头） | pan（左右）/ tilt（上下） | 展示空间、扫视 | 环境介绍、跟随 |
| **移**（移镜头） | truck / tracking shot | 跟随主体 | 走路、奔跑 |

### 进阶（够用即可）
| 中文 | 英文 | 用途 |
|---|---|---|
| 环绕/弧线 | orbit / arc | 展示人物全貌、气势 |
| 升降 | crane / boom | 大场面、揭示 |
| 手持 | handheld | 真实感、紧张 |
| 甩镜 | whip pan | 转场、冲击 |
| 变焦 | zoom | 注意：**变焦≠推镜**（变焦改焦距，推镜改透视） |
| 移焦 | rack focus | 前后景切换焦点 |
| 荷兰角 | dutch angle | 不安、混乱 |

### ⚠️ 铁律
1. **不要在同一段里要求冲突的运镜**（如「固定镜头」+「环绕镜头」）
2. **不要 4-5 秒塞太多场景**（要符合物理可行性）
3. **上传多张图必须用 @ 标注用途**（哪张参考运镜、哪张参考动作）
4. **一定要写音频指导**（音效能大幅提升质量）
5. **提示词复杂度要与生成时长匹配**

## 四、保持角色一致性的提示词写法（英源验证）

**核心句模板：**
```
Animate the source image with [运动] and [细节运动].
Preserve the exact character face, hairstyle, outfit,
body proportions, and art style.
Keep the background stable and lighting consistent.
```

**要点：**
- 明确写 **「保留：脸/发型/服装/身材比例/风格」**
- 明确写 **「背景稳定 + 光线一致」**
- 运镜要**克制**（如「跟随主体，自然手持感，无剧烈晃动」）

## 五、落实到 D5 流程

| 阶段 | 提示词怎么写 |
|---|---|
| **人物图** | 用「主体描述 + 风格化」，生成三视图 |
| **分镜图** | 用「主体 + 场景 + 美学控制」，定构图 |
| **图生视频** | 只写「**运动 + 运镜 + 保留角色**」 |
| **台词镜头** | 加「声音描述」（人声+情绪+语调） |
