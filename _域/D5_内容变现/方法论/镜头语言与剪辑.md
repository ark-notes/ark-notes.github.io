# 镜头语言与剪辑 · AI 短剧

> 来源：塔猴平台 / 知乎 Seedance / 復源7
> 抓取日：2026-10-03
> 用途：**D5 制作层** —— 把文字剧本变成视觉语言

---

## 一、分镜表（镜头级拆解）

**一支 1-2 分钟短剧 ≈ 8-15 个分镜。**

**每个分镜必须写清 5 件事：**

| # | 项 | 选项 |
|---|---|---|
| 1 | **景别** | 远景 / 全景 / 中景 / 近景 / 特写 |
| 2 | **视角** | 平视 / 俯视 / 仰视 |
| 3 | **运镜** | 固定 / 推 / 拉 / 摇 / 移 / 跟 |
| 4 | **角色动作 + 情绪** | 具体动作 |
| 5 | **场景环境** | 在哪、什么气氛 |
| 6 | **预估时长** | 秒数 |

---

## 二、⭐ 景别怎么用

| 景别 | 拍到哪 | 用来干嘛 |
|---|---|---|
| **远景** | 环境为主，人很小 | 交代地点、开场 |
| **全景** | 人物全身 + 环境 | 介绍人物、动作 |
| **中景** | 人物大半身 | **对话最合适** |
| **近景** | 胸部以上 | 情绪、表情 |
| **特写** | 脸/眼睛/手/物件 | **情绪爆点、关键道具** |

**⭐ 常用的起手节奏：**
```
远景起 → 慢慢推进到近景 → 最后落到特写
```
> 这样「镜头就有层次感和呼吸感」，而不是平铺。

---

## 三、⭐ 节奏铁律（塔猴验证）

| # | 规则 |
|---|---|
| **1** | **5-10 秒一个镜头** |
| **2** | **每 3-5 个镜头一个小反转** |
| **3** | **全程不留气口**（不让观众有机会划走） |
| **4** | 单集正片 **约 1 分钟**（首集 2 分钟引流） |
| **5** | 每段 **1-2 句台词为宜** |

---

## 四、⭐ 角色卡片（防跳戏的核心工具）

**问题**：每个镜头提示词凭感觉临时改写 → 人脸漂移。

**解法**：建**角色卡片**，**每个镜头开头粘贴完全相同的描述段落**。

**模板示例：**
```
角色 C01：25 岁亚洲女性，鹅蛋脸，杏仁眼，
右眼下方浅色小痣，黑色齐肩直发，三七侧分，
银色圆形耳环。
```
> 每个镜头提示词**开头原样粘贴**，不许改写。

**三件事做扎实，角色就稳：**
1. **三视图**（正/侧/3-4）
2. **图生视频**（不用文生视频）
3. **提示词复用**（粘贴角色卡片）

---

## 五、情绪催化：音效与配乐

| 元素 | 作用 | 提示词怎么写 |
|---|---|---|
| **音效** | 强化动作/环境 | 音源材质 + 行为 + 环境音 |
| **BGM** | 催化情绪 | 配乐 + 风格（如「悬疑风格」） |
| **人声** | 台词 | 内容 + 情绪 + 语调 + 语速 |

**⚠️ 音效设计要求写进提示词** —— 能大幅提升输出质量。

---

## 六、剪辑要点

| # | 要点 |
|---|---|
| 1 | 复杂动作**拆成多个简单镜头**，剪辑拼接 |
| 2 | 同一场景连续镜头用**同一首帧** |
| 3 | 去水印（平台 Logo 必去） |
| 4 | 加 **AI 标识**（合规） |
| 5 | 结尾必留**钩子**（悬念/反转） |

---

## 七、完整制作流程（七步）

```
1. 剧本：定单集结构（钩子—发展—反转—收尾）+ 对白
        ↓
2. 分镜表：段号 / 画面 / 景别 / 运镜 / 时长
        ↓
3. 角色卡片：三视图 + 固定描述段落
        ↓
4. 生图：首帧分镜图（确认构图）
        ↓
5. 生视频：图生视频（运动 + 运镜 + 保留角色）
        ↓
6. 配音 + 音效 + 配乐
        ↓
7. 剪辑 + 去水印 + AI 标识 + 发布
```
