# 三视图专业公式（角色一致性核心）

> 来源：塔猴《角色不崩》/ CSDN《豆包+即梦保姆级》/ 知乎《极繁风》
> 抓取日：2026-10-04
> **用途：这是"角色不崩脸"的标准打法，我之前给的是业余版**

---

## 一、⭐ 结构化公式（4 部分）

> 「不能只靠关键词堆砌。结构化模版由四部分组成：
> **主体描述 + 视角指令 + 风格限定 + 格式排版**」

| 部分 | 内容 |
|---|---|
| **1 主体描述** | 极致的细节（脸型/五官/发型/服装/身材） |
| **2 视角指令** | 明确"三视图"、"正面/侧面/背面"、"全身" |
| **3 风格限定** | 画风（BJD/UE5/次世代） |
| **4 格式排版** | 布局（左1/3面部特写，右2/3三视图）+ 白底 |

**⚠️ 原则：**
> 「一致性，来源于**极度变态的细节控制**。」
> 「AI 没有记忆。你只写"一套漂亮的裙子"，正面画百褶裙，背面可能变包臀裙。」

---

## 二、⭐ 两种「3D 美感」（用户说"3D分很多种"）

### 🅰️ BJD 精致风（最主流）
```
顶级3D国漫画风，极具质感的BJD风格，虚幻引擎5渲染，
次世代游戏建模，极高细节的3D CG人物设定图，
电影级柔和光影，8K超高清
```

### 🅱️ 极繁国潮风
```
8K超高清，极致写实，华贵鎏金轮廓打光，
极繁主义国潮古风风格，纯白色极简纯色背景，
质感华丽厚重
```

---

## 三、⭐ 标准布局（专业写法）

> 「最左边占满 **1/3** 是超大的**面部特写**，
> 右边 **2/3** 放**正视图、侧视图、后视图**，
> 纯白背景，无任何多余元素。」

**对比业余写法：**
| ❌ 业余 | ✅ 专业 |
|---|---|
| 「三视图并排」 | **「左1/3面部特写，右2/3正/侧/背」** |
| 没说背景 | **「纯白背景，无多余元素」** |

---

## 四、⭐ 一致性约束词（必须加在末尾）

```
面部稳定清晰，人体结构正常，服装、发型、五官前后一致，
无穿模、无变形
```

---

## 五、⭐ 完整模板（可直接套）

```
[风格限定]：顶级3D国漫画风，极具质感的BJD风格，
虚幻引擎5渲染，次世代游戏建模，极高细节，8K超高清。
[格式排版]：角色设定图，最左侧1/3为超大面部特写，
右侧2/3依次为正面全身、侧面全身、背面全身，人物大小一致。
纯白背景，无任何多余元素，全身完整入镜。
[主体描述]：（填：年龄性别+脸型+五官+发型+身材+服装+配饰）
[视角/姿态]：自然站姿，光线均匀。
[约束]：面部稳定清晰，人体结构正常，五官/发型/服装前后一致，
无穿模、无变形。
```
