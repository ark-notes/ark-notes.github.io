# AI 短剧制作 · 中文源实操要点（2026）

> 来源：塔猴平台 / 550W AI / 博客园 / AIGC-Sora
> 抓取日：2026-10-03

## 一、2026 的定位转变（塔猴）

> **AI 短剧的制作本质，已从「工具操作」升级为「内容工业管理」。**
> 不再是「写一段提示词等生成」的粗放阶段。

**成熟路径 = 10 步：**
```
立项策划 → 剧本工程化 → 角色/场景资产库 →
分镜脚本 → 镜头级生成 → 配音音效 →
后期合成 → 质检 → 发行 → 数据复盘迭代
```

## 二、🔴 角色一致性（最大的坑）

**问题**：同一个角色，上一镜长这样，下一镜换人了 → 差评。

**解法（必须生成前就锁死）：**

| 步骤 | 做法 |
|---|---|
| 1 | 用 **GPT Image / 即梦** 生成角色**三视图**：正面 / 侧面 / 3/4 侧 |
| 2 | 补**多角度参考图**：正面 + 侧面 + 背面 + 面部特写 |
| 3 | 用 **「图生视频」模式**（不是文生视频）——以定妆照为参考图 |

## 三、🔴 水印（必做环节，我原先不知道）

> AI 生成的视频**通常自带平台水印**（可灵 Logo / 即梦水印等）。
> **必须去除后才能用于正式发布。** 这是不可跳过的环节。

## 四、镜头级生成技巧（博客园 / 550W AI）

| # | 技巧 |
|---|---|
| 1 | 选功能 → 选模型（如视频 3.0，按内容挑最合适的） |
| 2 | 上传**首帧分镜图**，贴入「图生视频提示词」 |
| 3 | 加**负面提示词**：毁容 / 面部扭曲 / 肢体变形 |
| 4 | 每个镜头**多生成 2-3 版**，挑最佳 |
| 5 | **复杂动作拆成多个简单镜头**，后期剪辑拼接 |
| 6 | 负面提示词不能 100% 避免问题，只能降低概率 |

## 五、对我剧本的修正建议

| 我之前写的 | 应按此法补 |
|---|---|
| 「锁定人物」 | → 明确**三视图 + 多角度参考图** |
| 没提水印 | → 加**去水印**为必做步骤 |
| 「图生视频」 | → 补 **首帧分镜图 + 负面提示词** |
| 未提资产库 | → 建**角色/场景资产库**（复用降本） |
