## ⭐ 核心认知（我的错误）

> 「很多人写提示词最大误区：**只写剧情，忽略镜头、画质、画风、约束条件。**
> AI 本质是按文字描述还原画面，**描述越结构化，成品可控性越高。**」

**我之前：写"人物+美化" → 缺镜头/画质/约束 → 所以效果差。**

## 一、⭐ 六大模块（标准结构）

```
① 主体（人物外貌/服饰/表情/动作）
② 场景环境
③ 镜头视角（景别/机位/运镜）
④ 画风（风格/色彩/光影）
⑤ 制式与画质（比例/清晰度/渲染）
⑥ 约束条件（负面提示词）★ 我最缺的
```

**另一版表述（动态向）：**
```
主体 + 动作 + 表情 + 场景 + 运镜/景别 + 风格 + 画质
```

## 二、⭐ 负面提示词（关键武器）

### 为什么重要
> 「黄金法则：善用'负面提示词'」

### 基础负面词（固定加）
```
画质差、模糊、水印、多余肢体、丑陋、文字、
畸形手指、多余手指、肢体扭曲、穿模、
塑料感皮肤、过度磨皮、网红脸、低清晰度、噪点
```

### ⚠️ 正确用法（重要）
> 「网上很多人给几百个负面词大合集，**直接照搬反而导致画面平淡、细节丢失。**
> 正确用法：**基础负面词固定**（模糊、畸形、水印），
> **只在遇到具体问题时，补充对应的负面词。**」

**→ 不要无脑堆砌，要针对性。**

## 三、⭐ 风格词分类（写实向）

| 类型 | 英文关键词 |
|---|---|
| **写实系** | photorealistic, realistic, photograph |
| 插画风 | illustration, painting, paintbrush |
| 二次元 | anime, comic, game CG |

**→ 要写实，必须明确写「photorealistic / 真实照片级」。**

## 四、⭐ 权重控制

| 工具 | 语法 |
|---|---|
| Midjourney | `关键词::权重倍数`（如 `25岁女特工::2`） |
| SD/通用 | `(关键词:1.5)` 括号+数字 |
| 通用理解 | **词越靠前，权重越高** |

**→ 重要的词放前面。**

## 六、⭐ 表情细化（加分项）

> 「表情提示词不是只写'开心、难过、愤怒'。
> 真正有用的写法：把**眼神、眉毛、嘴角、身体**写细。」

| 笼统 | 细化 |
|---|---|
| 开心 | 眼角弯起，嘴角上扬，眼睛有光 |
| 愤怒 | 眉头紧锁，眼神凌厉，下颌绷紧 |
| 冷漠 | 眼神平静无波，嘴角微压，面无表情 |

**示例：**「眼神闪过狠厉」「嘴角勾起冷笑」「瞳孔微微收缩」

## 七、⚠️ 避坑

| 坑 | 说明 |
|---|---|
| ❌ 静态/矛盾指令 | 不要写"站着举手"、"既慢又快" |
| ❌ 只写剧情 | 忽略镜头/画质/风格/约束 |
| ❌ 负面词堆砌 | 照搬几百个 → 画面平淡 |
| ✅ 正确 | 结构化六模块 + 针对性负面词 |
