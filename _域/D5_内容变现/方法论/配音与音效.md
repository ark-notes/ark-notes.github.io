## 二、工具选型（2026 横评）

| 工具 | 优势 | 适合 |
|---|---|---|
| **AnyVoice 2.0** | **情绪精准调控**（参数级 + 参考情绪音频，情绪与音色解耦） | **短剧首选** |
| **MiniMax** | 情绪表现强，可控性中等 | 通用 |
| **豆包语音 2.0**（字节） | 指令式情感（"急切而发颤"/"生气吵架"），低延迟流式 | 剧情配音 |
| **讯飞译制** | 高情感克隆，跨语言语速均匀化 | **短剧出海** |
| **趣丸千音** | MaskGCT 模型，多语种 + 声音克隆 | 一站式 |
| **黑狐配音** | 音频分离 + 配音一体，一键提取原声替换 | **都市爽剧/情感剧** |
| **百宝音** | 声音克隆，多设备 | 短剧 + 小说推文 |

**⚠️ 选型看三点：① 情绪可控性 ② 声音克隆 ③ 批量能力。**

## 三、⭐ 声音提示词公式（配合 AI 视频原生音频）

```
人声 = 角色说话的内容 + 情绪 + 语调 + 语速 + 音色 + 口音
```

**示例：**
```
一个男人在讲脱口秀，他说道："好好学习，天天向上"，
语气轻松，语速适中，声音清亮，美式英文。
```

**音效 = 音源材质 + 行为 + 环境音**
```
一个玻璃小球从桌面掉在木质地面上，
发出"砰"的声音，室内安静环境。
```

**BGM = 配乐 + 风格**
```
雨夜，阴森窄小的走廊，尽头有一扇窗户，
配有悬疑风格背景音乐。
```

## 四、⭐ 完整配音流程（塔猴实测）

```
① 剧本分句（每段 1-2 句台词）
        ↓
② 选音色（每角色一个，锁死）
        ↓
③ 逐句合成（调情绪/语速/语调）
        ↓
④ 试听 → 不满意重合成
        ↓
⑤ 与画面卡点对齐
        ↓
⑥ 混音（人声 + 音效 + BGM，控制音量平衡）
```

## 五、对 D5 的落地

| # | 要求 |
|---|---|
| **1** | **每角色锁一个音色**（像锁人脸一样） |
| **2** | **情绪要标进台词**（不只写内容，要写"愤怒/颤抖/冷笑"） |
| **3** | **关键节点配音效**（打脸/开门/耳光 → 强化爽感） |
| **4** | **BGM 服务情绪曲线**（松紧交替，见 `rhythm-curve.md`） |
| **5** | **合规：音频也要检**（口播风险常藏在这） |
