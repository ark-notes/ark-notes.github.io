# 模拟演练（自主实战训练）

> 用户要求（2026-10-04）：
> 「你缺实战。能不能在学习过程中自主模拟实战环境进行演练？」
> **方法：拿真实案例当"考卷" → 我盲答 → 对答案 → 找差距**

---

## 演练机制

```
① 选一个真实失败案例
② 遮住"正确答案"
③ 我自己推演"最优应对"
④ 对照真实答案
⑤ 差异 → 学到什么 → 记入能力档案
```

---

## 演练 1：定妆照阴影问题

**考卷**：用「女主捂嘴笑」当锚点 → 后续所有镜头有莫名阴影

**我盲答（不看得出的答案）**：
```
我猜原因：
① 表情夸张 → AI 无法确定"中性脸" → 各镜头自己补脸
② 角度偏 → 侧脸信息不全 → 正面镜头只能"猜"
③ 光线复杂 → AI 把光影当"特征"记下来 → 到处复现

我的对策：
→ 换正脸无遮挡图
→ 或：用多张不同角度图，让 AI 提取"共同特征"
```

**真实答案**：
> 「定妆照带明显角度、夸张表情、复杂光影 → 特征不稳定。
> 换成**正脸无遮挡、光线干净的三视图** → 问题消失。」

**对比结果**：
| 我猜的 | 答案 | 对错 |
|---|---|---|
| 表情夸张 ✓ | 对 | ✅ |
| 角度偏 ✓ | 对 | ✅ |
| 光线复杂→被当特征 ✓ | 对 | ✅ |
| **对策：换正脸干净图** | **对** | ✅ |

**评分：4/4 全中** ✅

## 演练 2：角色崩掉的原因

**考卷**：某镜头角色彻底崩

**我盲答**：
```
可能原因：
① 锚点与外貌描述冲突（跨镜头不一致）
② 分辨率太低
③ 提示词有矛盾
④ 换了模型

对策：检查锚点一致性，统一描述
```

**真实答案**：
> 锚点写「黑齐刘海」，镜头写「金色长发」→ 认知冲突。

**评分**：猜中核心原因（①）✅ 但不够具体（没意识到是"锚点 vs 镜头"的冲突）

**差距**：我理解为"跨镜头不一致"，实际是"**锚点与单镜提示词冲突**"。
