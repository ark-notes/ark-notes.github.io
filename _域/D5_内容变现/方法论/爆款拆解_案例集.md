## 案例 1：《万妖图录传》（红果漫剧顶流）

**数据**：第十二季，累计 **60亿+**，热度峰值破 **1.3亿**

### 第1层：一句话概括
```
乱世妖魔横行，主角靠特殊能力一路变强、守护同伴的故事。
```

### 第2层：阶段任务
| 阶段 | 核心任务 |
|---|---|
| 前期 | 建立世界观 + 主角能力觉醒 |
| 中期 | 能力升级 + 敌人升级 + 同伴集结 |
| 后期 | 终极对决 + 真相揭示 |

### 第3层：成功要素（观众评价拆解）
| # | 要素 | 说明 |
|---|---|---|
| **1** | **一直爽，不拖沓** | 「不虐不恋爱脑」 |
| **2** | **特效打斗精彩** | 「几乎没有穿帮」 |
| **3** | **配乐好** | 「其他剧垃圾配乐，它不」 |
| **4** | **多季连载** | 稳定输出，养成追更习惯 |

**⚠️ 关键教训：**
> 「开篇埋钩子是**大部分漫剧都会搞的**」← 不是差异点
> **真正的差异：一直爽 + 特效 + 配乐**

## 案例 2：《发配边关，罪妻开荒养出战神》

**数据**：第九季，累计 **40-41亿**，抖音 **34亿**

### 第1层：一句话概括
```
末世专家穿越成边关罪奴，靠现代知识开荒种地，
养出战神丈夫，一步步经营出自己天地的故事。
```

### 第2层：结构特点
```
融合：种田 + 穿越 + 异能 + 逆袭 + 架空 + 权谋 + 战争
```

### 第3层：成功公式
| # | 要素 |
|---|---|
| **1** | **大女主种田**：「专注搞钱搞事业」 |
| **2** | **不内耗不宅斗**：「连婆婆都开明」 |
| **3** | **经营成就感**：「模拟经营式治愈爽剧」 |
| **4** | **多季连载**：每季 5500-6500万（**稳定**） |

**⚠️ 关键教训：**
> 「被网友形容为**拍不出的纯粹种田剧**」
> **→ 差异化在"纯种田"（别人加宅斗，它不加）**

## 案例 4：《我在末世开超市，S级诡异抢着来上班》

**数据**：开播即爆，热度榜第一（5331万）

### 第1层
```
末世开超市，诡异来打工——用"经营"反套路"末世恐怖"。
```

### 第2层：差异化
```
别人写"末世求生存"（苦）
它写"末世开超市"（轻松经营 + 诡异喜剧）
```

### 第3层：教训
> **「精品也能量产」** —— 它引爆了 AI 漫剧"精品时代"
> **差异化设定（超市+诡异）** 是关键

## ⭐ 拆解出的「单集模板」（可直接套）

### 黄金时间节点（听花岛）
```
3 秒   → 勾住观众
6 秒   → 进入冲突
10 秒  → 点出悬念
1 分钟 → 强化爽感（上瘾）
3 分钟 → 完整剧情
```

### 单集结构（通用）
```
开篇：冲突直接拉满（不存在慢开场）
中段：三集一次小反转爽点 / 五集一次大型高潮
结尾：卡在情绪最高点，戛然而止，黑屏收尾
      → 钩子力度 > 本集所有冲突
```

### 全剧节奏（分段）
```
开篇 1-5 集：极速铺世界观 + 立主角人设 + 抛主线大矛盾
            → 第 3 集安排小爆点（留住第一批观众）
中段：三集一小反转 / 五集一大高潮（爽虐交替）
最后：卡在最高点收尾
```

### 反转频率（妙笔生花）
```
每 5-10 集 → 一个小反转（身份/关系/态度）
每 20-30 集 → 一个大反转
```
