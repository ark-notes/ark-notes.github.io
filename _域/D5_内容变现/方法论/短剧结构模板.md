# 短剧结构模板（专业版 · 可直接套）

> 来源：妙笔生花 / 海螺社 / 知乎创作规范 / 搜狐钩子方法论
> 抓取日：2026-10-04

---

## 一、⭐ 单集结构（2 分钟标准版）

```
0:00-0:10  上集回顾（2秒闪回）+ 开场钩子
0:10-0:30  新场景展开
0:30-1:20  本集核心事件
1:20-1:50  反转或高潮
1:50-2:00  钩子（下集预告）
```

---

## 二、⭐ 双层钩子（必须都有）

| 层 | 位置 | 作用 |
|---|---|---|
| **集内钩子** | 开场 5 秒 | 用冲突/反常画面把人**摁住** |
| **集间钩子** | 结尾 5-10 秒 | **情绪最高/最意外处切断**，抛新悬念 |

> 「设计集尾钩子时，永远在情绪最高点切断。」

---

## 三、⭐ 开篇必用「极致冲突前置法」

> 「把全剧**最炸的反转、最虐的场面、最爽的打脸**
> 放在第 1 集开头。」

**范例：**
```
「新婚夜，妻子亲手把我推进手术室……」
「离婚宴上，前夫当众撕碎我的孕检单……」
```

---

## 四、⭐ 反转层次

| 频率 | 类型 | 作用 |
|---|---|---|
| 每 **5-10 集** | 小反转 | 推动剧情 |
| 每 **20-30 集** | 大反转 | 改变格局 |

**⚠️ 全剧最多 2-3 个核心大反转。**

---

## 五、⭐ 钩子设计方法论（拆3部剧）

> 「拿爆款短剧的剧本，**逐集分析每集结尾用了什么类型的钩子**——
> 是反问句、是事件打断、还是信息反转。
> **拆够三部剧，对钩子的类型就有感觉了。**」

**练习法：**
```
给一个场景 → 设计三种不同的钩子结尾 → 对比效果
```

---

## 六、⭐ 分场格式（导演/演员用）

```
场景标头（地点/时间/气氛）
出场人物
动作描述
对白
镜头建议
```

> 「短剧的分场格式已足够导演和摄影师使用。
> 除非有特殊效果镜头。」

---

## 七、⭐ 前三集铁律（综合）

| 集 | 任务 |
|---|---|
| **第1集** | 极致冲突前置 + 立主角 + 抛核心悬念 |
| **第2集** | 展开世界观 + 增强冲突 |
| **第3集** | **安排一次小爆点**（留住第一批观众） |

> 「开篇 1-5 集：极速铺世界观、立牢主角人设、抛主线大矛盾。」
