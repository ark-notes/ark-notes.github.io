## 三、⭐⭐ 十大爆款题材（含数据 + 公式）

### 1️⃣ 年代重生种田求生流（**抖音底盘最稳**）
- **数据**：《重回八零赶海》《重回八零赶山狩猎养妻女》**单剧 3.5 亿+**
- **受众**：下沉宝妈 + 中老年，庞大
- **公式**：**聚焦 70/80 年代囤货、赶海、赶山、手艺创业**
- **核心**：「真实生存感 + 踏实致富」，**减少无脑打脸桥段**

### 2️⃣ 古风种田边关逆袭流（**性价比最高**）
- **数据**：《发配边关，罪妻开荒养出战神》**近 40-41 亿**，第九季
- **公式**：**穿越/重生 + 边关或荒地基建 + 养家糊口 + 逐步逆袭**
- **卖点**：满足观众「经营成就感」，**适合超长季连载**

### 3️⃣ 玄幻仙侠 + 种田逆袭
- **数据**：《万妖图录传》全系列累计 **60 亿**，连载第八季
- **卖点**：世界观完整，打斗特效 AI 渲染成熟

### 4️⃣ 女频都市逆袭（真千金回归）
- **卖点**：节奏快、冲突强，精准踩女性观众爽点

### 5️⃣ 萌宝题材
- **数据**：《超团宠四岁半，我的铁汉爹爹们》登顶 DataEye 榜
- **卖点**：治愈系

### 6️⃣ 家庭伦理亲情守护流（**快手第一生态**）
- **数据**：快手热播 TOP10 中 **6 席**是家庭伦理
- **例**：《虎妈驾到》20 亿播放 / 31 亿话题
- **卖点**：代际冲突 + 亲情和解 → **最贴政策导向**

## 四、⭐ 选题公式（可直接套）

```
公式 A（年代种田）：
  重生/穿越 + 70-80年代 + 赶山/赶海/囤货/手艺
  + 养家糊口 + 踏实致富

公式 B（古风边关）：
  穿越/重生 + 边关或荒地 + 基建/开荒
  + 养家 + 逐步逆袭 + 权谋/战争
```

**⚠️ 共同点：**
1. **真实生存感**（不要悬浮）
2. **踏实致富**（不要一夜暴富）
3. **经营成就感**（观众代入「经营」）

## 五、⭐ 选题流程（提效录）

```
Step 1（30分钟）：打开红果/抖音榜单
   → 按「播放量 TOP100」分类统计题材频率
        ↓
Step 2：锁定前 3 个题材
        ↓
Step 3：生成 100 个选题 → 挑 20 个最有冲击力的备用
        ↓
Step 4：灵魂是「代入感」—— 观众 3 秒内能代入主角
```
