# 一、⭐ 核心公式（必记）

## 1.1 短剧提示词总公式
```
[主体描述] + [动作/表情] + [场景环境] + [景别角度] + [光影色调] + [风格关键词] + [质量参数]
```

## 1.2 剧本结构公式（爆款）
```
浓缩黄金开头 + 极致情绪反转 + 高频爆点铺设 + 硬核剧情钩子
```

## 1.3 单集结构（铁律）
```
第一集就开炸：如"婚礼当天，新娘逃婚，女主顶替出场"
每集一个爽点：打脸、逆转、升级、恋爱拉扯
每集结尾留钩子：如"你不是我老婆？那你是谁？"
每集500字左右，台词短有力，2人对话为主，避免独白
```

# 二、⭐⭐ 剧本生成提示词（第1步）

## 模板A：从零生成剧本
```
请写一部3分钟以内的重生逆袭类短剧剧本，格式如下：

【剧名】：（3-5个字，带钩子）
【题材】：重生/逆袭/打脸
【核心爽点】：一句话说清楚"观众为什么会爽"
【人物】：
- 主角：[姓名]，[年龄]，[核心身份]，[性格标签]，[重生前困境]
- 反派：[姓名]，[年龄]，[核心身份]，[性格标签]
【剧本正文】：
场景一：[地点][时间]
（画面描述：谁在哪儿、在做什么、情绪状态）
[角色名]：[台词]
【分镜要求】：
- 全剧控制在15-25个镜头
- 每个镜头时长[X]秒
```

## 模板B：网文改剧本（Role 版）⭐
```
【Role】
你是一个资深的爆款短剧导演，
擅长将冗长的网文小说改造成快节奏、高钩子的短剧脚本。

【Task】
我将为你提供一段小说原文，请你严格按以下步骤执行：

【核心提取】
总结这段内容中最重要的 3 个冲突点，
并确定本集结尾的"卡点"悬念。

【分镜输出】
将内容转化为 5-8 个镜头，输出格式为表格。

【Output Format（表格）】
镜号 | 景别 | 画面描述（含人物动作/神态/环境） | 台词/独白 | 背景音/音效

【Constraints】
语言风格：台词口语化，去掉书面语
节奏控制：平均每10秒一个画面切换，突出情绪特写
禁止废话：略过心理描写，全部转化为可拍摄的动作

[此处粘贴网文]
```

# 三、⭐⭐ 分镜拆解提示词（第2步）

## 模板C：剧本 → 分镜表（专业版）
```
请将第1集展开为详细的分镜脚本，格式如下：

【镜头1】
- 时长：5秒
- 景别：近景/中景/远景/特写
- 场景：具体环境描述（光线、天气、时间）
- 人物：外貌+服装+表情+动作
- 镜头运动：推/拉/摇/移/固定
- AI视频提示词（英文）：[可直接用于可灵/Sora]
- 对话/旁白：[如有]
- 音效/BGM：[氛围描述]

要求：
- 每个镜头 3-8 秒（AI视频最佳时长）
- 每个镜头只有一个主要动作
- 人物描述保持一致（每次都完整描述外貌）
- 避免复杂的多人互动场景
- 必须检查每个镜头时长，超过10秒立即拆分
```

## 模板D：分镜（横屏排版版）
```
Role：你是一名电影分镜设计师 + AI绘图提示词工程师
Think like a film director and storyboard artist.

任务：根据角色设计图和分镜脚本，
为每个镜头生成 Banana Pro 中文生图提示词。

核心规则（必须严格遵守）：
1. 每个镜头画面必须为 16:9 横屏比例
2. 分镜画面之间必须紧挨排列
3. 分镜之间不得出现任何边框、白边或分隔线
4. 每个镜头必须独立生成一条生图提示词
5. 如果镜头中出现角色，必须加入[角色一致性描述]
```

# 四、⭐ 画面生成提示词（第3步）

## 模板E：画面提示词公式
```
[主体描述] + [动作/表情] + [场景环境] + [景别角度] 
+ [光影色调] + [风格关键词] + [质量参数]

示例：
年轻亚洲女性（25岁，齐肩黑发，白色衬衫）+
缓缓转头，眼神坚定 + 1980年代农村土屋，煤油灯 +
中景，平视 + 昏黄暖光，侧光 + 写实3D国风 + 8K超高清
```

## 模板F：图生视频（关键）
```
[运动] + [运镜] + [保留角色描述]

示例：
女孩缓缓抬起头，眼神从茫然转为坚定。
镜头缓慢推近。
保持人物的长相、发型、服装完全一致。
```

# 五、⭐ 分镜资产库（提效关键）

## 5.1 必建三库
```
① 角色模板（三视图 + 面部特写）
② 场景素材
③ 有效提示词模板
→ 提升后续制作效率
```

## 5.2 分镜表标准结构
```
镜号 | 景别 | 画面描述 | 台词 | 音效 | 时长 | 运镜
```

## 5.3 运镜标注规则（专业）
```
· 镜头景深标注"浅景深，背景柔化"（情感特写可选）
· 同一机位连续出现可省略重复运动描述
· 微调类运镜 → 情感细腻场景（不用于动作场面）
· 跟拍类运镜 → 标注跟拍对象和距离
· 身体部位特写 → 明确标注部位名称
· 沉默对白 → 用"……"，长沉默标"（沉默X秒）"
```

# 七、⭐ 完整流程（四阶段）

```
① 剧本生成（模板A/B）
      ↓
② 分镜拆解（模板C/D）
      ↓
③ 画面生成（模板E）
      ↓
④ 图生视频（模板F）
```

**⚠️ 关键：**
```
· 每个阶段产出都要"可审校"

· 时长控制 3-8 秒
```

# 八、⭐⭐ 角色一致性（高级 · 四层叠加法）

> 来源：CSDN 实战（2026）
> ⭐ 单靠任何一层都不够，**四层叠加才稳**

```
① 提示词写清特征（Character Token，每次生图都带上）
② 角色 LoRA 固化形象
③ ControlNet 控制姿态
④ 局部重绘修正细节
```

## 8.1 关键规则

| # | 规则 |
|---|---|
| **1** | **建立固定角色提示词（Character Token）**，每次生图都带 |
| **2** | **多角色对话**：切忌在同一提示词内让AI同时解析两个面孔 |
| **3** | 多角色 → 用**"正反打分镜"**分别锁定生成，再剪辑拼接 |
| **4** | 角色外貌、服饰**严格遵循人设，不擅自改动** |
| **5** | 提示词分层：**主体 + 细节 + 风格 + 负面词** |

## 8.2 多角色对话的正确做法
```
❌ 错误：一张图里让AI画"两个人在说话"
✅ 正确：正打镜头（A说话）→ 反打镜头（B说话）→ 剪辑拼接
```
