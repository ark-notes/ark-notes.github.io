# AI 微短剧制作 · 英文源要点（2026）

> 来源：invideo.io / plotparty.ai / pixazo.ai / reddit r/aifilmmaking
> 抓取日：2026-10-03

## 一、核心观念（三个源都强调）

> **"不要把它当提示词，要当一部真正的制作（production）来做。"**
> — r/aifilmmaking《How to Make an AI Micro-Drama in 2026》

**过去两年，AI 视频从「实验性片段」→「可行制作管线」。**
以前要几十个画师/动画师/剪辑/配音，现在**小团队 + 正确工作流**就能做。

**但很多人误解 AI 视频能做什么、不能做什么。**

## 二、Agent 流水线（invideo.io 提出）

```
完整剧本
  ↓ 编剧 Agent
拆成每集的分镜清单（shot list）
  ↓ 分镜 Agent（storyboard）
每个镜头路由给对的视频模型
  ↓ 摄影 Agent（DOP）
把镜头拼接、延长、以悬念收尾
```

**要点：这是「单次顺序管线」（single sequential pass）。**

## 三、新手规格（plotparty.ai）

| 项 | 建议 |
|---|---|
| 场景数 | **5-8 场**（够放钩子+冲突+升级+结尾） |
| 观看场景 | 手机竖屏、快节奏 |
| 必备三件套 | **强钩子 / 情绪转折 / 悬念收尾** |
| 单人可做 | ✅ 写/分镜/生成/剪辑/发布 一人完成 |

| 形态 | **竖屏（vertical）** |
