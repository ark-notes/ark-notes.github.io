# 3D 漫剧制作工作流（2026 实测）

> 来源：知乎实测 / CSDN / 飞书 / 塔猴
> 抓取日：2026-10-04
> 用途：**D5 制作主线** —— 从剧本到成片

---

## 一、⭐ 核心认知

> 「AI 漫剧把成本压到传统短剧的 **1/10**，
> **一个人 + AI 工具就能日产一部剧**。」
> 「一个人就能撑起一个剧组。」

**⚠️ 但核心痛点只有一个：**
> 「**角色一致性是漫剧的核心痛点，
> 一定要用同一个模型生成，不要混用。**」

---

## 二、⭐ 完整工作流（9 步）

```
① 选题 → ② 剧本 → ③ 角色设定
        ↓
④ 分镜脚本 → ⑤ 分镜图（静帧）
        ↓
⑥ 图生视频 → ⑦ 配音 + 对口型
        ↓
⑧ 剪辑 → ⑨ 发布
```

**每步的产出：**
| 步 | 产出 | 谁做 |
|---|---|---|
| ① 选题 | 题材 + 剧名 | AI + 人 |
| ② 剧本 | 分集剧本 | ⭐ 我做 |
| ③ 角色设定 | 三视图 + 角色卡 | AI |
| ④ 分镜脚本 | 镜头表 | ⭐ 我做 |
| ⑤ 分镜图 | 静帧画面 | AI 生成 |
| ⑥ 图生视频 | 动态片段 | AI |
| ⑦ 配音 | 人声 + 音效 | AI |
| ⑧ 剪辑 | 成片 | 剪映等 |
| ⑨ 发布 | 上线 | 人 |

---

## 三、⭐ 工具链（两套方案）

### 方案 A：一站式平台（新手友好）
| 工具 | 特点 |
|---|---|
| **有戏AI** | 全流程自动化，**角色相似度 95%+**，邀请制 |
| 纳米漫剧流水线 | 支持 30 分钟超长视频 |
| 剧灵绘 | 输入梗概 → 自动分镜 → 视频 |
| 一批新平台 | 「一人即剧组」 |

**优点：** 省事，角色一致性有保障
**缺点：** 可能收费/邀请制/风格受限

### 方案 B：组合工具（可控性强）
```
豆包  → 写分场剧本
即梦  → 控图生成（分镜图）
可灵  → 图生视频
剪映  → 剪辑 + 配音 + 对口型
```

**优点：** 可控、免费（部分）
**缺点：** 环节多，要自己串

---

## 四、⚠️ 铁律（实测踩坑）

| # | 铁律 |
|---|---|
| **1** | **角色一致性：必须用同一个模型，不要混用** |
| **2** | 分镜图先确认满意，再图生视频 |
| **3** | 用「图生视频」，不用「文生视频」 |
| **4** | 配音 + 对口型（漫剧必需） |
| **5** | 去水印 + 加 AI 标识 + 备案 |

---

## 五、⭐ 对 D5 的建议

**先试「方案 A 一站式」**（如果可用），因为：
```
① 省去串流程的麻烦
② 角色一致性有保障（95%+）
③ 适合"先跑通，再优化"
```

**如果一站式不行 → 用方案 B（组合工具）。**

**⚠️ 但记住：不管哪套方案，剧本和分镜都是我做（这是我创造价值的地方）。**
