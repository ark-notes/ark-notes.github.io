# 视频测试 01 · 阿奇AI 图生视频

> 测试日：2026-10-04
> 目的：验证阿奇AI生成视频的能力（能否撑短剧）

---

## 一、测试设置

| 项 | 值 |
|---|---|
| 工具 | Arkie 视频（阿奇AI） |
| 输入 | **三视图**（一张图3个角度）❌ 错 |
| 分辨率 | 720p |
| 时长 | 6s |
| 消耗 | **1次**（99→98） |
| 指令 | 「让人物缓缓抬起头，保持长相五官发型服装一致，镜头缓慢推近」 |

---

## 二、结果

| 秒 | 内容 | 评价 |
|---|---|---|
| 0s | **三视图**（3视角挤一屏） | 🔴 **错**（阿奇把三视图当内容） |
| 3s | 抬头动作，脸清晰 | ✅ 好 |
| 6s | 黑屏→ARKIE吉祥物 | ⚠️ 过渡 |
| 8s | ARKIE标志+「本视频由阿奇AI生成」 | ⚠️ 自动片尾 |

---

## 三、⭐ 发现

### 发现1：**输入素材错了**
```
❌ 三视图（3视角）→ 阿奇以为你要展示三视图
✅ 应传：单张人物图（只有1个人）
```

### 发现2：**单人物时脸没崩**（3秒处结构清晰）
```
→ 说明阿奇视频能力【可用】
→ 前提：喂对素材
```

### 发现3：**阿奇自动加片尾**
```
最后有"本视频由阿奇AI生成"+LOGO
→ 短剧用可能要剪掉
```

### 发现4：**消耗 1 次**
```
99 → 98
⚠️ 需确认：99次是"每天"还是"总共"
```

---

## 四、结论

```
✅ 阿奇视频【能用】（脸没崩）
⚠️ 但要修正：
   ① 传单张图（不是三视图）
   ② 片尾要去掉
❓ 99次机制待确认
```

## 五、下一步
```
重测：用单张人物图 → 生成 → 看效果
```
