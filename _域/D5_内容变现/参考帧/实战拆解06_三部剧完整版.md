## 三、⭐⭐ 核心规律（累计5部剧总结）

### 规律1：**差异化人设 = 爆点**
```
E：三岁小孩重生（反套路）
C：疯批兄妹（极端人设）
→ 都是"不普通"的人设
```

### 规律2：观众会"赌爆款"
```
「我预感这部剧能爆，留痕等火了回我」
→ 好剧有"感觉很对"的特质
```

### 规律3：宠物/萌点是标配加分
```
（前几部）「毛茸茸」「大德牧真好」
```

### 规律4：标题公式固定
```
[灾害/时代] + [主角+反套路动作] + [爽点]
· 重回天灾前，葡萄搬空全球
· 末日来临：囤货癖的她又赢麻啦
· 天灾末世，她囤满物资后所向披靡
```
