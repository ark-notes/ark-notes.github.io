## 四、⭐⭐ 重大发现

### 发现1：「重生+空间+系统」= 观众心中的标配
```
弹幕直接说"对味了""还有系统"
→ 观众期待这个组合
→ ⚠️ 但也是同质化信号（大家都做）
```

### 发现2：宠物/萌点 = 差异化加分
```
「毛茸茸」「大德牧真好」
→ 观众对宠物角色好感强
→ 建议：加宠物元素（区分度）
```

### 发现3：⚠️ 主角名字要早交代、多重复
```
观众弹幕问「男主叫夏天」
→ 说明没记住/没看到
→ 教训：名字第1集就点明，且重复出现
```
