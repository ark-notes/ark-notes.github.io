# 视频测试 02 · 视觉比对（数字化）

> 测试日：2026-10-04
> ⭐ 用【工具】补我的"视觉弱"

---

## 一、问题
用户："两个视频里的人物都是三视图建模的样子（被污染）"
我："看不出区别" ← 我的视觉弱

## 二、解法：用人脸识别算相似度

### 结果
| 对比 | 相似度 | 判断 |
|---|---|---|
| 参考图 vs 视频1 | **0.207** | ❌ 不同人 |
| 参考图 vs 视频2 | **0.188** | ❌ 不同人 |
| 视频1 vs 视频2 | **0.828** | ✅ 同一人 |

### 结论
```
① 视频1、视频2 = 同一个人
② 但都【不是】参考图的人
→ 阿奇生成的脸【跑偏了】= 用户说的"污染"被证实
```

## 三、工具（已建）

