# 视频测试 04 · 动作执行验证

> 测试日：2026-10-04
> 目的：验证阿奇视频的动作/表情执行能力

---

## 一、设置
| 项 | 值 |
|---|---|
| 会话 | 新会话 |
| 输入 | 单张人物图 |
| 指令 | 抬头 → 转头向右 → 冷笑（3个动作） |
| 时长 | 10s（实际9s） |

---

## 二、结果

### 人脸（锁住）
| 时间 | 相似度 |
|---|---|
| 0秒 | **0.974** ✅ |
| 3秒 | 0.822 ✅ |
| 5秒 | 0.742 ✅ |

### 动作（部分执行）
| 指令 | 实际 | 判定 |
|---|---|---|
| 抬起头 | ✅ 头部微仰 | ✅ |
| 转头向右 | ❌ 只微侧 | ⚠️ |
| 冷笑 | 🟡 出"浅笑"非冷笑 | ⚠️ |

---

## 三、⭐ 关键发现

1. **动作会"简化"**：3个动作 → 约1.5个
2. **表情理解不准**："冷笑"→"浅笑"
3. **片尾 ARKIE 水印**仍在

---

## 四、⭐ 结论

```
✅ 锁脸：强（0.74-0.97）
✅ 简单动作：可以
⚠️ 复杂/连续动作：打折
⚠️ 表情细节：不准
⚠️ 片尾水印：要剪
```

**→ 制作原则：**
```
· 一个镜头 = 一个动作
· 别写"连续多动作"
· 表情尽量简单明确
· 剪片尾
```
