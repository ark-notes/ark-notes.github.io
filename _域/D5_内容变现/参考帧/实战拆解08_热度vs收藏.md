## 三、⭐⭐⭐ 核心发现

### 发现1：**"低热度"样本是存在的**
```
用户以为"低热度不展示"
→ 实际：1506万、1351万 都在榜单上（排名靠后）
→ ⚠️ 平台会展示，只是往后排
```

### 发现2：**热度 ≠ 收藏（重要！）**
```
《末日重生顶级堡垒》热度3091万，收藏只6690
→ 播放量高 ≠ 追更意愿高
→ ⚠️ 高播放可能是"推流买的"，非自然留存
```

**对比：**
| 剧 | 热度 | 收藏 | 收藏/热度比 |
|---|---|---|---|
| 空间末世 | 1351万 | 3.4万 | **0.025** |
| 顶级堡垒 | 3091万 | 6690 | **0.0022** |
| 古今小货郎 | — | 30.3万 | — |

**→ "收藏/热度比"才是真实质量的指标！**

### 发现3：**"小说改编"反复出现**
```
「好熟悉的名字 好像看过这个小说」
「从抖音过来的」
→ 原著粉基础 + 外部引流
```

## 四、⭐ 判定"好坏"的正确指标（修正）

| ❌ 错误 | ✅ 正确 |
|---|---|
| 只看热度 | **看"收藏/热度比"** |
| 热度高=好 | 热度高可能买量 |
| 收藏低=失败 | 需结合"上线时间" |

**三指标：**
```
① 收藏数（追更意愿）
② 收藏/热度比（真实质量）
③ 上线时间（新剧 vs 老剧）
```
