---

## 一、核心认知

```
❌ 之前死磕：画风（2D / 三渲二 / 3D写实）
✅ 真相：【妆容】才是"好看"的来源
        ↓
妆容到位 → 画风是漫剧还是写实，都好看
妆容不到位 → 画风再对，也不好看
```

## 二、🔴 男女妆容必须分开（关键教训）

**用户明确指出（#11228）：**
> 「感觉对了，但妆容有点女性化了，腮红过于粉了」

**⚠️ 我犯的错：** 男/女用同一套"脸颊红润"词 → 男主变女性化。

| 项 | 男主（男性化）| 女主 |
|---|---|---|
| **腮红** | ❌ **不要腮红、不要过粉** | ✅ 可自然红润 |
| **肤色** | 自然健康、清白 | 白皙红润 |
| **气质** | **英气硬朗** | 柔美清冷 |
| **眉眼** | 英挺剑眉、眼神锐利 | 精致柔美 |
| **唇** | 自然偏淡 | 柔美粉嫩 |
| **雷区** | **女性化妆容、粉腮红、柔弱** | — |

## 三、让图"好看"的妆容要素

| # | 要素 | 说明 |
|---|---|---|
| 1 | **高光** | 鼻尖/额头/唇部自然高光（水润感）← 最关键（阿奇旧图高光=0）|
| 2 | **眉眼** | 眉形清晰、眼妆精细、有神 |
| 3 | **唇** | 唇形清晰、唇色自然 |
| 4 | **肤质** | 白皙通透、明亮有光泽、无瑕 |
| 5 | **冷调** | 冷白皮、清透（不是暖黄、不是苍白）|

**数据支撑：** 参考图高光 0.066-0.164，阿奇旧图 0.000

## 四、可用提示词（男主 · 防女性化版）

```
保持参考图的画风与精致感。
28岁俊美男子，中国面孔，清冷成熟气质，英气硬朗。
五官精致立体，脸型流畅，眉形英挺，眼神深邃锐利有故事。
皮肤白皙通透、明亮有光泽，
鼻尖/额头/唇部有自然高光（水润感），
肤色自然健康（不要腮红、不要过粉），
眉眼英气，唇色自然偏淡。
深色中长发，分束有层次，碎发自然。
柔和唯美光影，冷调清透，画面精致高级，
人物突出，背景简洁。

负面：不是女性化妆容，不是粉腮红，不是柔弱，
不是苍白暗沉，不是无高光死板，不是过度光滑塑料感，
不是3D建模感，不是2D平涂，不是女性化脸。
```
