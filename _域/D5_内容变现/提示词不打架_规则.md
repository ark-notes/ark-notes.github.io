# 提示词"不打架"规则（解决核心问题）

> 触发：用户怀疑"提示词在打架"，我验证=确实
> 整理：2026-10-04

---

## 一、🔴 我犯的错：词互相矛盾

| 矛盾对 | 问题 |
|---|---|
| 3D vs 无勾线厚涂 | 两种塑形方式 |
| 写实 vs 乙女唯美 | 两个方向 |
| 血肉感 vs 如玉如瓷 | 完全相反 |
| 电影级写实 vs 动漫漫剧 | 根本对立 |
| 仿真人 vs CG渲染 | 可能冲突 |

**→ AI 收到矛盾指令 → 取"平均" → 出"四不像"**

---

## 二、⭐ 根本原因：我"左右横跳"

```
用户说"3D" → 我写3D
用户说"漫剧" → 我写动漫
用户说"参照图" → 我写仿真人+乙女
        ↓
我把【所有词堆一起】→ 矛盾 → 四不像
```

---

## 三、⭐ 解决方案（3条）

### 1. 选定方向（不左右横跳）
```
一次只用一个方向的词：
· 要么"3D仿真人"
· 要么"2D动漫"
不能混
```

### 2. 用【负面词】排除其他
```
正面：3D仿真人 CG渲染
负面：不是2D、不是动漫、不是插画、不是卡通风
```

### 3. 权重靠前
```
重要的风格词放最前面
（词越靠前，权重越高）
```
