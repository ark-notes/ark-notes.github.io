# 一、⭐ 进阶关键点（教程共识）

## 1. 节奏（更精细）
```
· 前 5 秒必须钩子
· 每 3-5 秒一个小反转
· 每 30 秒一个反转
· 公式：钩子 + 冲突 + 反转 + 爽点
```

## 2. ⭐ 运镜是分水岭
> 「静态插画和爆款漫剧的差距，全在【运镜描述】。
> 加上运镜指令 → 流畅度翻倍 → 完播率明显提升」
```
· 推/拉/摇/移/环绕/跟拍
· 每镜必写运镜
```

## 3. 旁白+配音组合
```
85% 爆款用「旁白 + 人物配音」组合
→ 推进剧情 + 让观众理清关系
```

## 4. 平台算法适配
```
· 完播率导向
· 结尾设【开放式问题】→ 引导评论分享
· 蹭热门话题（多巴胺穿搭/复古风）
```

## 5. ⭐ 投放（我没做）
```
平台：巨量千川(抖音) / 磁力金牛(快手)
策略：
· 测试期：小预算(500-1000/天)测3-5条
· 放量期：ROI>1.2 加投
· 稳定期：搭矩阵(10-30条同时跑)
指标：完播率>30% / 点击率>2% / ROI>1.2
```

## 6. ⭐ 数据复盘
```
发布后看：完播率/点击率/ROI
→ 数据不好 → 先改开头
```

# 三、⭐ 我最不足的 3 点

## 不足1：投放（最大盲区）
```
我只做"内容"，没做"投放"
爆款 = 内容 × 投放放大
→ 完全空白
```

## 不足2：运镜不够重视
```
进阶说"差距全在运镜"
→ 我分镜里运镜写太简单
```

## 不足3：没"数据复盘"
```
不知"发布后看什么、怎么调"
```

# 四、⭐ 补救

## 补救1：分镜加"详细运镜"
```
每镜必须写：景别 + 运镜 + 画面 + 光影
（不只是"中景"）
```

## 补救2：结尾设"开放式问题"
```
例："她到底是谁？" → 引导评论
```

## 补救3：加"投放规划"（后期）
```
· 测试期小预算
· ROI>1.2 加投
· 矩阵
```

## 补救4：加"数据复盘"
```
发布后看：完播率/点击率/ROI
```
