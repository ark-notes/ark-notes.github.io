# 五、⭐⭐ 终极版提示词（整合）

```

次世代建模，PBR物理渲染，高精度模型，
表面无多边形锯齿，细节刻画完整。
全局光照(GI)+光线追踪，明暗过渡自然，
阴影带环境色反射，高光位置贴合材质特性。
电影级光影，HDR，8K超清。

【主体】26岁中国男性，极其俊美的长相，清冷矜贵。
【五官】鹅蛋脸，剑眉，狭长深邃的眼睛，眼尾微扬，
眼球有高光点；高挺鼻梁，薄唇；下颌线清晰。
【皮肤】超写实质感，毛孔细节，真实肌理，
自然肤色，无磨皮过度，次表面散射(SSS)。

【构图】中景，三分法，末世废墟背景。
【光影】侧逆光+轮廓光，低调暗光，强对比。
【参数】8K，HDR，电影级，CG海报级别。
【约束】无崩坏、无畸形、无穿模、无模糊、无塑料感。
```
