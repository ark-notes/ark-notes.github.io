# D5 制作规范（省次数版）

> 用户额度：**99 次/天**（阿奇 AI 视频生成）
> 原则：**一次做对 > 反复重试**
> 建立：2026-10-03

---

## 一、成本账（必须先算）

| 项 | 数字 |
|---|---|
| 每日额度 | **99 次** |
| 优化后每集消耗 | **~24 次**（12 镜 × 试 2 次） |
| **一天产出** | **最多 4 集** |
| 30 集系列 | 约 **8-12 天** |

**⚠️ 核心：减少重试次数 = 提高产量。**

### ⭐ 关键规格（2026-10-03 验证）

| 项 | 数据 | 来源 |
|---|---|---|
| 首集时长 | **2 分钟**（引流） | 塔猴/抖音算法 |
| 后续正片 | **约 1 分钟** | 同上（完播率最优） |
| 镜头节奏 | **5-10 秒一个镜头** | 塔猴 |
| 小反转频率 | **每 3-5 个镜头** | 塔猴 |
| 单集分镜数 | **8-15 个** | 塔猴 |
| 每段台词 | **1-2 句** | 知乎 |

**⚠️ 超 3 分钟 → 完播率下滑。短、快、密 是唯一出路。**

---

## 二、省次数的五个做法

### ① 人物图必须一次锁死（三视图法）

**为什么：** 人脸漂移 → 整集作废 → 白烧次数。

**做法（2026-10-03 补 · 中源实操验证）：**
```
Step 1：生成角色【三视图】正面 / 侧面 / 3-4侧
Step 2：补【多角度参考图】正/侧/背 + 面部特写
Step 3：反复微调直到满意（这一步可以多试，值）
Step 4：之后所有镜头都用这几张图 → 【图生视频】
```
**⚠️ 一定用「图生视频」，不要「文生视频」——后者锁不住脸。**

**⭐ 角色卡片（每个镜头开头原样粘贴，不许改写）：**
```
角色 C01：25 岁亚洲女性，鹅蛋脸，杏仁眼，
右眼下方浅色小痣，黑色齐肩直发，三七侧分，
银色圆形耳环。
```
**三件事做扎实，角色就稳：三视图 + 图生视频 + 提示词复用。**

**⚠️ 这一步花 10-20 次也值 —— 因为省了后面全部重试。**

### ② 镜头数 15 → 12

**砍掉「可有可无」的镜头：**
- 保留：钩子 / 爆点 / 反转 / 悬念（必须的）
- 砍掉：过渡镜头 / 重复表达 / 纯氛围

### ③ 用「首尾帧」控制

**同一个场景的连续镜头 → 用同一张图做首帧，改尾帧即可。**

### ④ 先出分镜图，再出视频

**⚠️ 顺序很重要：**
```
先用「图生成」出 12 张分镜图（便宜/快）
        ↓
确认构图满意
        ↓
再用「图生视频」（贵）→ 一次成
```

**而不是直接用「文生视频」乱试。**

### ⑤ 一天做 2-4 集，不硬撑

**为什么：** 试错次数会随疲劳上升（越急越做不对）。

---

### ⑥ 建「角色/场景资产库」（复用降本）

**同一角色/场景只生成一次，全部镜头复用参考图。**
资产库 = 角色三视图 + 场景图，存下来跨集复用 → 系列剧越做越省。

### ⑦ 去水印（必做，别漏）

**AI 生成的视频自带平台水印**（可灵 Logo / 即梦水印等）。
**必须去除后才能正式发布** —— 这是不可跳过的环节。

## 三、标准流程（按顺序做，别跳）

```
第 0 步  先填充自己：读方法论 + 对手法自检（技能/知识/思维达标）
           ↓  ← 未达标不许进入下一步（用户铁律 ⓪）
第 1 步  写剧本（我做）
           ↓
第 2 步  生成人物图（三视图 + 多角度参考）→ 锁定
           ↑ 这一步可以多试，值
           ↓
第 3 步  生成分镜图 ×12（确认构图）
           ↓
第 4 步  图生视频 ×12（一镜一次）
           ↓
第 5 步  配音 + 配乐
           ↓
第 6 步  剪辑 + 去水印 + 加 AI 标识
           ↓
第 7 步  发布
```
