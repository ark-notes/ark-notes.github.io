## 四、制作流程（阿奇 AI 操作 · 7 步）

### 第 1 步：锁人物（最重要）
用「角色卡片」段落，给 4 个角色各生成**三视图（正/侧/3-4）**：
```
① 生成 → ② 反复微调至满意（可多试）→ ③ 存档复用
```
**⚠️ 锁角色三件套：三视图 + 图生视频 + 提示词复用。**

### 第 2 步：生成分镜图 ×12
每个镜头的「AI 指令」用于生成**首帧图**。先确认构图。

### 第 3 步：图生视频 ×12
用**首帧图 + 运动/运镜提示词**生成视频。
**⚠️ 一定用「图生视频」，不要「文生视频」。**

### 第 4 步：配音
| 角色 | 音色 | 情绪 |
|---|---|---|
| 林小满 | 年轻女声，偏冷静，有韧劲 | 坚定 / 隐忍 |
| 林母 | 中年女声，疲惫 | 无助 / 发颤 |
| 二叔 | 中年男声，油滑 | 算计 / 心虚 |
| 小虎 | 童声 | 兴奋 |
| 画外音 | 沉稳女声 | 笃定 |

### 第 5 步：配乐 + 音效
- 开场：悬疑 + 心跳
- 反转点（镜 7）：鼓点
- 片尾（镜 11-12）：弦乐推高 → 悬念

### 第 6 步：剪辑
- 每镜 **5-10 秒**，不留气口
- **去平台水印**（可灵/即梦 Logo）
- **检查穿模 / 模糊 / 杂音 / 字幕错误**（判低质）
- 加 **AI 标识**
