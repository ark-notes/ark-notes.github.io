# 短剧剧本 · 《重生1980：我靠赶山养活全家》第 1 集

> 类型：年代重生 + 赶山养家
> 时长：约 100 秒（15-18 个镜头）
> 节奏：3 秒钩子 → 10 秒爆点 → 30 秒反转
> 制作：阿奇 AI 生成画面 + 配音

---

## 一、人物设定（必须先锁定）

### 主角：林小满
- **年龄**：35 岁（重生回 18 岁）
- **外貌关键词**（用于 AI 保持一致性）：
  ```
  18岁中国农村青年女性，齐耳短发，眉毛较浓，
  皮肤偏黑有雀斑，穿褪色蓝布衫，眼神倔强
  ```
- **人设反差**：外表瘦小 → 内在是经历过失败婚姻、懂商机的 35 岁灵魂

### 配角 1：林母（45 岁）
```
45岁中国农村妇女，头发有白丝，灰色粗布褂子，面容疲惫但眼神温和
```

### 配角 2：二叔（40 岁，反派）
```
40岁中国农村男人，寸头，脸型瘦长，穿的确良衬衫，
眼神精明算计，习惯眯眼看人
```

### 配角 3：小虎（弟弟，10 岁）
```
10岁中国农村男孩，圆脸，锅盖头，黑瘦，穿打补丁的短袖
```

**⚠️ 关键：** 每个人物第一次出现时，用**同一组关键词**生成，之后全部复用，**人脸不漂移**。

## 二之二、次数预算（关键）

| 步骤 | 次数 |
|---|---|
| 人物图 ×3（可多试） | 10-15 |
| 分镜图 ×12 | 12 |
| **图生视频 ×12** | **12** |
| **合计** | **~35-40 次** |

**→ 99 次/天，可做 2-3 集。**

**⚠️ 关键：分镜图先确认满意，再图生视频 —— 避免视频白试。**

## 三、制作清单（阿奇 AI 操作）

### 第 1 步：锁定人物（最重要）

**用同一组关键词，给每个人物生成 3 张不同角度图：**

```
林小满：18岁中国农村青年女性，齐耳短发，眉毛较浓，
        皮肤偏黑有雀斑，穿褪色蓝布衫，眼神倔强
```

**⚠️ 三视图（正面/侧面/半身）—— 后面所有镜头都用这几张图做「图生视频」。**

### 第 2 步：生成画面

**每个镜头的「AI 指令」直接复制给阿奇 AI。**

**⚠️ 提示：**
- 用**图生视频**（不是文生视频）→ 人物才不漂移
- 每个镜头 **5-10 秒**
- 不要一次生成全片，**一镜一镜来**

### 第 3 步：配音

| 角色 | 音色建议 |
|---|---|
| 林小满 | 年轻女声，偏冷，有韧劲 |
| 林母 | 中年女声，疲惫 |
| 二叔 | 中年男声，油滑 |
| 小虎 | 童声 |

### 第 4 步：配乐 + 音效

- 开场：悬疑
- 反击点：鼓点
- 片尾：悬念

### 第 5 步：发布

| 项 | 要求 |
|---|---|
| **标题** | 带钩子（「重生回1980，我娘差点被赶出门」） |
| **封面** | 用镜头 4 或镜头 8（眼神坚定的那张） |
| **AI 标识** | ⚠️ **必须勾选** |
| **↓ 结尾** | 加「下集预告」引导追更 |
