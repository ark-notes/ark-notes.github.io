## 第 2 节 · 核心设定

### 主角
```
姓名：陈默
年龄：26岁（重生回末世前3天）
前世：末世里活了5年，死于尸潮，最后悔没早点囤货
性格：冷静、务实、不圣母但不冷血
```

### 异能【神农空间】（差异化核心）
```
- 一块可种植的空间（初始1亩）
- 种下的作物 24 小时成熟
- 空间内不出丧尸、可存物资
- 随等级提升：面积↑ / 作物种类↑ / 可容纳活人↑

⚠️ 为什么选"种植型"而非"战斗型"：
  ① 差异化（大部分异能是打斗）
  ② 契合经营内核
  ③ 不依赖打斗特效（省钱、好做）
```

### 世界观
```
某天，全球同时爆发"异变"：
- 70% 人类死亡或变异成丧尸
- 5% 人类觉醒异能
- 25% 普通人挣扎求生
幸存者建立安全区，互相争夺资源
```

## 第 3 节 · 3 季大纲

### 第 1 季（觉醒 + 立足）20-30 集
```
① 重生回末世前3天
② 用记忆提前囤货（超市被搬空）
③ 末世爆发，躲过第一波
④ 觉醒【神农空间】
⑤ 找到废弃农场 → 种出第一批粮食
⑥ 救下邻居/朋友 → 小团队成型
⑦ 对抗第一波掠夺者
⑧ 季终：建立"第一座小据点"
```

### 第 2 季（升级 + 扩张）30-40 集
```
- 空间升级，能种更多、存更多
- 据点扩大，收留更多幸存者
- 遇到更强势力（军阀/异能者集团）
- 用"粮食"当硬通货 → 建立贸易
- 季终：控制一座小城
```

### 第 3 季（巅峰 + 揭秘）30-40 集
```
- 异能来源之谜（为什么会有末世）
- 空间升级到极致
- 终极对决
- 大结局：重建文明
```
