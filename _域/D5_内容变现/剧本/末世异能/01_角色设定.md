## ⭐ 角色资产标准（2026-10-04 案例库修正）

**⚠️ 从真实案例学到的（案例库 1/2/3）：**

| # | 铁律 |
|---|---|
| **1** | **锚点图必须：正脸 + 无遮挡 + 干净光线**（带角度/夸张表情/复杂光影 → 特征不稳） |
| **2** | **基准锚点图要 6-8 张**：全景 + 正脸 + 45度侧脸 + 表情（喜/怒/哀） |
| **3** | **单镜头提示词不要重复写外貌**（会与锚点冲突 → 角色崩） |
| **4** | 用**固定身份标识符**（如 `[陈默]`） |
| **5** | **风格一次性锁定**，不每镜各写 |
