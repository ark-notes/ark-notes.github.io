# 林小满 · 去「AI 味」提示词 v2

> 问题：v1 太标准 → AI 吐通用脸
> 解法：给「独一份特征」+「活人神态」+「脏/旧/不完美」

---

## 一、对比（看差异在哪）

### ❌ v1（普通 · 你上传的那版）
```
18岁中国农村青年女性，齐耳短发，眉毛较浓，
皮肤偏黑有雀斑，穿褪色蓝布衫，眼神倔强沉稳
```
→ 问题：**全是通用词，AI 见过一万遍**

### ✅ v2-A（加「独一份特征」）
```
一个18岁的农村姑娘，脸型清瘦，颧骨略高。
左眉尾有一道很浅的旧疤（约1厘米），
右上唇有一颗小痣。
齐耳短发，发尾参差不齐，是自己剪的。
皮肤被晒成健康的小麦色，鼻梁和脸颊有晒斑和细汗。
穿一件洗到发白的蓝布衫，肘部有深色补丁，
领口磨破了一小圈。
嘴唇干裂起皮，嘴角习惯性向下抿着——
是长期咬牙忍事的表情。
眼神不看镜头，微微斜视左前方，带着戒备。
```

### ✅ v2-B（加「生活痕迹」· 更狠）
```
一个18岁的农村姑娘，站在土墙前。
头发被汗黏在鬓角，额头有细密的汗珠。
脸上有灰，不是脏，是干活沾的浮土。
左手虎口有厚茧，指缝里嵌着洗不掉的泥。
蓝布衫后背有一大块汗渍。
裤脚卷起，腿上有蚊虫咬的红点。
她不笑，盯着远处，眉头皱着，
像在算什么账。
```

## 二、⭐ 去AI感的 6 个「加料」公式

| # | 加什么 | 怎么加 |
|---|---|---|
| **1** | **不完美特征** | 疤 / 痣 / 不对称（左眉尾有浅疤） |
| **2** | **生活痕迹** | 汗 / 灰 / 茧 / 泥 / 蚊虫咬痕 |
| **3** | **服装真实感** | 磨破 / 补丁 / 发白 / 汗渍位置 |
| **4** | **神态具体化** | 「嘴角下抿」比「倔强」强 100 倍 |
| **5** | **视线方向** | 不总看镜头（看左前方 / 低头 / 斜视） |
| **6** | **动作感** | 站着别僵 —— 「手攥着衣角」 |

## 三、再叠「风格词」拉质感

**在提示词末尾加：**
```
电影感，35mm胶片质感，自然侧光，
柯达胶片色调，轻微颗粒感，非棚拍感
```

**避免用：**
```
❌ 高清 / 精美 / 唯美 / 完美  ← 这些词让 AI 更假
```
