# 林小满 · 「吸引人」版提示词

> 问题：现有形象「不吸引人」（用户反馈）
> 目标：**美 + 有辨识度 + 有故事感**，但不失底层真实感
> 建立：2026-10-04

---

## 一、诊断：为什么现在不吸引人

| 问题 | 表现 |
|---|---|
| 五官太平 | 圆脸、单眼皮、无亮点 → **路人感** |
| 没记忆点 | 看完记不住 |
| 写实过头 | 变「素人」而不是「剧抛脸」 |

**短剧女主公式 = 美 + 辨识度 + 故事感**

---

## 二、三版方案

### 🅰️ 清冷美强惨（反差最强）
```
仿真人写实风格，电影剧照质感。
一个18岁中国农村姑娘，清冷倔强的气质，
五官精致耐看：双眼皮，眼睛大而有神，眼尾微挑，
鼻梁挺直，唇形饱满，脸型小巧精致。
皮肤白皙偏冷，有细微的晒红和浮灰。
左眉尾一道浅疤，右眼下一颗泪痣（记忆点）。
黑色齐耳短发，发丝顺滑有光泽，几缕碎发垂落额前。
穿洗到发白的蓝布衫，肘部补丁。
眼神倔强，微微仰头看向斜上方，带着不服输的劲。
港风复古胶片色调，暖黄与青绿对比，柯达颗粒感，侧光。
中景，全身入镜，站在斑驳土墙前。
```

### 🅱️ 干净素颜美人（清纯路线）
```
仿真人写实风格，电影剧照质感。
一个18岁中国农村姑娘，干净清透的素颜美，
鹅蛋脸，皮肤白皙透亮有自然光泽，
大双眼皮，眼睛清澈明亮，睫毛长，
鼻梁精巧，嘴唇饱满带自然血色。
黑色齐耳短发，整洁利落。
穿洗到发白的蓝布衫，肘部补丁，领口磨破。
眼神清澈倔强，直视前方。
自然光，柔和暖调，浅景深，背景虚化。
中景，全身入镜，站在斑驳土墙前。
```

### 🅲 野性灵气型（有冲击力）
```
仿真人写实风格，电影剧照质感。
一个18岁中国农村姑娘，带着山野灵气的野性美，
脸型小巧，颧骨微高，五官立体分明，
深眼窝，眼神锐利有神，睫毛浓密，
鼻梁高挺，嘴唇丰润。
小麦色皮肤有健康光泽，左眉尾浅疤。
黑色齐耳短发，发丝蓬松自然，有风吹过的凌乱感。
穿洗到发白的蓝布衫，卷起袖子露出手腕。
眼神警觉锐利，像一头小兽，扭头看向侧面。
港风胶片色调，强烈侧光，暖黄与青绿对比。
中景，全身入镜，站在斑驳土墙前。
```
