## 二、红果平台核心指标（关键）

**第三方（人人都是产品经理）：**

> 「对红果来说，核心的运营指标**并不是豆瓣评分，也不是行业口碑**，
> 而是：**用户停留时长、完播率、复看率**，
> 以及**每一分钟用户时长对应的广告填充率和变现效率**。」

**⚠️ 翻译成人话：**

| 指标 | 意思 | 我要怎么做 |
|---|---|---|
| **停留时长** | 用户看了多久 | 别让他划走 |
| **完播率** | 看完的比例 | **前 5 秒必须抓人** |
| **复看率** | 回看的比例 | 有细节值得再看 |
| **广告填充率** | 平台能赚多少广告费 | （平台的事） |

**→ 核心就一条：让用户看完，别划走。**

## 三、平台审核标准（重要变化）

**官方数据（塔猴，2026-04）：**

> 「平台累计**下架/拦截超过 10,000 部低质 AI 短剧**，其中漫剧占比超 60%。
> 这意味着审核标准**已从『数量优先』转向『质量优先』**。」

**⚠️ 这直接推翻「量产就能赚钱」的想法。**

## 五、两条变现路径（关键）

### 路径 A：剧本投稿（不自己拍）

```
写剧本 → 投红果 → 签约 → 拿分成
```
| 项 | 说明 |
|---|---|
| **非独家**（已在别处发过） | 分成 **5%-10%** |
| **独家签约** | 分成 **20%-30%** |
| **结算** | 每月 10 号结算上月，T+7 到账 |

**⚠️ 投稿前必做：**「刷红果热榜，找**同类型 3 部**，分析它们的**开篇结构、反转节奏、台词风格**。不分析直接投，大概率被拒。」

### 路径 B：自己做成片上传（推荐给你）

```
注册创作者 → 上传成片 → 审核 → 收益全自留
```
| 项 | 说明 |
|---|---|
| **适合** | AI 数字人/漫剧/实拍 |
| **收益** | **全部自留** |
| **入口** | 创作者中心 → 内容管理 → 短剧上传 |
| **资质** | 需实名（身份证/营业执照） |

**⚠️ 需要澄清的传闻：**
> 「网传『红果取消 AI 仿真人剧保底政策』，
> 官方回应：**仅针对部分高风险剧本调整为纯分成模式，分成约 20%**，非全面取消。」
