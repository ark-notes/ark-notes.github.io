> 整理：2026-10-04

---

# 一、⭐ 三个层级（先分清）

| 层级 | 哪来的 | 例子 | 处理 |
|---|---|---|---|
| **1. 工具水印** | 生成工具（阿奇） | ARKIE吉祥物、"由阿奇AI生成" | 🔴 **去掉** |
| **2. 合规标识** | 法规/平台 | 备案号、"本作品含AI生成内容" | 🟢 **自己加**（片头） |
| **3. 作者署名** | 自己 | 你的署名/Logo | 🟡 可选 |

---

# 二、⭐ 参考：专业短剧怎么做

（从拆解素材观察）
```
① 片头前几秒 → 出现"备案号"文字 → 几秒后消失
② 片头/简介 → AI生成声明
③ 工具品牌水印 → 【无】
④ 作者署名 → 可选
```

---

# 三、⭐ 完整工作流（4步）

## 第1步：建模图 → 去水印
```
阿奇/即梦生成的图 → 右下角有角标
处理：手机相册【裁剪】把角标裁掉
⚠️ 注意别裁到人物
```

## 第2步：生成视频 → 剪掉工具署名
```
每个镜头视频 → 结尾有"ARKIE AI"+"由阿奇AI生成"
处理：剪辑时【剪掉结尾那1-2秒】
```

## 第3步：拼接成集 → 加合规标识
```
12个镜头 → 拼成1集
片头加：
  ① 备案号（红果给）
  ② "本作品含AI生成内容"
（几秒后消失，像专业剧）
```

## 第4步：发布
```
上传红果 → 平台审核 → 平台备案 → 上线
```
