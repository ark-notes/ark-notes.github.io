---

## 一、5个「low」的原因

| # | 问题 |
|---|---|
| 1 | **胶皮脸/塑料感**（过度磨皮、无毛孔） |
| 2 | **AI崩坏**（左脸颊生硬白色高光斑） |
| 3 | **发际线崩**（头发像脏棉絮） |
| 4 | **眼睛空洞**（无眼神光、呆滞） |
| 5 | **光影平**（高光像白漆、阴影死黑、无过渡） |

**视觉模型总结：**
> 「皮肤像塑料、头发像脏棉絮、光影像涂鸦」

---

## 二、⭐ 根因

```
① 我给的风格【3D国漫/BJD/UE5】→ "光滑、无毛孔"
② "光滑" → 就变"塑料感"
③ 而且【没加"防崩/细节"约束】→ 出崩坏
```

**核心矛盾：**
```
3D风格 与 真实质感 冲突
→ 要"3D的美" + "不塑料"
→ 必须【强制加细节约束】
```
