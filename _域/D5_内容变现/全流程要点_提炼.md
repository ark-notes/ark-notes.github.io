# 一、完整流程（8步）

```
① 选题（看榜单，定题材）
② 剧本（3秒钩子/10秒爆点/30秒反转）
③ 角色设定（三视图/定妆照 → 锁脸）
④ 分镜脚本（景别/动作/台词/时长）
⑤ 画面生成（图生图，多版挑最佳）
⑥ 视频生成（图生视频，保持一致性）
⑦ 配音+剪辑（剪映：拼接/字幕/音效）
⑧ 发布（红果/抖音 + 备案 + AI标识）
```

---

# 二、⭐ 各步要点（教程共识）

## ① 选题
```
· 看红果/抖音榜单
· 统计高频题材
· 锁前3个题材
```

## ② 剧本
```
· 3秒钩子 → 10秒爆点 → 30秒反转
· 每集一个爽点
· 结尾留钩子
· 单集 1-3 分钟
```

## ③ 角色
```
⭐ 先出"定妆照"再生成视频
· 三视图（正/侧/背）
· 多角度参考图
· 固定角色描述（每次重复）
```

## ④ 分镜
```
· 每镜3-8秒
· 一镜一动作
· 复杂动作拆成多个镜头
```

## ⑤⑥ 生成
```
· 图生视频（不是文生视频）
· 每镜多生成2-3版，挑最佳
· 保持角色一致
```

## ⑦⑧ 剪辑发布
```
⭐ 关键：AI生成的视频自带水印（可灵/即梦/阿奇）
   → 必须去除后才能发布（不可跳过）
· 拼接 + 字幕 + 音效
· 片头加：备案号 + AI标识
· 发布红果 → 平台审核 → 平台备案
```

# 五、⭐ 避坑（教程提醒）

```
① 图生视频 > 文生视频（保持一致性）
② 角色描述每镜重复（防跳戏）
③ 一镜一动作（别多动作）
④ 多生成几版挑最佳
```
