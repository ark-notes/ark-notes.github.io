# 短剧知识库 · 底层原理

> 来源：豆包专家手册（第一部分）

## 一、短剧为什么能火

### 算法机制（抖音/快手通用）
```
流量池分级：初始500播放
 → 3秒停留率达标 → 1万播放
 → 完播率/互动率达标 → 10万 → 50万 → 500万 → 千万级

权重占比：完播率60% > 点赞评论转发25% > 关注率10% > 主页访问5%
核心门槛：前3秒跳出率＜70% 才能进下一级流量池
爆款基线：整体完播率 ≥30%
```

### 人性弱点（精准对应）
| 弱点 | 表现 | 对应题材 |
|---|---|---|
| 贪婪 | 暴富、逆袭、白得好处 | 系统流、神豪流 |
| 虚荣 | 打脸、装逼、被人仰望 | 赘婿战神、总裁逆袭 |
| 好奇 | 悬念、反转、未知结局 | 悬疑、重生流 |
| 代偿 | 现实得不到的，剧里实现 | 情感/权力补偿 |
| 惰性 | 不用动脑，1分钟一个爽点 | 碎片化爽感 |

### 情绪触发
```
高频有效情绪：爽、虐、燃、气、甜 → 单集必须覆盖≥2种
情绪密度：每30秒1个小情绪点，每1分钟1个大情绪释放
触发逻辑：先压抑（反派羞辱）→ 再爆发（主角打脸）
         → 压抑越狠，爽感越强
```

## 二、爆款必备要素（按重要性）
```
1. 3秒钩子 → 权重40%
2. 情绪密度 → 权重25%
3. 强人设 → 权重15%
4. 反转节奏 → 权重10%
5. 视觉冲击力 → 权重7%
6. 结尾留钩 → 权重3%
```

## 三、为什么"一眼划走" vs "停不下来"

**划走原因：**
```
· 前3秒无冲突/无反差/无悬念（全是铺垫）
· 画面平庸，人物没辨识度
· 台词拖沓，前5秒没进正题
· 开局全景/空镜，没有人物表情和冲突
```

**停不下来：**
```
· 信息差：观众知道主角身份，剧中人不知道 → 期待打脸
· 悬念前置：开头抛问题，全程找答案
· 情绪连续：上个爽点刚落，下个冲突已起（无尿点）
· 节奏卡点：每5秒一切镜，每15秒一小高潮
```
