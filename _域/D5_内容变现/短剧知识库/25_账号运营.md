# 短剧知识库 · 账号运营

> 来源：豆包《AI短剧运营全体系》

## 一、⭐ 新号冷启动（7天）

```
第1-2天 养号+定位：注册、统一赛道风格、每天刷30分钟同题材
      点赞评论关注20个对标号，给账号打标签
第3-4天 首发3集测数据：一天3集、间隔2小时、流量高峰发
      每集投50元DOU+，定向对标粉丝
      看：前3秒跳出<70%、完播率≥30% → 继续；达不到改钩子
第5-7天 爬坡拉权重：数据达标加到日更5集，连更7天
      每天回所有评论。第7天单集破万→稳定期
```

## 二、⭐ 矩阵号（6个号一组）

| 类型 | 数量 | 分工 | 玩法 |
|---|---|---|---|
| 主力号 | 1 | 冲播放冲粉丝，变现主力 | 精品，日更3集，投流主推 |
| 测试号 | 3 | 测题材/钩子/画风 | 每号测不同方向，跑通移到主力 |
| 衍文号 | 2 | 剪高光片段引流回主号 | 日更多条短片段，带话题 |

**规则：**
```
· 同赛道不同人设，不做一样内容（避免内耗）
· 测试号跑出的爆款模型 → 立刻复制到主力号放大
· 一个号爆了 → 其他号跟同题材，吃满红利
· 单号限流不影响其他号（风险分散）
```

## 三、⭐ 日更频率 + 发布时间

**频率：**
```
冷启动期（前7天）：日更3-5集
稳定期（1万粉+）：日更3集（性价比最高）
爆火期（单集100万+播放）：日更4-5集
禁忌：断更超3天，权重掉一半；一天更10集，完播率暴跌
```
**发布时间（黄金）：**
```
早高峰 7:30-9:00（通勤）
午高峰 12:00-13:30（播放最高）
晚高峰 18:00-22:00（付费转化最高）
· 每集间隔2小时以上
· 固定时间发，培养追剧习惯
```

## 四、⭐ 涨粉（关注率）

**公式：关注率 = 人设记忆点 + 追更欲望 + 引导强度**
```
1. 人设锚定法：主角有强记忆点（痣/疤/口头禅）
2. 结尾留钩法：55秒处抛悬念 + 文字引导"关注看下集"
3. 合集引导法：所有剧集放合集，封面标"第X集"
4. 评论区引导：置顶"关注我每天更新3集"；
   回复带引导"后面更精彩，点关注不迷路"
```
**标准：关注率≥2%合格，≥5%优秀，<1%立刻优化。**

## 五、⭐ 标题/封面公式

**标题（爆率90%）：**
```
公式1 冲突反差式（男频首选）：
  身份反差+冲突事件
  例："千亿总裁假扮保安，被前女友当众甩巴掌"
公式2 悬念提问式（通用）：
  极端场景+灵魂拷问
  例："为什么全城首富见到这个清洁工，当场就跪下？"
公式3 情绪利益式（女频首选）：
  情绪承诺+利益点
  例："重生回到结婚前，这一次我要让渣男付出代价"
```
**封面标准：**
```
1. 画面：人物近景+冲突表情（愤怒/震惊/打脸瞬间），不要全景/平淡脸
2. 文字：3-5个大字，加粗黑边，写核心冲突（"战神归来""当场打脸"）
3. 配色：高对比，人物突出，背景暗，文字亮
4. 禁忌：文字堆满、模糊图、和内容无关
```

## 六、⭐ 评论区运营（三步法，互动+30%）

```
1. 预埋评论：发布后立刻用小号发3-5条热评
   （猜身份/骂反派/催更/吐槽）
   例："我赌五毛，男主下周就亮身份"
2. 置顶引导：一条催关注，一条引讨论
3. 互动回复：前100条尽量都回；怼反派的点赞顶上去
   负面评论不用删（有争议度），只要不违规
核心：评论区是第二情绪场，情绪越激烈，算法推流越多。
```
