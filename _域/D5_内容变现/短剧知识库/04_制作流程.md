# 豆包知识库 · 制作流程

> 来源：豆包对话

---

## 一、⭐ 全流程（豆包原版，按天排）

```
第1-2天：固定男主基准素材
  目标：磨出一张最稳的男主脸

第3-X天：批量出镜头
  每天任务：出 30-40 个镜头
  同个镜头生成 3 版 → 挑脸最正、氛围最好的用
  优先级：男主近景 > 国贸场景 > 奢露空景 > 面部镜头
  技巧：同款表情、同款景 → 直接复用，不用重做，省次数

第9-11天：转视频 + 剪辑成片
  目标：全部做成 2 分钟竖屏成片
  步骤：
   1. 用关键帧图在 Arkie 生态（生成）5 秒动态，
      只加微动作（眨眼、转头、呼吸、抬手）
   2. 裁剪掉帧镜头，配 AI 配音、免费 BGM、风雨雷效、醒目字幕
   3. 剪辑卡 2 分钟，接尾句半句叠念
```

## 二、⭐ 变量控制（豆包原版）

**"每次只变一个核心变量"：**

| 情况 | 做法 |
|---|---|
| 同一集、同一状态 | 只变动作和表情，不变服装/发型/妆容 |
| 换场景 | 只变场景 |
| 换状态 | 只变妆容（如"受伤妆"）|

**服装/发型/妆容/状态的变量表：**
```
· 服装：卫衣、外套、衬衫、黑T、风衣、工装 → 每类先做基准图
· 发型：基础狼尾、凌乱湿发、刘海遮眼、半扎短发
· 妆容：清冷日常、病弱苍白、受伤妆、压迫感冷妆
· 状态：冷静、愤怒、克制、受伤、疲惫、冷笑
       → 用表情和眼神变化，不重做
```
**= "Arkie 低成本换装逻辑"**

## 三、⭐ 成本认知（豆包纠正用户的）

```
不是"省钱"（Arkic会员每天99次免费）
        ↓
而是："用免费次数堆质量，
      全流程 Arkic 闭环，零额外使用成本"
        ↓
= 不用省，反而要把每天的次数用满
```

## 四、人物一致性

```
· 磨出一张"最稳的男主脸" → 当基准
· 之后所有镜头用它 → 图生图
· 变装/变状态 → 只换变量，不动基准脸
```
