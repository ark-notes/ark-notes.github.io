## 一、⭐ 投流ROI阈值（我搞错了）

```
❌ 我原以为：ROI<1 就该放弃
✅ 正确阈值：
   ROI < 0.7        → 直接放弃（止损线）
   ROI 0.7 - 1      → 优化再测（微亏区间，有潜力）
   ROI > 1          → 逐步放量
   ROI > 1.2        → 大胆放量

⚠️ 关键：不要把止损线设太高！
   ROI 0.8 且内容完播好（如35%）→ 优化封面/定向再测，别浪费
```

## 二、⭐ 选题阶段临界值（我判早了）

```
❌ 我原以为：上榜数量腰斩（15→8）就是过气
✅ 正确临界值（以增速为准）：
   新作增速 +30%以上 → 上升期
   新作增速 ±10%     → 成熟期
   新作增速 -20%以下 → 衰退期
   
⚠️ 不要只看"绝对数量"，要结合：
   · 新作增速
   · 播放量增速
   · 投流ROI
   三个维度交叉验证
```
