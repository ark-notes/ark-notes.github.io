# 短剧知识库 · 判断标准（质检用）

> 来源：豆包专家手册（第七部分）

## 一、⭐ 一个镜头"合格"的标准（5条全满足）

```
1. 人脸合格：五官端正无畸形，相似度≥80%，表情符合剧情
2. 画质合格：1080P以上，清晰无模糊，无噪点/水印/过曝欠曝
3. 构图合格：主体突出，人物在黄金分割点，不歪不斜，不穿帮
4. 光影合格：面部光线均匀，不阴阳脸，有层次感
5. 内容合格：动作/场景/服饰符合分镜，无逻辑错误
→ 任意一条不满足 → 直接重制
```

## 二、⭐ 一集"能不能爆"（发布前预判）

```
1. 钩子测试：给3个外行看前3秒，能停下问"然后呢"=合格
2. 情绪点数：1分钟内≥2个明确情绪点（爽/虐/气）
3. 尿点测试：有想快进/划走的地方 → 剪掉
4. 留钩测试：看完最后一句，有想看下一集的欲望
```

## 三、⭐ 发布后数据判断（2小时为准）

```
完播率 ≥30% → 正常流量，能继续推
完播率 ≥40% → 小爆潜质，加大投放
完播率 ≥50% → 大爆潜质，全力追投
前3秒跳出率 ＞70% → 直接废掉，重剪开头
```

## 四、⭐ 图"能用" vs "废掉"

**能用（5条全满足）：**
```
1. 人脸正常，无畸形、无五官错位
2. 相似度≥75%，能认出是同一个人
3. 画质清晰，构图正确
4. 动作表情符合剧情
5. 无穿帮、无违禁、画风统一
```

**必须废掉（满足任意一条）：**
```
1. 人脸畸形、五官错位、多/少手指、肢体崩坏
2. 完全不像，换了一张脸
3. 模糊、大片噪点、过曝/欠曝严重
4. 明显穿帮（古代出现空调/手机）
5. 画风和整体不统一
6. 有违禁内容、水印、logo、文字
```
