# 短剧知识库 · 新手必踩30个坑

> 来源：豆包专家手册（第八部分）

## 提示词类（5）
```
1. 写"超级帅哥"→网红脸 → 写具体五官参数
2. 负面词只写"丑陋" → 用标准20+负面词清单
3. 堆50个形容词 → 核心词15个以内，按权重排序
4. 每次全改提示词 → 每次只改1-2个变量
5. 用人名代替外貌 → 纯写外貌描述
```
## 人设类（5）
```
6. 主角完美无缺 → 加无伤大雅的小缺点
7. 反派纯坏没动机 → 给合理立场和动机
8. 配角抢戏 → 配角只承担1-2个功能
9. 主角长相模板化 → 加专属记忆点
10. 人设和剧情不符 → 气质外形匹配身份
```
## 剧本类（5）
```
11. 前10秒还在铺垫 → 3秒必须出钩子
12. 结尾没钩子 → 单集小闭环+下集悬念
13. 全是对话 → 少说多做，用画面讲故事
14. 反转生硬 → 反转前埋伏笔
15. 多线并行太复杂 → 单线叙事
```
## 制作类（5）
```
16. 时长忽长忽短 → 固定60秒左右（误差≤5秒）
17. 一个镜头10秒不动 → 每集12-15镜头，4-5秒一个
18. 人物每集不一样 → 基准图+Lora锁一致性
19. 画面堆满细节 → 留白构图
20. BGM比人声大 → BGM比人声小20%
```
## 运营类（5）
```
21. 一次性发完100集 → 日更3-5集
22. 埋头更新不看数据 → 发3集测数据
23. 标题随便写 → 悬念式/冲突式标题
24. 封面随便截帧 → 冲突画面+大字标题
25. 不回复评论 → 尽量回复每条
```
## 认知类（5）
```
26. 追求画质忽略剧情 → 剧情＞画质，爽点＞精致
27. 做自己喜欢的题材 → 先抄爆款结构，再微创新
28. 想靠一集爆火 → 批量做号，矩阵玩法
29. 频繁换画风换题材 → 定位清晰，一条路跑通
30. 全靠AI不质检 → 每张图人工审核
```

## ⭐ 豆包的"隐藏规则"（写提示词时遵循）

```
1. 名词＞形容词："剑眉"比"帅气"有用10倍
2. 具体＞抽象："眉峰在瞳孔外侧"比"眉毛好看"精准
3. 前重后轻：前3个词权重是后面的2倍
4. 负＞正：负面词权重比正向词高
5. 同类相聚：五官放一块，服饰放一块
6. 画风唯一：只写一种画风
7. 不用否定：不说"不胖"，说"身材匀称"
8. 年龄必写：不写年龄AI默认20岁
9. 质感词优先："电影剧照""镜头感"比"8K高清"更提质感
10. 小步迭代：每次只改1-2个词
```

## ⭐ 为什么改这个、不改那个（决策逻辑）

```
1. 先改高权重：人脸崩先改五官，再改画风
2. 改具体不改抽象：不说"更帅"，说"眉峰高1mm"
3. 优先加负面：先排除（如塑料感→排除硅胶感）
4. 核心词不动：人设核心气质（如"凌厉霸气"）永远不改
5. 符合常识：古代人不染发不纹身
6. 只改一个变量
```

```
1. 3秒钩子决定生死，完播率是第一权重
2. 扮猪吃虎是永恒爆款题材
3. 女频吃情绪价值，男频吃爽点打脸
4. 批量矩阵号比单个精品号变现更稳
5. 三渲二是当前性价比最高的短剧画风
```

**豆包的推断（它自己不确定）：**
```
1. 每集12-15个镜头是完播最优节奏
2. 主角加小缺点，完播率+5%
3. 结尾钩子放55秒处比60秒处完播率高5%
4. 负面词25个左右画质提升最明显
5. 日更3集是涨粉变现平衡点
```
