# 短剧知识库 · 完整实操案例（豆包给的样板）

> 来源：豆包《AI短剧运营全体系》
> 案例：0基础做男频三渲二赘婿战神号，30天跑通变现
> ⚠️ 这是豆包给的"示范案例"（数据是示例）

---

## 第1天：选题 + 对标拆解
```
1. 打开DataEye短剧榜，看近7天男频TOP20
   → 赘婿战神6部上榜，增速40%，上升期
2. 挑3个对标：《战神赘婿》《隐龙出世》《龙婿归来》
3. 拆解：每集60秒，3秒钩子都是"被羞辱+反差"，
   15秒亮小底牌，30秒打脸，结尾留身份悬念
结论：做赘婿战神，三渲二画风，标准60秒结构
```

## 第2天：人设 + 剧本大纲
```
男主：表面窝囊赘婿，实际隐退战神；眉骨浅疤，
     左手黑色龙纹戒指；隐忍，出手狠
反派：丈母娘+富二代情敌，嚣张
女主：温柔千金，维护男主（情感锚点）

前3集：第1集钩子"结婚三年，女婿连桌都不能上，下一秒全场惊呆"
每集严格：3秒钩子→5秒羞辱→15秒反转苗头→30秒打脸→55秒留钩
```

## 第3天：磨主角人设图（关键）
```
提示词：三渲二风格，电影质感，8K，25岁男性，
赘婿战神，隐忍霸气，窄方脸，剑眉星目，眉骨一道浅疤，
高鼻梁，薄唇，黑色短发，哑光小麦色皮肤，
穿灰色休闲外套，左手戴黑色龙纹戒指，
近景正面，自然光，侧逆光
负面词：畸形脸，大小眼，网红脸，塑料感，女性化，
       油光，模糊，水印

→ 生成3张不同seed
→ 按看图checklist质检：
  第1张偏女性化（眉太细）；第2张塑料感（皮肤太光）；第3张刚好
→ 微调：给第3张加"硬朗下颌线，哑光皮肤"，再生成2版，选最优

产出：男主正面+侧面基准图2张
```

## 第4-5天：制作第1集全镜头
```
1. 按分镜表12个镜头，用基准图图生图，只改动作表情和场景
2. 逐个质检：第3个镜头脸崩→重制；第7个角度太偏→换角度
3. 修图：统一色调、修瑕疵、裁9:16竖屏
4. 配音：沉稳男声，180字/分钟，带隐忍感
5. 剪辑：按分镜剪，每镜4-5秒，高潮加快，加打脸音效+BGM
6. 字幕：黑体28号，白字黑边，重点台词标红
产出：第1集成品，59秒，12个镜头
```

## 第6天：发布 + 测数据
```
1. 中午12点发第1集
   封面：男主被扇耳光；标题："赘婿被当众扇耳光，
   转身一个电话，全城首富都慌了"
2. 投50元DOU+，定向"赘婿短剧"对标粉丝，跑6小时
3. 小号发3条预埋评论，置顶引导关注
结果：6小时播放5000，完播率38%，跳出率62%，关注率2.5%
判断：达标，继续更
```

## 第7-10天：冷启动爬坡
```
· 每天3集（7:30/12:00/19:00），每集投50元测
· 问题：第5集完播率22% → 排查发现前10秒铺垫太长
  → 重剪把冲突提前到第3秒 → 完播率回到35%
结果：第10天单集最高12万，粉丝破3000，
     开流量主，第一笔广告收入278元
```

## 第11-20天：稳定更新 + 投流放大
```
· 日更3集，批量生产
· 选播放最高的3集，每天投500元巨量，ROI稳定1:1.3
· 问题：做10集后有几集人物不一样 → 排查发现seed差太多
  → 固定seed前5位，用基准图图生图 → 相似度回到85%+
结果：第20天总播放破500万，粉丝2万，月入过万
```

## 第21-30天：矩阵复制 + 变现拓展
```
· 开2个测试号，换人设细节，测新钩子
· 对接红果，投稿剧本，申请保底
· 优化结尾引导，提升付费转化
结果：30天，主号粉丝5.2万，总播放1200万，总收益3.2万
```

---

## ⭐ 案例的核心经验（豆包总结）

```
"前期慢一点，把人设、钩子、节奏磨对，后面批量就快；
 遇到问题先排查最高权重的变量，不要瞎改。"
```

**→ 这正是我这两天该学的：前期把"人设/钩子/节奏"磨对，
  而不是反复抠画风细节。**
