# 短剧知识库 · 看图 Checklist（可直接用）

> 来源：豆包《标准看图流程》附 Checklist
> 用法：打√=合格，×=不合格，？=不确定
> ⚠️ 一票否决项有任意一个×，直接判废图

---

## 【一、废图排查（一票否决）】
```
□ 人脸畸形：五官错位、大小眼、歪嘴、塌鼻梁、脸部变形
□ 肢体崩坏：多手指、少手指、肢体扭曲、比例失调
□ 画质不合格：模糊、马赛克、过曝、欠曝、严重噪点
□ 合规问题：穿帮、水印、logo、多余文字、违禁内容
□ 画风严重不符：和项目要求完全不是一类画风
```

## 【二、人物一致性检查】
```
□ 脸型轮廓和参考图/人设一致
□ 五官特征（眉/眼/鼻/唇）标志性特点一致
□ 发型发色、发量质感一致
□ 标志性特征（痣/疤/配饰）位置、形状正确
□ 整体气质和人设匹配
□ 相似度≥70%
```

## 【三、画风质感检查】
```
□ 画风类型符合项目要求（2D/三渲二/3D写实）
□ 渲染质感达标，无廉价感
□ 材质表现正确（皮肤/布料/金属区分清晰）
□ 和同剧其他角色画风统一
```

## 【四、五官妆容检查】
**通用项：**
```
□ 左右五官基本对称，无明显偏差
□ 五官比例正常，无夸张变形
```
**男角色：**
```
□ 眉形硬朗，符合人设
□ 无明显眼妆、卧蚕
□ 唇色自然，无妆感
□ 皮肤哑光，无油光
□ 整体无女性化、网红脸、塑料感
```
**女角色：**
```
□ 眉形柔和，符合人设
□ 眼妆自然有层次，不浓
□ 唇色均匀，质感正确
□ 腮红、高光位置正确
□ 皮肤清透，不假面
□ 整体无网红脸、塑料感
```

## 【五、构图光影检查】
```
□ 景别符合分镜要求（特写/近景/中景/全景）
□ 主体在画面合适位置，不偏不歪
□ 光线方向、软硬符合场景氛围
□ 人物面部曝光正常，不阴阳脸
□ 背景不杂乱，不抢主体
□ 有适当景深/虚化，突出人物
```

## 【六、剧情适配检查】
```
□ 表情符合对应剧情情绪
□ 动作、姿态符合分镜要求
□ 服饰、场景和剧情时段匹配
□ 画面有足够冲击力（钩子镜头专用）
```

## 【最终结论】
```
□ 合格，直接可用
□ 微调可用，标注修改点
□ 不合格，重制
□ 废图，重新生成
```
