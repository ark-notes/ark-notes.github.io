# 短剧知识库 · 数据运营

> 来源：豆包《AI短剧运营全体系》

## 一、⭐ 关键指标（按权重）

```
1. 前3秒跳出率（权重最高，决定进不进下一级流量池）
   路径：抖音创作者后台→数据中心→作品数据→播放完成度→0-3秒留存
   合格：<70%；优秀：<60%
2. 整体完播率（第二权重）
   合格≥30%；优秀≥40%；爆火≥50%
3. 互动率（点赞+评论+转发/播放）
   合格≥3%；优秀≥5%
4. 关注率（关注数/播放）
   合格≥2%；优秀≥5%
5. 付费转化率（付费用户/播放）
   合格≥1%；优秀≥2%
```

## 二、⭐ 什么数据该投流/该放弃

**可投流（满足前2条就测）：**
```
1. 自然完播率≥30%，前3秒跳出<70%
2. 关注率≥2%，互动率≥3%
3. 投流测试ROI≥1:1，就能放量
```
**绝对放弃（满足任意一条）：**
```
1. 前3秒跳出>75%，改3版钩子都救不回
2. 完播率<20%，怎么调都上不去
3. 投流测试ROI<0.7
4. 连续3集播放不过500（账号标签没打好或题材不行）
```
**原则：用自然流量测内容，用投流放大结果；内容不行，投多少亏多少。**

## 三、⭐ 投流（三阶法）

```
第一阶段 测试期（300-500元）：
  选3集数据最好的，每集投100元DOU+，定向对标粉丝，跑24小时
  ROI<0.7直接停，ROI>1留下继续测
第二阶段 放量期（每天1000-5000元）：
  选1-2个最优素材，转巨量，预算每天加10%-20%
  ROI稳定>1:1.2就加预算
第三阶段 稳定期（按ROI动态调整）：
  ROI>1.5 大胆放量（每次+20%）
  ROI 1-1.2 维持+优化素材
  ROI<0.9 立刻减预算换素材
铁律：每天调整ROI间隔>30分钟，频繁调价废计划
```

## 四、⭐ 视频生命周期

```
爆发期（0-7天）：占总播放60%-70%，前3天决定生死
稳定期（7-30天）：靠搜索和合集持续，维护评论做转化
长尾期（30天+）：每天零散播放，爆款长尾能持续3-6个月
红果分账模式长尾尤其明显，爆款能拿好几年分成
```
