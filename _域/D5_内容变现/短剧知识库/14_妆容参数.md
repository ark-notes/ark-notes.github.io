# 短剧知识库 · 妆容参数（毫米级）

> 来源：豆包专家手册（第四部分）

## 一、⭐ 男妆具体参数

```
· 眉部：自然黑色，眉峰角度15°，眉尾下垂不超眉峰2mm，
        填充度70%，边缘虚化，不画硬框
· 眼部：无眼影，黑色内眼线仅画眼尾1/3，长度5mm，
        睫毛自然不夹翘，无卧蚕提亮
· 鼻部：灰棕色鼻侧影，从眉头延伸至鼻尖，宽度2mm，
        山根处加深，鼻头哑光提亮
· 唇部：裸粉色哑光唇膏，唇线模糊，不刻意画唇峰，唇面无光泽
· 皮肤：哑光粉底液，自然白，遮瑕度60%，保留纹理，T区控油
· 修容高光：下颌线+颧弓内收阴影宽3mm；
            哑光高光仅眉骨、鼻梁中段，面积≤指甲盖
```

## 二、⭐ 女妆具体参数

```
· 眉部：深棕色，平眉/弯月眉，眉峰弧度10°，
        眉尾长于眼尾3mm，填充度80%，眉头虚化
· 眼部：大地色眼影晕染眼窝（不超眶骨）；外眼角加深；
        卧蚕珠光提亮宽2mm；睫毛纤长，翘度30°
· 鼻部：浅棕色鼻侧影，山根自然过渡，鼻头珠光高光
· 唇部：豆沙/蜜桃色唇釉，玻璃质感，唇珠提亮，唇峰明显，嘴角微扬
· 皮肤：清透水光粉底，粉一白，遮瑕度40%，
        苹果肌打蜜桃色腮红直径3cm
· 修容高光：下颌线轻扫阴影；水光高光打眉骨、鼻尖、
            唇珠、苹果肌上方
```

## 三、⭐ 画风选型

| 画风 | 适合题材 | 优点 | 缺点 | 适用账号 |
|---|---|---|---|---|
| 2D手绘/平面 | 古风搞笑、甜宠Q版 | 成本低、快、崩图少 | 质感弱、难出大爆款 | 低成本矩阵号，日更10集+ |
| **三渲二** | 玄幻、仙侠、战神、动作 | 兼顾质感和效率，打斗强，**当前主流爆款** | 一致性略难控 | 中成本主力号，追播放量 |
| 3D写实 | 都市霸总、悬疑、女频情感 | 真实感强、变现强 | 成本高、慢、崩图多 | 高成本精品号，高转化 |

**选择标准：**
```
· 男频玄幻/战神 → 三渲二
· 女频都市/霸总 → 3D写实
· 搞笑/低成本试错 → 2D
```

## 四、⭐ 怎么让画面"精致"（不是细节堆满）

**精致的核心是层次和秩序，不是细节多：**
```
1. 光影分层：三点布光（主光+辅光+轮廓光），光比1:2，
            人物边缘有轮廓光，背景虚化，前后景分离
2. 色彩统一：全片主色调≤3种，同场景统一
            （如都市冷蓝调、仙侠暖金调）
3. 留白构图：人物占画面1/3-1/2，背景干净，不塞满
4. 材质准确：区分材质（丝绸柔亮/金属冷反光/布料纹理）
            → 材质对比比细节多更显精致
5. 焦点清晰：焦点落在眼睛，前后景虚化，有虚实层次
```

**→ ⭐ 这解决了我之前"精致≠细节多"的困惑（用户早就点破过）！**
