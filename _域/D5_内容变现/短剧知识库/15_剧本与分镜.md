# 短剧知识库 · 剧本与分镜

> 来源：豆包专家手册（第五部分）

## 一、⭐ 单集60秒标准结构（精确到秒）

```
0-3秒   钩子：冲突前置/悬念抛出/打脸结果 → 直接给最强冲突
3-15秒  压抑铺垫：反派嚣张、主角受辱、背景交代 → 把情绪压下去
15-30秒 反转启动：主角亮底牌/帮手出现/意外转折 → 情绪回升
30-45秒 高潮爽点：打脸释放/复仇成功/甜宠暴击 → 情绪最高点
45-55秒 收尾+新冲突：解决当前问题，抛出下一个麻烦
55-60秒 留钩+引导：悬念问句/下集预告 → 引导关注
```

## 二、⭐ 3秒钩子（4种万能公式，爆率90%）

```
1. 打脸前置式：直接放结果
   例："千亿总裁假扮保安，被前女友当众甩巴掌"
2. 悬念提问式：反差疑问
   例："为什么全城首富见到这个清洁工，当场跪下？"
3. 冲突爆发式：激烈画面+台词
   例："婚礼现场，新娘当众给新郎戴绿帽"
4. 利益诱惑式：好处前置
   例："看完这集，你也能三天赚一百万"
```

**合格标准：** 3秒内必须同时出现「人物+冲突+反差」，
台词≤15字，画面必须人物近景/特写。

## 三、⭐ 规格参数

```
· 时长：标准58-62秒，误差≤5秒（最短≥55，最长≤65）
· 镜头数：每集12-15个，平均4-5秒一个
· 前3秒：1个特写镜头（钩子）
· 同框人数：控制在3人以内，超过3人必崩
   → 方法：先单独生成每个人，再合成
   → 替代：多人对话拆成正反打单人镜头
```

## 四、剪辑/配音/字幕/音乐

**配音：**
```
· 男频语速180字/分钟，沉稳男声
· 女频语速190字/分钟，甜御女声
· 高潮部分语速加快10%，反派语气带嚣张感
· 每句台词间隔0.3秒
```

**剪辑：**
```
· 硬切为主，不用花哨转场
· 高潮切换加快，铺垫稍慢
· 每集加3-5个关键音效（巴掌声/抽气声/脚步声）
```

**字幕：**
```
· 黑体，28-32号，白色加黑边
· 位置：画面下方1/5处，不挡脸
· 每行≤12字，重点台词加红色高亮
```

**音乐：**
```
· BGM纯音乐，音量比人声小20%
· 铺垫舒缓，高潮换燃/虐BGM，钩子部分音乐骤停
· 用平台免费版权音乐
```
