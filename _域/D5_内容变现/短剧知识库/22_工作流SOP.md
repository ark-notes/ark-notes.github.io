# 短剧知识库 · 工作流/SOP（豆包原版）

> 来源：豆包《AI短剧操盘手·完整工作方法论》

## 一、⭐ 5大阶段（前一阶段验收不过，绝不进下一阶段）

```
立项筹备期 → 小样测试期 → 批量生产期 → 运营迭代期 → 收尾复盘期
```

## 二、⭐ 30天排期（100集标准项目）

| 阶段 | 天数 | 做什么 | 产出 | 验收标准 |
|---|---|---|---|---|
| **立项筹备** | 第1天 | 需求拆解、3个对标账号拆解、选题定位、大纲、人设初稿 | 项目定位表、大纲、人设初稿 | 选题符合近30天爆款赛道 |
| | 第2天 | 前3集剧本+分镜表、节奏校准、钩子优化 | 前3集剧本分镜表 | 3秒钩子到位、60秒结构完整、有反转、结尾留钩 |
| | 第3天 | 主角人设图3版选优、配角/反派、场景图2张 | 定版人设图、场景基准图 | 符合人设参数、无崩图、画风统一 |
| **小样测试** | 第4天 | 第1集全流程：生图+修图+配音+剪辑+字幕+BGM | 第1集成品(1080P) | 58-62秒、音画同步、爽点到位 |
| | 第5天 | 第1集优化、2-3集制作、内部3人测试 | 前3集成品、测试报告 | 3集画风一致、无尿点 |
| | 第6天 | 发布前3集、盯2小时数据、出调整方案 | 数据报告、优化方案 | 5000播放、完播率≥30%、跳出<70% |
| **批量生产** | 第7-14天 | 日更5集，三线并行，每日质检 | 每日5集、质检表 | 日更准时、相似度≥80% |
| | 第15-21天 | 日更4集，按周数据调方向 | 每日4集、周报告 | 完播率稳定30%+、日增粉≥500 |
| | 第22-30天 | 日更3集，投流测试，做衍生 | 每日3集、投流报告 | 投流ROI≥1:1.5 |
| **收尾复盘** | 第31天 | 全剧复盘、问题总结、资产沉淀 | 复盘报告、模板包 | 有3+可落地改进点 |

## 三、⭐ 7个核心SOP

**SOP1 需求对接与立项**
```
输入：用户需求 → 拆解→补全→出方案 → 输出：立项确认表
1. 收需求，拆核心目标+约束 2. 补全默认参数 3. 确认核心项 4. 立项目排期
```

**SOP2 剧本创作与分镜**
```
1. 按60秒结构写单集 2. 拆12-15个镜头填分镜表
3. 卡时长，每句台词标秒数 4. 自检：钩子/反转/留钩
```

**SOP3 人物与场景生成**
```
1. 按人设写标准提示词（正向+负面）
2. 生成3版不同seed
3. 按 checklist 质检，选最优
4. 定基准图，同步生成侧面/半侧面
5. （可选）训练人物小LoRA，权重0.7
```

**SOP4 单集制作**
```
按分镜批量生图 → 修图(一致性/崩点/尺寸) → 配音 → 剪辑 → 字幕+BGM → 终检
```

**SOP5 批量生产**
```
1. 固定提示词模板、基准图、LoRA
2. 批量生成同场景，复用场景
3. 流水线：生图组→修图组→剪辑组
4. 每日全检一致性，抽检画质
```

**SOP6 发布与数据迭代**
```
1. 发布前3集，盯2小时 2. 数据不达标按优先级排查
3. 调整后再测 4. 每周复盘
```

**SOP7 项目复盘**
```
1. 拉全量数据，找最高/最低单集
2. 分析爆/扑原因 3. 总结可复用经验
4. 更新模板/checklist/SOP
```

## 四、⭐ 可复用模板清单（10个）

```
立项类：《选题定位表》《人设设计模板》
提示词类：《正向提示词标准模板》《负面词标准清单》
剧本分镜类：《60秒剧本结构模板》《分镜表标准模板》
质检类：《人物图质检Checklist》《单集成品质检表》
运营类：《数据监测表》《每日生产排期表》
```
