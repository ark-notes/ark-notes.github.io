## 二、⭐ 豆包的"效果验收"框架

**验收要看的点（豆包原版）：**
```
合格点：
· 脸型窄长协调，下颌线有锐度
· 冷调雾面皮肤质感稳定，不假面不油腻
· 五官比例舒展
· 眼下专属痣清晰（记忆点）
· 原创辨识度足够
· 气质清冷疏离，和人设匹配

不足点：
· 下颌缘切割感
· 狼尾的蓬松凌乱感
· 眼尾上扬锋利度
→ 未达"一眼抓人"的强冲击力
```

## 三、⭐ 可微调提升点（豆包给的具体项）

```
1. 脸型：下巴略宽 → 收紧下颌缘，下巴微翘弧度强化，
        保留骨骼感，避免尖锥脸
2. 发型：狼尾不够明显 → 发顶蓬松度提高，
        加几缕细碎刘海自然垂落眉骨（增强破碎感）
3. 妆容：眼尾上扬偏弱、卧蚕不够 → 调整；
        山根到眉骨衔接更立体，鼻侧影更自然；
        嘴唇略厚 → 收薄，唇峰更分明（疏离感更强）
```

## 四、⭐ 版权判断（豆包给的标准）

```
侵权只看两点：
1. 实质性相似（核心五官/脸型/标志性特征高度重合，
   观众一眼对应上原角色）
2. 以营利为目的（短剧/引流/卖素材）

✅ 安全的参考：只借鉴画风、光影、审美比例、精致度
❌ 危险：1:1 复刻某张原图的脸和角色

判断结论（豆包给的）：
"风格借鉴 + 原创五官组合，
 没有和任意参考图形成实质性相似
 → 低风险，可用于红果短剧上传"
```

## 五、⭐ 豆包的工作方式（方法论）

```
① 参考图分类：近景男主图 = 风格锚点；
              全身图 = 只保留服装结构
② 每次只变一个变量，控制变化幅度
③ 不用全身构图硬做，先半身
④ 图生图微调力度有限，不要过度重复
⑤ 迭代边际效益判断：连续多轮微调，收益递减
```
