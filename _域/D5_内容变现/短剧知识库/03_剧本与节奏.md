# 豆包知识库 · 剧本与节奏

---

## 一、题材选择（豆包建议）

```
选红果男频最稳的「废土异能拆解流」，
已跑出多部中爆作品，受众稳定，爽点明确，
Arkie 也好做画面。
```

## 二、基础信息

**剧名备选：**
```
1.《废土拆解王》（直白爽点型，新手最稳）
2.《我在废土靠拆解成神》（悬念升级型）
3.《被扔熔炉后，我拆了整个避难所》（钩子型，吸点击）
```

**男主名：** 林默（普通好记，底层修理工身份感强）

## 三、⭐ 24集结构（豆包原版）

| 段落 | 集数 | 核心内容 |
|---|---|---|
| **开篇钩子** | 1-3 | 林默被同事陷害扔进废料熔炉，濒死觉醒异能，反杀追兵逃出避难所 |
| **发育爽点** | 4-8 | 躲进贫民窟，靠拆解机械谋生，小有名气，悄悄升级异能 |
| **中期高潮** | 9-15 | 财团派人抓捕，林默正面拆解对方机甲，一战成名，发现被陷害的真相 |
| **收官** | 16-24 | 潜入中层避难所→杀回顶层→推翻财团，建立新秩序 |

**规格：24集，每集2分钟，总时长48分钟**

## 四、⭐ 节奏设计（豆包原版）

```
· 一集多长：2 分钟
· 镜头：6-10 秒一个
· 小反转：每 3-5 个镜头
· 复杂镜头（打斗/多人）：用剪辑+音效掩盖
· 闪回镜头：做得更短更炸（6秒被关门、6秒拍门、10秒倒下）
```

## 五、⭐ 制作技巧（豆包原版）

```
"Arkie 只负责出稳定的短镜头，
 2 分钟完整感靠剪辑完成。"
例：
· Arkie 生成 6 秒男主冷笑
· 剪映里放慢一点
· 加旁白："距离极寒降临，还有 15 天。"
· 加字幕 + 低频悬疑音乐 + 日历特写
· = 看起来像一个完整镜头
```
