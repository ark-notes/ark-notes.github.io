## 六、数据分析与决策题（20分）

**11. 排查顺序**
```
数据：播放6000，前3秒跳出76%，完播22%，互动2%
第一步先改：前3秒钩子
核心问题：钩子失败（跳出76%>70%红线，权重最高）
排查顺序：① 前3秒跳出率 → ② 完播率 → ③ 互动率
```

**12. 投流决策**
```
A集（完播35%/ROI0.8）→ 直接放弃（ROI<0.9）
B集（完播28%/ROI1.1）→ 优化再测
C集（完播42%/ROI1.3）→ 直接放量投
```

**13. 综合情景决策**
- 答案：**B（优化钩子和结尾引导，再测3天）**
- 理由：A放弃太早（跳出68%<75%、完播28%接近30%，还有救）；
  C大额投流错（数据未达标，内容不行投多少亏多少）；
  B对：先优化钩子（跳出接近红线）+ 结尾引导（关注1.5%<2%），
  再测3天，达标再投流。
