# 短剧知识库 · 选题与对标

> 来源：豆包《AI短剧运营全体系》

## 一、⭐ 找"能爆"题材（三步定位法）

```
第一步 看增速，找上升赛道：
  拉近14天榜单，统计各题材上榜数量增速
  增速>30%=上升期；<10%=成熟期；负增长=过气期
  → 优先选"上升中期"（已有3-5部爆款，还没扎堆）

第二步 看供给，找缺口赛道：
  播放量高但新作少 = 需求>供给，优先做
  播放量高但每天几十部新作 = 红海，慎入

第三步 看验证，找可复制赛道：
  至少3个不同账号同题材都爆 = 赛道红利
  只单个账号爆 = 偶然，别碰
```

**黄金判断：** 用户搜索量周环比涨50%+、新作数量涨20%+ → 即将爆的赛道，立刻进场。

## 二、⭐ 去哪看榜单

**官方渠道（免费、最准）：**
```
1. 抖音创作者服务中心 → 数据中心 → 短剧榜单（近30天）
2. 红果短剧创作者后台 → 热度榜单（周榜/月榜）
3. 央广网·微剧中国（覆盖抖音+快手，每周更新）
```
**第三方工具：**
```
1. DataEye短剧观察（日更7大榜单，含抖音漫剧榜、红果热榜）
2. superline漫剧榜（实时追踪，有爆发/衰退预警）
3. 新抖/飞瓜数据（账号粉丝/播放/变现）
```
**新人用法：** 每天10分钟扫TOP20，记录重复出现的题材/钩子/人设。

## 三、⭐ 拆解对标账号（两层拆解法）

**表层（10分钟，抄形式）：**
```
· 基础信息：粉丝量、更新频率、单集时长、总集数、发布时间
· 包装信息：头像/昵称/简介/封面风格/标题格式
· 内容结构：钩子位置、反转位置、留钩方式、镜头数量
```
**深层（核心，抄逻辑）：**
```
· 人设：主角身份、反差点、记忆点、反派、配角功能
· 爽点：每集爽点类型、压抑时长、打脸方式、情绪密度
· 节奏：3秒钩子台词、15秒反转点、30秒高潮点、留钩话术
· 变现：变现方式、引导位置、转化话术
```
**拆解模板：** 找3个同题材爆款，列成表格，**重合部分=爆款共性（直接抄），差异部分=可优化点**。

## 四、⭐ 判断题材"过气/上升"

| 指标 | 上升中 | 成熟期 | 过气了 |
|---|---|---|---|
| 新作数量增速 | 周环比+30%以上 | ±10% | -20%以上 |
| 平均完播率 | 上升，>35% | 稳定30%左右 | 下滑，<25% |
| 投流ROI | 普遍>1:1.2 | 头部能正 | 大部分亏 |

**辅助信号：**
```
上升中：刷十条有1条同题材，评论区求更多
过气了：刷十条有5条以上，评论区骂"又是老套路"
```

## 五、⭐ 稳的赛道

**男频（按稳度）：**
```
1. 赘婿/战神回归 ← 永恒TOP1，爆率最高
2. 都市神医/风水 ← 下沉市场，付费意愿强
3. 系统/神豪开挂 ← 爽点密集，完播率高
4. 都市逆袭/复仇 ← 代入感强
5. 玄幻/宗门废柴崛起 ← 三渲二首选
```
**女频（按稳度）：**
```
1. 闪婚/先婚后爱 ← 女频基本盘
2. 重生/复仇虐渣 ← 情绪张力强
3. 总裁独宠/契约恋爱 ← 流量密码
4. 萌宝助攻/带娃嫁大佬 ← 关注率高
5. 真假千金/替嫁逆袭 ← 适合做长剧
```
**新手首选：** 男频赘婿战神、女频闪婚虐渣（模板成熟、容错最高）。
