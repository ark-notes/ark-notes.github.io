# 短剧知识库 · 男频/女频爽点本质（核心）

> 来源：豆包导出的表格（code_20261005.csv）

| 维度 | 男频爽点本质 | 女频爽点本质 |
|---|---|---|
| **核心方向** | 向外征服：权力、资源、地位的跃迁 | 向内确认：情感、偏爱、掌控感的满足 |
| **爽点公式** | 我比你强 → 你看不起我 → 我碾压你 → 众人膜拜 | 他只爱我 → 别人看不起我 → 他护着我 → 众人羡慕 |
| **核心载体** | 身份/实力/财富/小弟 | 爱情/婚姻/孩子/男性偏爱 |
| **打脸对象** | 同级对手、看不起自己的人、反派势力 | 渣男、绿茶、婆婆、情敌 |
| **终极追求** | 成为最强者，掌控规则 | 成为唯一偏爱，拥有稳定幸福 |

**用法：** 选题材先定频向 → 按对应爽点公式设计剧情。
