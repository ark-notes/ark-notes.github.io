## 一、图片类
1. 画风 → 判据：无毛孔/无纹理+有3D体积 → 结论：**三渲二**
2. 合格 → 判据：小插座不遮主体 → 结论：**能用（微调）**
3. 废图 → 判据：手部六指/畸形=一票否决 → 结论：**废图，重制**
4. 妆容 → 判据：男妆应无眼影眼线卧蚕 → 结论：**不到位，多了眼影+眼线+卧蚕**
5. 问题 → 判据：下颌圆/眉细/眼妆唇红+眼过大尖下巴+无毛孔油光 → 结论：**三项全中**
6. 一致性 → 判据：发色棕→金、银肩甲、脸变尖 → 结论：**核心差异=这三项，必须改回**
7. 模糊 → 判据：轮廓可辨细节不清 → 结论：**中度模糊→退回重生成，不能判妆容**
8. 构图 → 判据：要求近景正面平光；实测45度侧+侧逆光+面暗+中景 → 结论：**不符合**
9. 综合 → 判据：logo半透明切衣角不遮脸 → 属【可裁】 → 结论：**微调可用**
10. 优先级 → 结论：**①钩子→②唇色→③字幕**
