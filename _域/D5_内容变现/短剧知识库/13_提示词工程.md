# 短剧知识库 · 提示词工程（核心）

> 来源：豆包专家手册（第三部分）

## 一、⭐ 人物提示词标准结构（按权重排序）

```
1. 画风定性（第一优先级）：画风类型+渲染方式+画质标准
   例：3D写实风格，UE5渲染，电影质感，8K超高清
2. 主体核心：年龄+性别+身份+核心气质
3. 五官细节：脸型+眉+眼+鼻+唇+皮肤
4. 发型发色：形状+长度+发色+质感
5. 服饰配饰：款式+材质+颜色+配饰
6. 构图光影：景别+角度+光线+构图
7. 负面排除：统一负面词清单
```

## 二、⭐ 正向词权重法则

```
权重占比：画风定性25% > 主体核心25% > 五官细节25%
         > 发型服饰15% > 构图光影10%
排序原则：大类在前，细节在后；核心特征在前
实操：最想要的效果写最前
数量：核心正向词≤15个（多了AI混乱，优先级抵消）
```

## 三、⭐ 负面词标准清单（越全越好）

**人脸畸形类：**
```
畸形脸，大小眼，歪嘴，龅牙，牙齿不齐，双下巴，脸部变形，
五官不对称，眼睛无神，瞳孔涣散，眼袋，黑眼圈，皱纹，
老年斑，塌鼻梁，朝天鼻，厚嘴唇
```
**皮肤质感类：**
```
塑料感，硅胶感，假脸，网红脸，油光，毛孔粗大，痘印，
瑕疵，皮肤粗糙，假面感，过度磨皮
```
**肢体结构类：**
```
多手指，少手指，畸形手，六指，肢体扭曲，比例失调，
大头娃娃，短腿，长脖子，歪头
```
**画面质量类：**
```
模糊，像素低，噪点，过曝，欠曝，水印，字幕，logo，
变形，拉伸，马赛克，颗粒感
```
**风格不符类：**
```
卡通，Q版，二次元，手绘，素描，油画，抽象，恐怖，血腥
```

## 四、⭐ 防女性化/网红脸/塑料感

| 问题 | 做法 |
|---|---|
| **防女性化** | 加强：方下颌、粗眉骨、喉结、胡茬、宽肩、窄胯、肌肉线条、硬朗气质<br>删柔化词：精致/柔美/漂亮/可爱<br>光影：硬光侧光，突出骨相 |
| **防网红脸** | 把"网红/仙女/精灵"换"自然/真实/写实/原生态"<br>比例：眼裂≤32mm，鼻子不过度翘挺，下巴不过尖<br>加真实感：保留皮肤纹理，卧蚕不过宽，睫毛不夸张 |
| **防塑料感** | 加：哑光皮肤、皮肤纹理、毛孔细腻、真实肤质、轻微瑕疵<br>减：光滑无瑕、完美皮肤、零瑕疵<br>光影：自然光，三点布光 |

## 五、⭐ 统一多角色画风（6法）

```
1. 共用画风前缀：所有角色第一句完全一样
2. 统一画质参数：同一套光影描述
3. 统一审美体系：全中式写实 / 全韩系（不混）
4. 基准图复用：先出主角基准图，配角用主角图图生图
5. 模型/Lora固定：同一基础模型+同一画风Lora
6. 种子值接近：同场景同角度，seed前5位相同
```
