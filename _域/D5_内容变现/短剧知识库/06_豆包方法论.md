## 二、⭐ 豆包的工作模式（我要学的）

### 1. 先诊断，再给方案
```
用户发图 → 豆包先说：
"当前生成偏向纯写实3D建模展示，
 和参考的短剧男主画风偏差在：
 ① 质感太工业建模，缺半写实半漫的精致感
 ② 面部没有妆容层次
 ③ 像素模展示"
        ↓
= 先精准描述"差在哪"，再开方
```

### 2. 一次只解决一个变量
```
"固定生图模板，每次只换一个变量"
"控制每次变化幅度"
```

### 3. 给"可执行的验收标准"
```
不说"要好看"，
说"合格点：脸型窄长、下颌线有锐度、
    冷调雾面不假面、眼下痣清晰"
```

### 4. 考虑合规/版权
```
主动给"风险等级 + 判断依据"
```

### 5. 尊重工具限制
```
"Arkie 界面单一，只有上传入口，
 没有画质选项 → 8K 达不到"
```
