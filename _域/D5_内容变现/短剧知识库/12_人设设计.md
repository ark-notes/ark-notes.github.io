# 短剧知识库 · 人设设计

> 来源：豆包专家手册（第二部分）

## 一、⭐ 主角设计万能公式

```
核心身份 + 反差特质 + 执念目标 + 专属符号 + 微小缺点
```
| 项 | 说明 | 例 |
|---|---|---|
| 核心身份 | 观众一眼 get 的基础设定 | 赘婿/战神/神医/千金 |
| 反差特质 | 和身份形成强反差 | 底层赘婿=隐藏战神；柔弱千金=顶级黑客 |
| 执念目标 | 贯穿全剧的动机 | 为妻复仇/夺回家产/治好恩人 |
| 专属符号 | 视觉记忆点 | 眼角痣/眉骨疤/左手戒指/固定发型 |
| 微小缺点 | 无伤大雅的小瑕疵 | 战神怕狗/医仙路痴 → 拉近距离 |

**反模板化核心：** 给主角加一个"非爽点属性"的个人习惯
（紧张时转戒指、思考时摸下巴）→ 记忆点强3倍。

## 二、⭐ 男主要"好看"的关键（五官硬标准）

```
· 脸型：折叠度高的窄方脸/长鹅蛋，下颌线清晰成120度，
        颧弓不外扩，下巴宽度≈嘴宽
· 眉毛：剑眉，眉峰在瞳孔外侧正上方，眉尾微扬15度，
        眉粗0.8-1cm，眉长≈眼裂长+5mm
· 眼睛：丹凤眼/内双桃花眼，眼裂长28-32mm，内眼角尖，
        外眼角略高于内眼角2mm，黑瞳占比2/3
· 鼻子：山根高度4-5mm，鼻背直，鼻头圆润有肉，
        鼻翼宽度=内眼角间距
· 嘴唇：薄唇，M型唇峰明显，唇色自然粉，
        上唇:下唇厚度=1:1.5
· 皮肤：哑光质感，冷白皮/小麦色，毛孔细腻，无油光，
        保留轻微皮肤纹理
```

**男妆核心：做减法，突出骨相，无妆感**
```
· 底妆：哑光粉底液，遮瑕度60%，不假面
· 修容：鼻侧影+下颌线阴影，宽度2-3mm，过渡自然
· 高光：仅眉骨、鼻梁中段，哑光高光，面积不超指甲盖
· 眼妆：无眼影，只画内眼线眼尾1/3，长度5mm
```

## 三、⭐ 女主要"好看"的关键

```
· 脸型：流畅鹅蛋脸/心形脸，软组织饱满，下颌线柔和，下巴圆润
· 眉毛：平眉/弯月眉，眉峰弧度10度，眉尾长于眼尾3mm，眉粗0.6-0.8cm
· 眼睛：圆杏眼/桃花眼，眼裂长26-30mm，卧蚕宽2-3mm，
        眼尾微扬，黑瞳占比2/3
· 鼻子：山根高度3-4mm，鼻背微翘，鼻头小巧，
        鼻翼窄于内眼角间距2mm
· 嘴唇：饱满M唇，唇珠明显，上唇:下唇厚度=1:2，豆沙/蜜桃色
· 皮肤：水光质感，冷白皮/粉白皮，通透有光泽，苹果肌饱满
```

**女妆核心：提气色，弱化骨相，突出幼态/柔美**
```
· 底妆：清透粉底液，遮瑕度40%，带水光感
· 腮红：蜜桃色，打苹果肌最高点，直径3cm
· 高光：眉骨、鼻尖、唇珠、苹果肌上方，水光高光
· 眼妆：大地色眼影晕染眼窝，卧蚕珠光提亮，睫毛纤长自然翘
```

## 四、反派/配角设计
```
反派：坏得有逻辑，压迫感有载体
· 动机：立场/利益/仇恨驱动（不是为坏而坏）
· 符号：金丝眼镜+拐杖/阴笑/固定手势
· 能力：前期比主角强
· 结局：被打脸，方式对应他的嚣张点

配角：功能单一，不抢戏，有记忆点
· 每个配角承担1-2个功能：搞笑/传信息/助攻/制造冲突
· 配角颜值不能超过主角，穿搭不能比主角亮眼
```

## 五、⭐ 记忆点怎么造

| 类型 | 最优位置 | 禁忌 |
|---|---|---|
| **痣** | 眼角下1mm（泪痣）、唇边右侧、锁骨中间 | 鼻子上、脸颊大面积、超2颗 |
| **疤** | 眉骨横疤、下颌线细疤、手背刀疤 | 大面积毁容疤、脸上竖疤 |
| **发型** | 和身份强绑定，全程不变 | 频繁换发型、发色花哨 |

**高阶记忆点：专属小动作（摸戒指/转钢笔/挑眉）→ 留存率高50%**
