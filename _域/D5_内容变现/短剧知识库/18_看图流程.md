# 短剧知识库 · 看图流程（豆包标准，解决"视觉弱"）

> 来源：豆包《AI短剧人物图·标准看图流程（新人版）》
> 原则：「先淘汰、再合格、后优化」，不浪费1秒在废图上
> 所有判断均有【可观测的明确判据】，不凭感觉

---

## 一、⭐ 固定7步流程（严禁跳步，前一步不合格直接终止）

```
第1步（1秒扫）：废图排查 → 崩脸/畸形/穿帮/模糊/水印 → 直接丢
第2步（3秒）：人物一致性 → 是不是这个角色，和人设对不对得上
第3步（5秒）：画风匹配 → 2D/三渲二/3D写实，和项目匹配吗
第4步（10秒）：五官细节 → 眉/眼/鼻/唇逐部位看，符合人设参数吗
第5步（5秒）：妆容质感 → 男妆/女妆到位吗，有网红脸/塑料感吗
第6步（5秒）：构图光影 → 景别/角度/光线符合分镜吗
第7步（5秒）：剧情适配+优化点 → 表情动作能用吗，标注可微调处
```
**训练要求：单张图完整判断 ≤30秒；废图判断 ≤3秒。**

## 二、⭐ 画风判断（100%准的核心判据）

**核心方法：放大看脸颊皮肤 + 材质反光，3秒定类**

| 画风 | 核心判据（必中）| 辅助特征 | 误区提醒 |
|---|---|---|---|
| **2D平面/手绘** | 无3D体积感，光影平涂/手绘笔触，有明确轮廓线，平面透视 | 画笔质感，色彩块面强，材质无真实反光 | 别把三渲二的描边当2D线条 |
| **三渲二** | 有3D体积感，但皮肤/材质**完全没有真实物理纹理**，光影简化柔和 | 边缘可能有细描边，饱和度高，**毛孔/皮肤纹理完全消失** | 写实风三渲二易和低质3D写实混 |
| **3D写实** | 皮肤有**真实毛孔/细微纹理/自然瑕疵**，材质真实物理反光 | 细节丰富，光影自然过渡，有景深 | 高磨皮3D写实易和三渲二混 |

**⭐ 操作技巧：放大200%，看苹果肌——**
```
有毛孔/细碎纹理 = 3D写实
完全光滑像画出来的 = 三渲二
平涂有笔触 = 2D
```

## 三、⭐ 妆容到位标准（男女各5条）

**男妆到位（5条全满足）：**
```
1. 妆感：无妆感，看不出化妆痕迹
2. 眉部：眉形清晰，边缘不生硬，颜色和发色统一，无夸张眉粉感
3. 眼周：无明显眼影、眼线，睫毛自然，无卧蚕提亮
4. 唇部：唇色自然偏粉/裸色，无唇釉反光，唇线不刻意
5. 皮肤：哑光质感，无油光，修容自然，高光仅在骨点且不明显
```
**女妆到位（5条全满足）：**
```
1. 妆感：清透自然，不假面，气色提升但不厚重
2. 眉部：眉形柔和，颜色自然，眉头虚化，不生硬
3. 眼周：眼影有层次但不浓，卧蚕自然不夸张，睫毛纤长不浓密
4. 唇部：唇色均匀，有光泽但不油，唇峰明显
5. 皮肤：水光感但不油，腮红在苹果肌，高光自然
```

**不合格典型表现：**
```
男妆：有眼影、唇红、皮肤油亮、眉形过细
女妆：假面感、腮红过重、卧蚕像毛毛虫、眼影发黑发脏
```

## 四、⭐ 看出「偏女性化/网红脸/塑料感」

**男角色偏女性化（满足3条及以上=偏女化）：**
```
1. 脸型：下颌线圆润无棱角，下巴尖，没有男性方硬感
2. 眉部：眉形细、弯，没有硬朗感，眉峰平缓
3. 眼部：眼睛大而圆，卧蚕明显，眼神柔和无锐气
4. 唇部：嘴唇饱满偏厚，唇色偏红，唇珠明显
5. 皮肤：光滑无瑕，水光感强，完全没有男性皮肤的粗糙感
6. 轮廓：肩窄，脸部线条柔和，骨骼感弱
```
**网红脸（满足3条及以上）：**
```
1. 比例：眼睛过大（占脸宽>1/3）；下巴过尖呈锥子形
2. 五官：通天鼻、卧蚕过宽（>3mm）、苹果肌过度饱满
3. 皮肤：过度磨皮，完全没纹理，白得发光，假面感强
4. 辨识度：五官没特点，和常见网红模板高度相似
5. 细节：睫毛夸张，眼线粗，唇色鲜艳
```
**塑料感（满足2条及以上）：**
```
1. 皮肤：完全没有毛孔纹理，像塑料/硅胶，均匀得不正常
2. 反光：油光均匀，高光弥散，没有真实反光差异
3. 边缘：五官边缘模糊柔和，像塑料人偶的打磨感
4. 质感：整体像塑胶玩具，僵硬不自然
5. 色彩：肤色发灰发白，没有血色
```

## 五、⭐ 对比两图差异（6步法）

```
第1步 前置校验：角度差≤30°、景别一致、光影方向相同
        → 缩放到同尺寸，并排摆放，左右切换看
第2步 整体层面对比：脸型轮廓/发型发色/肤色深浅/整体气质
        → 第一眼看不出是同一个人 = 直接不合格
第3步 五官逐部位（按眉→眼→鼻→唇）
第4步 标志性细节：痣/疤位置、配饰、服饰
第5步 画风光影：画风类型/光影方向软硬/色彩色调
第6步 差异分级：
  · 核心差异（必须改）：脸型变、五官特征变、标志特征没了、画风变
  · 次要差异（可微调）：唇色深浅、眉毛细微差别、光影强弱
  · 可接受差异：角度透视变化、细微表情差异
```
**相似度标准：≥85=高度一致；70-84=基本一致微调可用；＜70=不一致重制。**

## 六、⭐ 图片模糊/压缩处理（3级，绝不超清晰度判断）

| 级别 | 表现 | 处理 |
|---|---|---|
| 轻微模糊 | 放大细节发虚，但轮廓清晰 | 可判断合格性/一致性/画风；**不做妆容细节判断** |
| 中度模糊 | 轮廓能辨，细节看不清，有颗粒 | 仅做废图级判断；**不做一致性/妆容/画风判断**；退回重生成 |
| 重度模糊 | 脸都看不清，大面积马赛克 | **直接判废图，不做任何判断** |

**⚠️ 核心原则：模糊图绝不提"改眉毛粗细""调唇色"这类细节建议——
看不清就是看不清，改了也是瞎改。**

## 七、⭐ 保证看得准（5个方法）

```
1. 固定流程法：按顺序走，不跳步
2. 分区扫描法：脸分上庭/中庭/下庭，从上到下+从下到上各扫一遍
3. 反向找茬法：不带"好不好"心态，带"哪里有问题"心态找
4. 对照标准法：对照人设表/参数/checklist，不凭感觉
5. 盲点专项查：手指数量、耳朵、脖子、背景穿帮、画面边缘、角落水印
```

## 八、⭐ 五官细节（逐个看什么）

- **鼻子（5点）**：山根/鼻背/鼻头/鼻翼/鼻孔
- **嘴唇（6点）**：厚度/唇峰/唇色/唇形/质感/对称性
- **皮肤（7点）**：质感/颜色/妆感/瑕疵/油光/修容/高光
