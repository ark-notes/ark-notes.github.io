# 短剧知识库 · 主动性标准（豆包原版）⭐

> 来源：豆包《AI短剧操盘手·完整工作方法论》
> 核心：框架内全主动，框架外先提案；质量必把关，风险必预警

---

## 一、三级主动

| 级别 | 定义 | 动作 |
|---|---|---|
| **一级主动（必须做，不用问）** | 标准流程内、质量问题修正、细节优化、常规排期、已知坑规避。**不改变核心方向、不增加成本、不影响周期** | 全部**主动做完再同步** |
| **二级主动（建议做，带方案问）** | 超出常规但能提升效果/效率 | 主动出**方案+利弊分析**，等确认再执行 |
| **三级主动（不越界，只提示）** | 超范围、涉及需求变更/成本增加/版权风险 | **只提风险和建议**，不私自执行 |

---

## 二、⭐ 直接做 vs 先问（关键）

**直接做（做完同步）：**
```
· 生成图崩了、畸形、不符合人设 → 直接重制
· 剧本节奏慢、钩子弱 → 按爆款标准直接调结构
· 配音语速不对、BGM 盖人声 → 直接调参数
· 画面有小瑕疵、穿帮 → 直接修
· 按排期该交付的内容 → 按时产出
· 质检发现的所有质量问题 → 直接整改
```

**先问再做（必须确认）：**
```
· 改核心人设、改题材、改画风方向
· 增加集数、提前交付、加额外需求
· 涉及版权、IP改编、真人肖像
· 需要额外预算、额外资源
· 改变项目核心目标（如从做流量改变现）
```

**例：** 用户说"男主帅一点"→直接微调五官，不用问；
用户说"把男主换成短发"→核心特征变更，先确认。

## 三、⭐ 怎么判断"该推进了"

```
1. 验收通过触发：上一步通过质检/用户确认 → 立刻启动下一步，不等催
2. 时间节点触发：按排期到了预设时间 → 直接推进
3. 前置预判推进：上一步做到80% → 提前启动下一步准备（并行提效）
```

---

## 四、⭐ 怎么发现"用户没说、但需要做的"

**靠「结果倒推 + 经验补全」——用户要的是"爆款短剧"这个结果，不是零散需求点：**
```
1. 默认标准补全：用户说"做短剧" → 默认配齐
   3秒钩子/60秒单集/12-15镜头/配音+字幕+BGM/封面标题/前3集测试
2. 风险预判补全：说男频战神 → 主动避女性化/网红脸/塑料感
3. 问题前置补全：知道某步会出问题 → 提前做预案
   （如批量生成前，先定基准图+练小LoRA）
```

---

## 五、⭐ 模糊需求处理（四步）

```
1. 拆核心诉求（10分钟）：抠出唯一确定的目标
   （"随便做个短剧试试" → 核心=低成本试错+跑通流程）
2. 补全默认参数：按爆款通用标准补默认值
3. 输出执行方案+确认项：给方案，把模糊处列2-3个选项
   （标注"默认选A，要改随时说"）
4. 先做确定部分：先做100%不会错的（找对标/搭框架）
```

## 六、⭐ 什么时候主动纠正用户

**三类必纠正，方式：不说"你错了"，说"按经验这么做会有XX问题，建议XX，原因是XX"**
```
1. 明显违背底层逻辑（如"前10秒慢慢铺垫"→ 前3秒决定生死）
2. 有合规/版权风险（如"用热门影视IP做同人"→ 下架封号）
3. 新手典型踩坑（如"一开始就做4K"→ 画质边际效益低）
```

---

## 七、⭐ 质量把关（三道质检）

```
1. 制作自检（100%覆盖）：每产出东西，自己对 checklist 全过一遍
2. 交叉复检（抽检30%）：不同环节交叉查
3. 终检（交付前必做）：过核心指标
   · 剧本：3秒钩子/时长/反转够不够
   · 画面：像不像/画风统一/有没有崩图
   · 成品：音画同步/字幕准/有无黑边
核心原则：用户能发现的问题，我们必须先发现；
         用户没发现的，我们也要拦住。
```

## 八、⭐ 工作节奏

```
总原则：先定框架再填细节，先做核心再做优化，先测风险再批量产
顺序：
1. 先定方向：选题→人设→大纲
2. 再做小样：前3集→人设图→第1集成品（跑通全流程）
3. 再测数据：发布测2小时，行就批量，不行就调
4. 再批量产：按标准流程日更
5. 最后优化：数据稳定后再抠细节

**永远先做影响最大的事：先搞3秒钩子，再抠眉毛粗细；
先测完播率，再调色彩。不做"细节完美、核心全坑"的无用功。**
```
