# 短剧知识库 · 能力清单 + 决策规则（豆包原版）

> 来源：豆包《AI短剧操盘手·完整工作方法论》

## 一、⭐ 15项核心能力（5大类）

```
1. 底层认知类：爆款底层逻辑、算法规则理解
2. 内容创作类：选题判断力、人设设计、剧本结构、分镜设计
3. 技术制作类：提示词工程、画风把控、人物一致性、修图/配音/剪辑、质检
4. 运营数据类：数据解读、内容迭代、流量判断
5. 项目管理类：批量生产管理、风险预判避坑
```

| 能力 | 什么时候用 | 怎么用 | 注意 |
|---|---|---|---|
| 爆款底层逻辑 | 全程 | 所有决策回到「算法权重+人性情绪」 | 不凭个人喜好 |
| 选题判断力 | 立项 | 看近30天爆款榜，找上升赛道 | 只做数据验证能爆的 |
| 人设设计 | 立项 | 「身份+反差+执念+符号+小缺点」 | 模板化必扑 |
| 剧本结构 | 全阶段 | 严格按60秒5段式 | 前3秒必须有冲突 |
| 分镜设计 | 剧本转画面 | 12-15镜头，4-5秒一个 | 多用近景特写 |
| 提示词工程 | 生图 | 按权重排序 | 每次只改1-2变量 |
| 画风把控 | 定画风+质检 | 同题材统一参数 | 绝不2D/3D混 |
| 一致性管控 | 批量生产 | 基准图+提示词+LoRA+seed | 相似度<80%废掉 |
| 质量质检 | 每步交付前 | 对照checklist | 废图第一时间淘汰 |
| 数据解读 | 发布后 | 看完播率+前3秒跳出 | 别被点赞迷惑 |
| 内容迭代 | 数据不好 | 反推问题，精准改 | 每次只改一个变量 |
| 批量管理 | 量产 | 模板化+流水线 | 求稳定不求单集极致 |
| 风险预判 | 全程 | 提前做预案 | 别重复踩坑 |

## 二、⭐ 豆包自认"独有"的5项能力

```
1. 标准化看图质检体系（识别准确率95%+，漏判少90%）
2. 提示词权重逻辑（迭代效率是行业3倍）
3. 数据反向归因（从曲线反推问题，命中率80%+）
4. 全流程避坑清单（30坑+正确做法，试错成本降60%）
5. 低成本批量生产（单集成本比行业低30%，效率高2倍）
```

## 三、⭐ 决策规则

### 方案二选一：加权评分 + 一票否决
```
第一步 一票否决（任意一个直接排除）：
· 违反算法底层逻辑 · 有版权/合规风险
· 明显拉低完播率 · 超预算/周期

第二步 加权打分（总分高的选）：
· 效果影响 40% · 效率影响 25% · 成本投入 20% · 风险大小 15%
```

### 数据不好排查（按权重从高到低，每次只改一个变量）
```
1. 查前3秒跳出率 >70% → 改钩子
2. 查完播率曲线掉点：
   15秒掉 → 铺垫太长；30秒掉 → 爽点不够；结尾掉 → 留钩不行
3. 查互动率低 → 情绪不够
4. 查关注率低 → 人设不讨喜/钩子弱
5. 以上都好 → 题材/赛道不行
```

### 卡住了怎么办（三级解法，绝不死磕30分钟）
```
先替代 → 再简化 → 最后绕开
· 技术卡：换模型/换参数/拆简单
· 创意卡：找3个对标抄结构换壳
· 数据卡：换3版钩子/标题/封面测；不行就切题材
· 流程卡：先并行做后面的 / 先做低配版
**心态：短剧是结果导向，能用就行，不追求完美。**
```

### 优先级排序
```
1. 合规风险类（最高）
2. 核心指标类（完播率/跳出率/播放量）
3. 质量问题类（崩图/不一致/音画不同步）
4. 效率成本类
5. 细节优化类（妆容微调/色彩/精修）← 最低

口诀：影响完播率吗？影响交付吗？影响安全吗？
     都不影响→往后放；有一个影响→往前排。
```
