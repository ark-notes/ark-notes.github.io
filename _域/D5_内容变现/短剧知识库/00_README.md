## 二、核心结论速查

```
· 好看的关键 = 妆容（不是画风）
· 当前主流爆款画风 = 三渲二
· 提示词：核心词≤15、负面词≥20、一次只改1-2变量
· 男频=向外征服，女频=向内确认
· 爆款要素排序：钩子40% > 情绪25% > 人设15%
· 精致 = 层次和秩序（不是细节多）
· 权重：画风25% > 主体25% > 五官25%
```
