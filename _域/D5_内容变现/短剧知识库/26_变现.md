# 短剧知识库 · 变现

> 来源：豆包《AI短剧运营全体系》
> ⚠️ 具体金额是豆包给的（可能变动），需以平台最新政策为准

## 一、⭐ 6种变现方式（按门槛低→高）

```
1. 广告分成（IAA）：用户看广告解锁，创作者拿分成，门槛最低
2. 付费分账（IAP）：用户付费看全集，按比例分成，效率最高
3. 平台保底/扶持：和平台签约，拿制作保底+分成
4. 私域引流变现：导到微信卖课/周边/社群
5. 收徒/培训变现：做起来后教别人做，收学费
6. IP衍生变现：第二季/周边/真人改编
```

## 二、⭐ 收入模型/门槛

| 方式 | 门槛 | 收入模型 | 适合 |
|---|---|---|---|
| 广告分成 | 1000粉+流量主 | 千次播放1-3元，爆款月几千到几万 | 新手/个人/矩阵 |
| 付费分账 | 入驻平台+版权报备 | 自然流量分成70%-80%，投流按ROI | 团队 |
| 平台保底 | 签约+剧本评审 | 保底2-20万+20%-40%分账 | 专业编剧/公司 |
| 私域变现 | 有粉丝基础 | 客单价几十到几千 | 个人IP |

## 三、⭐ 红果/抖音规则（2026 豆包版）

**抖音：**
```
· 付费分账(IAP)：自然流量创作者拿80%
· 广告分成(IAA)：70%，月度结算
· 扶持：AI融合短剧单部保底40-100万；
       系列剧50-200万；创新题材20-400万
```
**红果：**
```
· 真人剧本：S++级20万保底+40%分成；S级12万+20%；A级6万+12%
· AI仿真人剧本：S+级8万保底+20%永久分账；
               S级6万；A级4万；A+级2万
· 特点：全生命周期分账，长尾强
· 投稿：30集完整剧本，审核通过拿保底
· 优势：平台包流量，不用自己投流
```

## 四、⭐ 从0到第一笔收入

```
广告分成：最快15天（7天冷启动+7天更剧，1000粉开流量主）
付费分账：最快30天（15天做剧+报备+上架）
平台保底：45-60天
私域/收徒：1-2个月（粉丝过万后）
```
**新手建议：** 先从广告分成做起，跑通流程，再转付费分账/保底。
