# 短剧知识库 · 画风判据表（3秒定类）

> 来源：豆包《标准看图流程》
> ⭐ 解决"我看不出画风"的问题

## 核心方法：放大看脸颊皮肤 + 材质反光

| 画风 | 核心判据（必中）| 辅助特征 | 误区提醒 |
|---|---|---|---|
| **2D平面/手绘** | 无3D体积感；光影平涂/手绘笔触；有明确轮廓线；平面透视 | 画笔质感，色彩块面强，材质无真实反光 | 别把三渲二的描边当2D线条 |
| **三渲二** | 有3D体积感，但皮肤/材质**完全没有真实物理纹理**；光影简化柔和 | 边缘可能有细描边；饱和度高；**毛孔/皮肤纹理完全消失**；材质反光简化 | 写实风三渲二易和低质3D写实混 |
| **3D写实** | 皮肤有**真实毛孔/细微纹理/自然瑕疵**；材质真实物理反光（布料纹理、金属高光）| 细节丰富，光影自然过渡，有景深 | 高磨皮3D写实易和三渲二混 |

## ⭐ 操作技巧（最实用）
```
把图片放大 200%，看苹果肌位置：
· 有毛孔/细碎纹理 → 3D写实
· 完全光滑像画出来的 → 三渲二
· 平涂有笔触 → 2D
```

## ⭐ 核心区分点
```
三渲二 vs 3D写实：
  看【有没有皮肤毛孔】
· 毛孔/纹理消失 → 三渲二
· 有真实毛孔 → 3D写实
```

**→ 之前我判不准画风，是因为【没用这个方法】+【视觉模型弱】。
现在有了判据，可以对照着判。**
