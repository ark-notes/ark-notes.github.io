## 🔹 第 1 步：生成「陈默」角色图

### 操作
```
① 新建会话
② 输入提示词（角色设定里的）
③ 生成 → 多张里挑最好的
④ 存下来（这是你的"陈默基准图"）
```

### 提示词（复制）
```
26岁中国男性，短发利落微凌乱，剑眉星目，
眼神冷峻锐利，鼻梁高挺，下颌线凌厉，
面部骨相优越有辨识度，不是千篇一律的AI脸。

肩膀背着黑色战术背包，末世废土感。
写实电影质感，侧光，皮肤有真实纹理，
超高细节，电影级布光，8K。
```

### ⚠️ 注意
```

```
