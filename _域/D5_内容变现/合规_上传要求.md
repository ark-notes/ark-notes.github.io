# 短剧上传 · 合规要求（2026 最新）

> 来源：新华网/抖音审片标准/标识办法/账号帮
> 整理：2026-10-04
> ⚠️ 不遵守 → 限流/下架/罚款10万-100万

---

## 一、⭐ AI 标识（强制）

### 抖音要求（2026）
```
AI生成内容占比 ≥50% 的作品 → 必须在【三处】标注"本作品含AI生成内容"：
① 片头前 3 秒
② 封面
③ 简介
→ 未达标：直接限流或下架
```

### ⚠️ 绝对不能"裁掉标识"
> 「导出后自行裁掉角标、水印或片头提示，
> 导致二次发布内容失去显式标识」→ **违规**

---

## 二、⭐ 备案（前置条件）

```
AI短剧合规上线 =
① 按投资额走完【备案】
② 标注【备案号】
③ 加好【AI标识】（显式+隐式）
→ 两个都不能少
```

**⚠️ 先备案后上线（2026年4月起，未备案存量强制下线）**

---

## 三、⭐ 水印处理（回答用户问题）

| 水印 | 处理 |
|---|---|
| **"AI生成"声明** | 🔴 **必须保留**（合规） |
| **备案号** | 🔴 **必须有** |
| **工具品牌水印**（如 ARKIE AI） | 🟡 **可裁**（不是合规标识） |

**⚠️ 关键：别把"AI标识"当成"品牌水印"裁掉！**

## 七、⭐ 阿奇视频的水印（实测）

**阿奇生成的视频结尾有 2 个东西：**
```
① 中间：ARKIE AI 吉祥物 + "ARKIE AI"字
② 底部："本视频由阿奇AI生成"
```

### 处理建议
| 元素 | 性质 | 处理 |
|---|---|---|
| **"本视频由阿奇AI生成"** | **AI生成声明**（近似合规标识） | 🟡 **保留**（或换成规范格式） |
| **ARKIE吉祥物LOGO** | **品牌水印** | 🟡 **可裁**（非合规标识） |

### 对比专业短剧
```
专业剧：片头备案号 + "内容由AI生成" + 无品牌水印
阿奇给：片尾"本视频由阿奇AI生成" + ARKIE品牌LOGO
```

### ⚠️ 待确认
```
问红果：认不认"本视频由阿奇AI生成"这个格式
· 认 → 直接用
· 不认 → 换成红果要求的格式
```

## 八、⭐ 修正：按市场做法（用户意见）

**用户的判断（正确）：**
> 「你看哪个剧带品牌水印的？人家即梦水印也没带」
> 「这是短剧，是个剧」

### 结论：工具品牌水印 → 去掉

| 阿奇视频结尾 | 处理 |
|---|---|
| **ARKIE吉祥物 + "ARKIE AI"** | 🔴 **去掉**（品牌署名，非合规）|
| **"本视频由阿奇AI生成"** | 🔴 **去掉**（工具署名，专业剧不带）|

### 但"AI标识"合规要有 → 自己加规范版

```
① 去掉阿奇的品牌水印 ✅
② 自己加【规范AI标识】在片头
   （如"本作品含AI生成内容"，按平台要求格式）
③ 片头加备案号（红果给）
        ↓
= 和看的专业剧一致
```

**⚠️ 关键：**
```
"工具署名（由XX生成）" → 去（专业剧不带）
"AI生成性质声明" → 保留（合规），但用规范格式
```
