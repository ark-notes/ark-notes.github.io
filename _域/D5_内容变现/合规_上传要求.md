# 短剧上传 · 合规要求（2026 最新）

> 来源：新华网/抖音审片标准/标识办法/账号帮
> 整理：2026-10-04
> ⚠️ 不遵守 → 限流/下架/罚款10万-100万

---

## 一、⭐ AI 标识（强制）

### 抖音要求（2026）
```
AI生成内容占比 ≥50% 的作品 → 必须在【三处】标注"本作品含AI生成内容"：
① 片头前 3 秒
② 封面
③ 简介
→ 未达标：直接限流或下架
```

### ⚠️ 绝对不能"裁掉标识"
> 「导出后自行裁掉角标、水印或片头提示，
> 导致二次发布内容失去显式标识」→ **违规**

---

## 二、⭐ 备案（前置条件）

```
AI短剧合规上线 =
① 按投资额走完【备案】
② 标注【备案号】
③ 加好【AI标识】（显式+隐式）
→ 两个都不能少
```

**⚠️ 先备案后上线（2026年4月起，未备案存量强制下线）**

---

## 三、⭐ 水印处理（回答用户问题）

| 水印 | 处理 |
|---|---|
| **"AI生成"声明** | 🔴 **必须保留**（合规） |
| **备案号** | 🔴 **必须有** |
| **工具品牌水印**（如 ARKIE AI） | 🟡 **可裁**（不是合规标识） |

**⚠️ 关键：别把"AI标识"当成"品牌水印"裁掉！**

---

## 四、⭐ 参考：专业短剧怎么做的

（从拆解看）
```
① 片头 → 备案号
② 片内 → "内容由AI生成"声明
③ 品牌水印 → 基本没有/很小
```

---

## 五、⚠️ 你要做的（前置）

```
① 【备案】← 最重要（否则发不了）
② AI标识（片头3秒+封面+简介）
③ 品牌水印 → 可裁可不裁
```

---

## 六、境外问题

**关于"境外"：**
```
· 如果是"国内平台"（红果/抖音）→ 遵守国内规定（备案+标识）
· 如果"出海"（海外平台）→ 另有一套规则
→ 先确定"发哪"，再定规则
```
