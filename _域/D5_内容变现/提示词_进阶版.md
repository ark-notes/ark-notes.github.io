## 二、⭐ 进阶版提示词（用进阶结构）

```
顶级3D国漫画风，极具质感的BJD风格，
虚幻引擎5渲染，次世代游戏建模，
极高细节的3D CG人物设定图。

【角色】26岁中国男性，极其俊美的长相，
清冷矜贵的气质，眼神深邃有故事感。

【面部】鹅蛋脸，脸型流畅，颧骨不突出。
剑眉，眉毛浓密有型。
眼睛狭长深邃，双眼皮，眼尾微扬，
眼中有锐利的眼神光。
鼻梁高挺精致，鼻头小巧。
嘴唇薄而唇形清晰，嘴角平直。
下颌线清晰流畅，下巴微翘。

【皮肤】白皙通透，有真实质感，
细微毛孔可见，不过度磨皮。

【发型】黑色短发干净利落，几缕碎发垂额前。

【服饰】做旧的深灰色连帽卫衣（有磨损灰尘），
黑色工装裤，厚底作战靴，肩背黑色战术背包，
末世废土感。

【光影】电影级柔和侧光 + 轮廓光，
明暗有层次，面部立体。

【画质】8K超高清，CG海报级别。

【约束】面部稳定，五官清晰，无变形，无穿模。
```

## 三、⭐ 进阶技巧（教程）

```
1. 先出"定妆照"当锚点 → 后续镜头只描述动作/场景
2. 生成"基因库"（三视图）锁体型
3. 提示词结构：角色+面部+肢体+时间轴+光影+画质+约束
```

⚠️ 注意：阿奇用"单张图"（不用三视图，否则会展示三视图）
