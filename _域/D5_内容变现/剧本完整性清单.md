# 剧本完整性清单（防漏）

> 目的：确保剧本"一个要素不漏"
> 来源：万众编剧规范 + 塔猴12项要素 + 彭子骁格式
> 建立：2026-10-04

---

# 一、⭐ 专业「12项分镜要素」（逐项对照）

| # | 要素 | 说明 |
|---|---|---|
| 1 | **镜头编号** | 镜1、镜2… |
| 2 | **景别** | 远/全/中/近/特写 |
| 3 | **视角/机位** | 平视/俯视/仰视 |
| 4 | **分镜场景类型** | 对话/动作/情绪/转场 |
| 5 | **综合动作** | 人+物+环境的动作 |
| 6 | **光影/色调** | 布光+色彩 |
| 7 | **镜头动作（运镜）** | 推/拉/摇/移/固定 |
| 8 | **情绪/感受表达** | ⭐ 核心 |
| 9 | **角色台词** | — |
| 10 | **情绪标注** | 爽/虐/惊/怒/甜 |
| 11 | **音效** | 环境音+特殊音效 |
| 12 | **时长** | 精准秒数 |

**⚠️ 字数限制：除编号/台词外，其余9项 ≤100字（防AI跑偏）**

# 二、⭐ 完整剧本「要素清单」

## A. 结构层
```
□ 题材/主题
□ 核心冲突
□ 人物关系
□ 风格基调
□ 目标受众
□ 目标时长
□ 节奏（开场即爆点/每30秒转折/结尾悬念）
□ 剧情概述
□ 单元大纲
□ 情节点分布（钩子→发展→危机→高潮→结局）
□ ⭐ 情绪曲线
□ 可视化关键场景建议
```

## B. 单集层
```
□ 开场（0-3秒）最强冲突
□ 每30秒一个钩子/反转/悬念
□ 结尾强追更点
□ 总字数 800-1200（或按要求）
```

## C. 分镜层（12项，见上）
```
□ 编号/景别/视角/类型/动作/光影/运镜
□ 情绪/台词/情绪标注/音效/时长
```

## D. 台词层
```
□ 极简（每句 ≤15字）
□ ⭐ 标注情绪（爽/虐/惊/怒/甜）
□ 内心独白标注（角色(内心)）
□ 沉默标注（角色(沉默X秒)）
```

## E. 动作层
```
□ 具体到表情和肢体
□ 微表情（鼻腔一酸/眉头皱/指节发白）
□ 走位描述
```

## F. 漫画技法层
```
□ 立绘 / ⭐ Q版（内心活动用）
□ △（视觉动作）
□ OS（心理活动）
□ VO（旁白）
□ 镜头过渡（防突兀）
```

## G. 音效层
```
□ 环境音
□ 特殊音效
□ BGM（情绪配合）
```
