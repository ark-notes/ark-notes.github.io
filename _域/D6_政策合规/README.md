## 二、已查证的事实

### 文件 1：《金融产品网络营销管理办法》

| 项 | 内容 |
|---|---|
| **文号** | 公告〔2026〕第9号 |
| **发布方** | 八部门（央行、工信部、市场监管总局、金融监管总局、证监会、知识产权局、网信办、外汇局） |
| **制定/公布** | 2026-04-21 / 2026-04-24 |
| **⚠️ 施行** | **2026-09-30** ← 用户说的日期对上了 |

**关键条款：**
- **第六条**：任何机构和个人**不得为非法金融活动提供网络营销服务或便利**（非法金融活动含**虚拟货币发行交易**）
- **第二条**：**金融机构、第三方互联网平台外的其他组织或个人，不得开展或变相开展金融产品网络营销**
- **第十条（七）**：**禁用词** —— 「低风险」「低门槛」「秒到账」「高收益」「低利率」「无成本」
- **第十条（三）**：不得**保本、承诺收益、预测未来业绩**
- **第六条末**：**境外机构未经许可面向境内居民提供金融产品服务** = 也属非法金融活动

### 文件 2：银发〔2026〕42号

| 项 | 内容 |
|---|---|
| **发布** | 2026-02-06（央行等八部门） |
| **要点** | **废止**银发〔2021〕237号（924通知）；**新增**禁止挂钩人民币的稳定币、禁止境内 RWA 代币化 |
| **境外条款** | 「境外单位和个人不得以任何形式非法向境内主体提供虚拟货币相关服务」 |

## 三、对用户的实际影响（谨慎表述）

| 方面 | 影响 |
|---|---|
| **内容里宣传虚拟货币** | 🔴 高风险（第六条） |
| **挂交易所/项目注册链接** | 🔴 可能构成「提供便利」 |
| **拉群→引导注册入金→返佣** | 🔴 可能构成「提供便利」 |
| **用禁用词**（低门槛/秒到账等） | 🔴 第 10 条明文禁止 |
| **承诺收益/预测涨跌** | 🔴 第 10 条明文禁止 |
| **单纯讲 AI 产品功能** | 🟢 风险较低 |
| **「算国外」** | ⚠️ **不是免责理由** —— 专门有条款管「境外机构面向境内居民」 |
