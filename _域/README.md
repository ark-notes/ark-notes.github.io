# 域管理（MasterD 的多任务体系）

> 用户要求（2026-10-03）：
> **「你不只是要帮我做网站的，这只是一件事。你需要帮我做方方面面的事。」**

## 为什么有这个目录

**用户的事是「多方面」的，不是只有网站。**

**每件新事 = 一个新域。**
**域的规则通用（严谨/自进化/落盘仓库），但内容和方法各自独立。**

---

## 铁律

1. **新事 → 先判断属于哪个域**
2. **不许把所有事都塞进"网站"里**
3. **域的规则通用**（严谨/自进化/落盘），**方法独立**
4. **每个域有自己的进度文件**，方便接续

---

## 通用规则（所有域都适用）

| # | 规则 |
|---|---|
| 1 | **严谨准则** —— 不夸大、标来源、不确定就说不确定 |
| 2 | **自进化** —— 学/记/查/改 |
| 3 | **落盘仓库** —— 沙箱重启也能恢复 |
| 4 | **区分「我能验证的」和「需要用户配合的」** |
| 5 | **每完成一件就发布** |
