# 中国本地化认知体系（总纲）

> 建立：2026-10-04
> 触发：用户指出「我用国外数据理解中国市场是不现实的」
> 定位：这是【大方向分类框架】，不是某个可调用的组件

---

## 一、为什么要建这个

```
问题：我的底层数据/思维是国外的
     但用户是中国用户，市场是中国市场
        ↓
= 用国外坐标系理解中国 → 不现实
  （例：做漫剧不懂中国观众爽点；
       做网站不懂中国用户习惯）

正解：取世界最优秀的方案 → 经中国式处理 → 适应中国市场
```

**核心：本地化差异 = 风土人情 + 用户习惯 + 喜欢/讨厌的东西**

## 三、使用原则

```
⓪ 总原则：取世界之最优，做中国之改造，落中国之市场
         （找世界上最优秀的方案 → 中国式处理 → 适应中国）
① 动手前 → 先查【中文资料/市场】，不靠我的直觉
② 有样本 → 优先照样本做（样本 > 我的判断）
③ 做判断 → 用"中国市场标准"当尺子，不用"国际审美"
④ 词库 → 用行业现成词，不自己"翻译英文概念"
⑤ 遇到不确定 → 明说，不硬装懂
```

## 四、我的已知短板（诚实记录）

| 短板 | 表现 | 补救 |
