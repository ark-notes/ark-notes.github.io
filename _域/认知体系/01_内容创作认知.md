## 一、漫剧/短剧行业标准（已获证据）

### 1.1 类型词（红果短剧主流）

**证据来源**：塔猴/知乎/CSDN 教程

| 行业叫法 | 说明 |
|---|---|
| **高级CG漫剧插画** | 出图类型词 |
| **韩漫霸总风格** | 风格词 |
| **3D国漫 / 国风CG** | 类型词 |
| **赛璐璐 / 平涂** | 2D漫剧主流画风 |
| **BJD质感 / 伪厚涂** | 质感词 |

**⚠️ 不用**：`3D仿真人CG渲染`（这是我错造的，偏"真人"，不是漫剧）

### 1.2 提示词「三段式结构」（行业写法）

```
【基础定位】谁（年龄/身份/气质）
【细节描述】脸型/五官/发型/服装/眼神
【风格指令】画风 + 光影 + 配色 + 题材 + 精度
```

**真实范例（塔猴）：**
```
28岁成熟俊美男子，冷峻且带有压迫感的霸总气质。
棱角分明的面部轮廓，眼神深邃疏离。
乌黑发亮的背头造型，发丝质感细腻。
身着黑色高定三件式西装…
高级CG漫剧插画，韩漫霸总风格，强烈的冷暖色调对比。
顶级光影构图，笔触流畅，权谋感十足，极致精致。
```

### 1.3 必备字段（我从来没写过）

| 字段 | 作用 |
|---|---|
| **五官固定** | 锁角色一致性 |
| **统一画风** | 锁风格一致性 |

### 1.4 提示词权重规则

```
① 重要词放【前面】（权重高）
② 顺序：概念/大范围 → 画面内容 → 细节
③ 逗号分隔每个短语
④ 平台支持权重：(词:1.2)
⑤ 负面词：排除干扰项
```
